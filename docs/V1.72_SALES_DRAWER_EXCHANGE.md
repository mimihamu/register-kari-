# v1.72 販売画面の両替・ドロア開放

- 通常販売画面の下部操作バーへ「両替」を追加。小型横画面の2段バー・大型横画面の1段バー両方に表示。
- 「両替」はプリンター接続のキャッシュドロアを開放するのみ。金額を入力せず、入金・出金・売上・在高に影響しない。
- 既存プリンターの「両替時にドロアを開ける」設定、通信設定、パルス設定に従う。無効・接続不可はエラーメッセージ。
- 販売権限を持つログイン中の担当者に限定。非同期送信、連打抑止、イベントキー重複排除、ドロア開放監査に従う。
- 入出金の新規登録では「両替」の選択肢を撤去、入金／出金のみ。過去に登録された両替履歴・既存のCashMovementTypeは読み取り互換で残す。
- レジマイナス（返品）画面には両替ボタンを追加しない。
- 実機検証：開放信号・実機開放、オフライン/プリンターエラー、権限なし拒否、連打時1回、入出金履歴の両替表示、狭い画面の7ボタン配置。

# v1.36 Issue #137 #28 RCPT-005 ロゴプリセット — 正式仕様監査

## 結論

Issue #137 の旧チェック項目 `RCPT-005 ロゴプリセット` / `20種仕様突合` は、正式仕様書 `REGISTER（仮）_Androidレジ_詳細仕様書_v2.5` に存在しない。

正式仕様を優先し、20種類のロゴプリセットは実装しない。存在しない仕様を追加すると、初版の正式仕様から逸脱するためである。

## 正式仕様で確認できる店名スタンプ要件

正式仕様 v2.5 §8.14 `店名スタンプ・印字デザイン設定（SCR-720）` では、主に以下を扱う。

- 文字スタンプ
- PNG/JPEG画像スタンプ
- 切抜き、回転、明るさ、閾値
- 透過を白として扱うモノクロ変換
- Bayer / Floyd-Steinberg 等のディザ
- アスペクト比維持と印字可能幅への収まり
- 58mm 384dot / 80mm 576dot を基準とする実幅プレビュー
- stampVersion と文書別適用
- 再印刷時のsnapshot / source hash関連

`20種プリセット` は上記正式要件に含まれない。

## Issue台帳上の扱い

- #28 は「正式仕様 v2.5 に該当要件なし（旧台帳項目）」として不適用扱いにする。
- SCR-720 の未完了要件を #28 の20種プリセットへ読み替えない。
- 切抜き・回転、文字スタンプ、文書別適用、テスト印刷、stamp snapshot/source hash は #27/SCR-720 の正式残件として継続する。

## 実機

本監査は仕様差分の整理であり、実機確認項目ではない。#27/SCR-720の実印字確認は別途未確認のまま維持する。

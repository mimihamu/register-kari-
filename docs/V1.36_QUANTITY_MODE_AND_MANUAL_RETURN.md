# v1.36 quantityMode / 元取引なし返品

正式仕様 v2.5 4.1 / 9.2 / 14 の数量契約を実装する。

- INTEGER: 通常商品。整数数量のみ。
- DECIMAL: 量り売り商品。0.01～9,999.99。
- 正本数量は 1/100 scaled integer。
- product_meta.quantity_mode に商品設定を保存。
- cart_items / held_ticket_items / sale_items に quantity_mode をスナップショット保存。
- 既存小数明細は DECIMAL、その他の既存明細は INTEGER として補完。
- 元取引返品は売上時 quantity_mode snapshot で判定。
- 元取引なし返品は現在の商品 quantityMode で判定し、quantity_hundredths で計算・保存・表示。
- legacy Int quantity は互換維持。

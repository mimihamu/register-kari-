# v0.90.0-dev.1 リリースノート

## 概要

v0.90では、v0.88/v0.89で追加した上書き更新の起動台帳・DB健全性ゲートを、責任者がSCR-767「データ保全・バックアップ・復元」から確認できるようにした。

## 変更内容

- `AppUpdateDiagnosticsV090` を追加
- v0.88更新台帳SharedPreferencesを読み取り専用で参照
- v0.89 DB健全性失敗証跡を読み取り専用で参照
- 現在版 / 最終成功版 / 最終成功日時を表示
- 現在版pending起動を表示
- source→target、開始時刻、起動試行回数を表示
- 前版未完了証跡を表示
- DB健全性NG対象版・検出時刻・サニタイズ済みsummaryを表示
- `AppUpdateDiagnosticsPanelV090` をSCR-767へ追加
- 画面ON_RESUME時に自動再読込
- 更新状態を削除・強制成功させる操作は追加しない

## 状態優先順位

1. DB健全性NG・更新成功未確定
2. 起動成功確認中
3. 起動成功確定済み
4. 更新台帳未確立

## データ保護

v0.90の診断Reader/PanelはSharedPreferencesとBuildConfigのみを読み取り、DB書込みや更新状態の変更を行わない。

販売、税、支払、印刷、Drive、CD、バックアップ、復元の業務処理は変更しない。

## バージョン

- つぐレジ: `0.90.0-dev.1` / versionCode `120`
- つぐレジ＋: `0.14.0-dev.1` / versionCode `14`（変更なし）
- つぐレジ CD: `0.14.0-dev.1` / versionCode `7`（変更なし）

## テスト

- DB健全性NGが最優先表示になること
- pending起動が確認中表示になること
- 現在版と最終成功版一致時に成功確定済みになること
- 診断ReaderがSharedPreferencesを変更しないこと
- DBアクセス・SQL書込みを持たないこと
- SCR-767からv0.90パネルが呼ばれること
- ON_RESUMEで再読込すること
- 状態削除・強制成功操作が存在しないこと
- v0.14以降の累積テストを維持すること

## 実機未確認

以下は実機確認が必要。

- 800×480〜1920×1080横画面でのSCR-767表示
- Android表示サイズ・フォント倍率変更
- v0.89→v0.90上書き後の表示
- 起動途中強制終了→再起動時の試行回数表示
- DB健全性NG証跡表示
- 健全化後の表示更新
- Activity復帰時の自動更新

CI成功やAPKビルド成功を実機確認済みとは扱わない。

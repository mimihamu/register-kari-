# つぐレジ v0.29.0-dev.1 リリースノート

## 全画面レスポンシブ基盤

- 800×480dpから1920×1080dpまでを共通の画面クラスで判定
- Androidの表示サイズ・フォント倍率をレイアウト判定へ反映
- ヘッダー、カード余白、画面余白、下部操作の寸法を共通化
- 固定幅の下部操作を画面幅に応じた比率配分へ変更
- 小さい画面では補助情報を省略し、主要操作領域を優先
- 高さ不足時は部品を重ねず、対象領域だけをスクロールへ切り替え

## 販売画面

- 注文一覧・テンキー・商品領域の列比率を画面サイズ別に変更
- テンキーを固定42dpから、残り高さに応じた48～80dpへ変更
- 金額表示、数字キー、数量、訂正、行編集、値引、取引中止へ残り高さを配分
- 下部の伝票一覧、保留、売上一覧、プリンター、印刷管理、会計を固定幅から比率配分へ変更
- コンパクト表示では補助状態文を省略し、担当者と主要操作を優先

## 会計画面

- 内訳・支払入力領域を固定430dpから画面幅に応じた比率配分へ変更
- テンキー、金額表示、カード、商品券、掛売を残り高さに応じて拡大
- 支払内訳だけに高さ上限とスクロールを設定
- 高さ不足時も会計確定操作とテンキーを重ねない構成へ変更

## MainActivity配下の共通変更

- ヘッダー高、タイトル文字、カード内余白を画面クラス別に変更
- 下部の戻る・保存・確定操作を固定幅から比率配分へ変更
- フォント倍率1.3以上ではコンパクト構成を使用
- 最小タップ領域48dpを維持

## 自動検査

- 800×480dp
- 1024×600dp
- 1280×800dp
- 1536×960dp
- 1920×1080dp
- フォント倍率1.3
- テンキー最小48dp・最大80dp
- 高さ不足時のスクロールフォールバック

## 実機確認が必要

- 販売・会計画面で余った高さがテンキーへ配分されること
- Androidの表示サイズ変更後も主要操作が重ならないこと
- フォントサイズを上げてもボタンや金額が欠けないこと
- 低い画面でテンキー領域をスクロールできること
- 管理・設定系Activityの個別最適化対象を洗い出すこと

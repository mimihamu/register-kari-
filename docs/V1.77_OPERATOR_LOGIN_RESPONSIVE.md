# v1.77 担当者画面：名前ボタンの幅を自動調整

- PIN入力パネル幅を確保した残りの横幅から、担当者ボタンの列数を自動決定。
- 340dp未満は1列、340〜489dpは2列、490dp以上は3列（文字倍率1.3以上は最大2列）。
- 小型Android端末や大きい文字でも1つの担当者ボタンが極端に細くならないように調整。
- PIN必須／PINなし担当者のログイン動作、セッション権限、テンキー高さ、既存ボタンデザインは変えない。
- 自動テスト `V177OperatorLoginResponsiveTest` で境界値とPINなし担当者操作を確認。
- 実機での確認：800×480、1024×600、文字拡大150%、長い担当者名、PINなし担当者、キーボード。

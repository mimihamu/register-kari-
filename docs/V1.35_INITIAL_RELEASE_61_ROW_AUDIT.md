### 状態の定義

- `実装済`: コードと自動検証まで閉じ、実機を要しない項目。
- `部分実装`: v1.35担当範囲の一部だけ実装済み。
- `未実装`: 対応コードが無い、または要件の中心が未実装。
- `将来版監査のみ`: v1.36以降の担当。v1.35では実装せず現状確認だけ行う。
- `実機確認待ち`: v1.35担当コード/自動検証は進んでいるが、最終実機試験を残す。

# つぐレジ v1.00.0-dev.1 リリースノート

## 概要

v1.00では、実プリンターで確認された日本語文字化けを初期リリース阻害要因として優先修正した。

v0.99までの実装は日本語本文を `MS932` の2バイト列へ変換していたが、プリンター初期化後は `ESC t 1` の1バイト文字テーブル選択だけで、EPSON日本語仕様の漢字コード体系選択が不足していた。

`EPSON_TM_JAPAN` プロファイルを `Shift_JIS` とし、`ESC @` 初期化後に `FS C 1` を送信してから日本語本文を出力するよう変更した。

## 主な変更

- `EPSON_TM_JAPAN.charsetName` を `Shift_JIS` へ明示。
- `PrinterProfile` に機種別 `kanjiCodeSystem` を追加。
- EPSON日本語プロファイルのみ `kanjiCodeSystem = 1`。
- `PrinterCommandEncoder.beginDocument()` を追加。
- EPSON日本語の開始シーケンスを `ESC @ → ESC t 1 → FS C 1 → ESC a 0` とした。
- `ESC @` 後にShift JIS漢字コード体系を必ず再選択する。
- STAR / GENERICにはEPSON用 `FS C 1` を送信しない。
- 既存の売上レシート・領収書・業務帳票・プリンター試験は同一エンコーダを通るため共通修正される。
- 既存プリンター連続印刷試験が1枚から実行可能で、日本語サンプルを含むことをテストで固定。

## 日本語バイト列回帰

`V100JapanesePrinterEncodingTest.kt` を追加し、以下を確認する。

- `つぐレジ` がShift JISバイト列であること。
- UTF-8の日本語バイト列が本文へ混入しないこと。
- `領収書` がShift JISであること。
- 税シンボルに使用する `内 / 外 / ※` がShift JISであること。
- `円 / ￥` がShift JISであること。
- `FS C 1` が初期化後、本文前に置かれること。
- STAR / GENERICへEPSON固有の漢字体系指定が混入しないこと。

既存 `V012PrinterProfileTest.kt` も新しいEPSON初期化シーケンスへ更新した。

## 維持する既存安全仕様

- TCP 9100 / ESC/POS。
- v0.99の同一endpoint送信直列化。
- v0.99の自動／手動同一ジョブ二重印刷防止。
- permit待機タイムアウトの送信前安全失敗。
- `CONNECTING / CONNECTED / WRITE_STARTED / FLUSHED`。
- `WRITE_STARTED`以降の失敗は送信結果不明として自動再送しない。
- v0.98の自動印刷の古い順・1run最大20件・最初の失敗で停止・single-flight。
- 58mm / 80mm。
- カット / ドロア設定。
- EPSON DLE EOT状態確認。
- 手動再印字・責任者PIN付き強制印刷・監査ログ。

## 実機再確認

文字化けそのものは実機で発生確認済みだが、本版で解消したかはv1.00 APKを実プリンターで再印刷するまで未確認。

完成APK導入後は、既存のプリンター連続印刷試験を以下で1枚実行する。

- プロファイル: EPSON TM（日本語）
- 印刷回数: 1
- 印刷間隔: 1秒

`つぐレジ / あいうえお / アイウエオ / 日本語印字・通信・連続動作確認` が文字化けせず印字されることを優先確認する。

レシート／領収書では `内 / 外 / 内※ / 外※ / 円` を追加確認する。

カット、ドロア、DLE EOT、紙切れ、カバー開、LAN切断、送信途中切断、自動／手動競合は引き続き最終総合実機試験へ繰越する。

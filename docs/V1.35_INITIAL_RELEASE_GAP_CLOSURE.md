## 開発ルール

- v1.34までの機能を壊さない累積開発とする。
- PRはDraftのまま維持し、明示依頼があるまでmergeしない。
- `main`へ直接commitしない。
- 仕様・コード・テスト・ドキュメントを同時に更新する。
- コード変更後は以下を必ず実施する。
  1. 累積ソースゲート
  2. ユニットテスト
  3. Kotlin compile
  4. つぐレジ / つぐレジ＋ / つぐレジ CD の3 APK build
- APK完成後はCIとは独立にZIP/APKのSHA-256、integrity、manifest identity、APK Signature Scheme v2、RSA/SHA-256、content digest、証明書SHA-256を検証する。
- 実機未確認事項は確認済みと扱わない。

## v1.34からの実機繰越し

v1.34のDrive page commit checkpointについて、以下は引き続き実機未確認。

1. outer SQLite commit直後〜SharedPreferences progress前のkill
2. same-content fingerprint refreshとcheckpointのatomicity
3. empty / all-unchanged page
4. stale / run_token mismatch checkpoint破棄
5. ContentProvider起動順 `400 → 300 → 200 → 100`
6. recovery失敗時のorphan/history/bootstrap阻止
7. SharedPreferences commit false時のcheckpoint保持・再試行
8. durable republish成功後のみcheckpoint削除
9. DB version migration regression無し
10. 通常同期が壊れていないこと
11. synchronous commitによるANR/I/O影響
12. WorkManager起動阻害なし
13. zero-page状態でのkill

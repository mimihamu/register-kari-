# v0.91 Release Notes

## 概要

SCR-767「データ保全・バックアップ・復元」を、既存の共通レスポンシブ基盤へ接続しました。

販売・会計画面はv0.29で既にCompact／Medium／Expanded対応済みでしたが、後から追加されたデータ保全面は固定寸法が多く、低い横画面や大きいフォント倍率で下部操作へ到達しづらくなる余地がありました。

v0.91ではバックアップ・復元ロジックを変えず、Compact時のみ左右パネルを独立スクロール化します。

## 主な変更

- SCR-767で `rememberRegisterResponsiveMetrics()` を使用
- ヘッダー高、画面余白、カード余白、下部バー高を共通値へ統一
- Compact時の左パネル幅を360dpへ縮小
- 左パネルをCompact時のみ縦スクロール
- 右パネルをCompact時のみ縦スクロール
- Compact時のバックアップ一覧を80〜150dpへ制限
- 下部メッセージは最大2行
- 「設定へ戻る」を下部バー内へ維持
- v0.90更新診断パネルをそのまま維持

## 変更しないもの

- 売上／会計／税／支払
- 印刷キュー／再印字
- Google Drive同期
- つぐレジ CD
- バックアップ内容
- 復元前ブロッカー
- 責任者PIN
- 復元予約条件
- ロールバック安全処理

## 実機確認

ユーザー方針に合わせ、v0.91個別の実機確認は実施しません。

**800×480〜1920×1080、Android表示サイズ、フォント倍率、ソフトキーボード、実バックアップ／復元を含む確認は最終総合実機試験へ繰越します。**

ソフトウェア側では累積unit test、Kotlin compile、3アプリdebug APK build、SHA-256確認を実施します。

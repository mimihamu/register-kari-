# v0.55 Release Notes

## つぐレジ 0.55.0-dev.1

- Google Drive・同期設定から「送信運用・個別再試行」を明示
- v0.38のOutbox運用ダッシュボードを日常運用導線として統合
- FAILED 1件ごとの安全な再試行、JSONプレビュー、監査履歴を継続
- 既存のGoogleかんたん接続、Drive API直接送信、互換フォルダ送信を維持

## つぐレジ＋ 0.14.0-dev.1

- 「Google Drive売上同期検証・復旧」を「同期運用ダッシュボード」へ拡張
- 現在経路、健康状態、最終同期、経過時間、最新営業日、取込・隔離件数を表示
- WorkManagerの定期・起動時・手動同期状態を可視化
- Drive API失敗時の通常差分同期再試行を一画面化
- `gdrive://` / `content://`元ファイルを持つ隔離データの1件再試行を追加
- 個別再試行でもduplicateImportKey重複防止を継続
- 再試行成功後も元の隔離履歴を削除しない
- 全件強制再取込は日常ダッシュボードから実行しない

## つぐレジ CD

- `0.14.0-dev.1` / versionCode 7を継続
- v0.55では機能変更なし

## 安全性

- SQLite売上、POSジャーナル、Drive上JSON、同期fingerprintを自動削除しない
- OAuthアクセストークン・更新トークンを永続保存しない
- 隔離元URIを画面・診断レポートへ表示しない
- 実Google Drive、実WorkManager挙動、本番署名は実機確認が必要

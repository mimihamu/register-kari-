# v0.95 Release Notes

## 概要

v0.95では、販売中に直接使用する `SCR-120 行編集` と `SCR-121 値引・割引` を共通レスポンシブ基盤へ接続した。

従来は両画面とも固定2ペイン＋非スクロール構成で、800×480やAndroidフォント倍率を上げた環境では、入力欄・税区分・プレビュー・値引導線が下側で見切れる可能性があった。

## 変更内容

### SCR-120 行編集

- 共通レスポンシブメトリクスを使用
- 編集ペインと変更後サマリを独立縦スクロール化
- Compact時はペイン幅を比率配分
- Compact時の商品名・余白・税ボタン文字・メモ欄高さを縮小
- 通常画面の330dpサマリ幅を維持
- 値引・割引画面への導線をサマリ下部に維持

### SCR-121 値引・割引

- 共通レスポンシブメトリクスを使用
- 入力ペインと税率別プレビューを独立縦スクロール化
- Compact時はペイン幅を比率配分
- Compact時の見出し・余白・説明文を縮小
- 通常画面の390dpプレビュー幅を維持

## 非変更

以下は変更していない。

- `DiscountEngine` の商品値引・伝票値引計算
- 税計算、税区分、税シンボル、混在税設定
- 会計・支払処理
- 売上SQLite / Sales Journal / Google Drive同期
- レシート、領収書、印刷処理
- データ保護、バックアップ、復元
- つぐレジ＋、つぐレジ CD

# v1.01 Release Notes

## Google Drive 実アカウント障害時のデータ保全

実アカウント運用を想定し、OAuth再認可や一時通信障害を売上データ固有の障害と混同しないよう修正した。

### つぐレジ

- 再認可、Drive API無効、容量不足、権限不足では売上JSONを `PERMANENT_FAILED` にしない。
- 429、ネットワーク、5xx等は現在候補のみRETRYとしてバッチ停止し、後続候補へ障害を連鎖させない。
- JSON不正等のデータ固有エラーのみ恒久失敗扱いを維持。
- Easy Connectへ「再接続が必要」「API確認が必要」「容量確認が必要」「権限確認が必要」を反映。
- 接続テスト成功時にblockerを解除して同期を再要求。

### つぐレジ＋

- 個別JSON downloadの401/403を隔離せず同期停止。
- 429、ネットワーク、5xxを隔離せずWorkManager retryへ戻す。
- サイズ不正等のファイル固有エラーだけ `READ_ERROR` 隔離を維持。
- 一時障害時に途中ファイルをimport確定しない。

## 実機確認

Google Drive実アカウントでの接続、アクセス解除→再接続、通信断→復旧、つぐレジ→つぐレジ＋の実データ往復は**最終総合実機試験へ繰越**。実アカウント確認済みとはまだ断定しない。

v1.00のEPSON日本語印字も実紙再確認待ちを継続する。

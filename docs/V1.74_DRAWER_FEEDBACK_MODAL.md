# v1.74 ドロア開放エラー表示
- 担当者名エリアをエラーで上書きせず、中央ポップアップに表示する。成功時のみ短いToastを表示する（物理開放成功とは断言しない）。
- 設定・権限エラーは送信前の拒否と区別する。通信失敗など送信結果が不明な場合は「ドロアがすでに開いた可能性」を明記し、確認してから手動再操作する。
- 自動再送は禁止。プリンター状態確認の導線を付け、プリンターエラーとドロアエラーのポップアップ同時表示を避ける。
- v1.73の入出金への両替登録禁止、1.5秒連打抑止とイベント監査を維持する。
- 実機未確認: 接続断、送信後切断、プリンターエラー同時発生、成功Toastの視認、Android 15表示。

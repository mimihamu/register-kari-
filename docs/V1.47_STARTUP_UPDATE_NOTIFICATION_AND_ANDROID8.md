# v1.47 起動時の自動更新確認とAndroid 8互換修正

配信サイト: https://tenpos.jp/support2/update/tsuguregi/

## 主要変更
- つぐレジ・つぐレジ＋・つぐレジ CDの3アプリで、起動時にバックグラウンドで更新情報だけを確認。販売画面・会計画面・顧客表示へ更新ダイアログを突然重ねない。
- 成功後の次回確認は24時間後、ネットワーク失敗後は6時間後まで抑制する。オフラインでもアプリの操作・会計をブロックしない。
- 更新候補を確認できた場合、端末通知が許可されていれば低優先度の通知に表示。通知をタップすると従来のAPK検証・インストール確認画面へ移動。通知不許可でも更新画面には確認済みの候補版を表示。
- Android13以降の通知権限は更新画面から必要な場合に明示的に許可。アプリ起動時に強制的な権限ダイアログは表示しない。
- POSは既存の端末・アプリ設定「更新確認を有効」の値を使用。管理・顧客表示は更新画面の「起動時に更新を確認」を個別ON/OFF。
- Android8/9で存在しないPackageInfo.longVersionCodeを直接呼ばないよう、SDK28未満はversionCodeにフォールバック。
- Androidの「この提供元からのアプリを許可」を設定して戻ると、検証済みキャッシュAPKのインストーラーへ遷移する。許可設定後の再ダウンロード不要。インストール自体はAndroidのユーザー確認が必要。
- 更新通知は提供元情報（app/channel/package、SSLホスト、versionCode、size、SHA256、ダウンロードURL）を基本検査する。APKの本当のバイト・署名は更新画面のダウンロード後に照合する。

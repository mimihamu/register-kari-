# v1.42 システムバー安全領域の全画面点検

## 背景
v1.41ではログイン／会計の大型テンキー、および主要画面のヘッダー色・Androidステータスバーとの重なりを修正した。プリンター周辺の補助画面、顧客表示設定、データ保護などに未適用の画面が残存していた。

## v1.42修正範囲
- プリンター状態、プリンターツール、通知設定、状態分析、試験環境、プローブ、状態検証、長時間試験、長時間試験履歴
- 顧客表示設定
- データ保護
- 領収証発行履歴
- ネイティブ画面「元取引なし返品」

Compose画面は `configureRegisterSystemBars(window)` によって共通の紺色上部バーと白地の下部ナビゲーションバーを指定し、`RegisterSafeAreaV141` で `WindowInsets.safeDrawing` を適用する。Composeと異なる旧ネイティブ画面では `WindowInsetsCompat.Type.systemBars()` を `ScrollView` のpaddingに反映させる。

## 回帰防止
`V142SystemBarSafeAreaTest` で対象画面のカラー設定、システム余白、元取引なし返品の責任者承認・操作入口保持を監視する。既存の販売、会計、印刷、Drive、顧客表示同期処理は変更しない。

## 残る実機確認
- Android 13～16：上部ステータスアイコンとタイトル／ボタンが被らないこと
- 800×480、960×600、1280×800dp、高フォント倍率：画面内操作に到達でき、戻る・保存をタップできること
- 元取引なし返品：上部／下部のスクロール、責任者PIN、返品理由、取消と確定の動線
- 領収証印字、診断画面、CD接続、Drive設定の従来動作

実機の確認を完了扱いにせず、総合実機試験へ繰り越す。

# つぐレジ v0.36.0-dev.1 リリースノート

## 追加

- 外部売上ジャーナルJSONを `schemaVersion=1` の固定エンベロープへ統一
- `storeId`、`terminalId`、`businessDate` を必須化
- SHA-256ベースの `duplicateImportKey` を追加
- 売上、返品・取消、点検、Z精算を正規化した `eventType` を追加
- v0.35の種別別payloadと税内訳を内包し、後方互換を維持
- JSON Schema正本と契約ユニットテストを追加

## 維持

- v0.35 外部Outbox自動配送、サイズ・SHA-256検証、最大10回再試行
- v0.34 外部バックアップ複製
- v0.33 定期内部バックアップ
- v0.32 統合印刷キュー
- v0.31 プリンタ設定による印字幅固定

## バージョン

- つぐレジ: `0.36.0-dev.1` / versionCode `66`
- つぐレジ CD: `0.13.0-dev.6` / versionCode `6`（本版では機能変更なし、累積ビルドのみ）

## 実機未確認

外部保存先選択、URI永続権限、実取引JSON、端末ID維持、USB抜差し、容量不足、Doze、Google Driveアプリ同期、「つぐレジ＋」取込互換性は実機未確認です。

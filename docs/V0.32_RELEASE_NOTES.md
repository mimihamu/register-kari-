# つぐレジ v0.32.0-dev.1 リリースノート

## 変更概要

統合印刷キューを業務運用向けに完成させた。

- 未完了・要対応・完了・破棄済みの状態別表示
- 帳票種別、期間、試行回数、文字検索による絞り込み
- 失敗理由の分類と確認手順表示
- 手動再試行、安全印刷、責任者承認付き強制印刷
- 責任者PINと理由を必須とする印刷ジョブ破棄
- `DISCARDED`終端状態追加
- 破棄済みジョブを未印刷件数とZ精算ブロックから除外
- 再送、強制送信、破棄の監査ログ
- 印刷キュー画面の共通レスポンシブ化
- 印字幅はv0.31どおりプリンター設定だけで決定

## 実機確認が必要な項目

- 58mm／80mmの実印字
- オフライン、用紙切れ、カバー開、タイムアウト時の実エラー表示
- 送信途中切断時に自動再送せずFAILEDになること
- 安全印刷前の状態確認
- 強制印刷で責任者PINと目視確認が必須になること
- 破棄で責任者PINと理由が必須になること
- 破棄済みジョブがZ精算前の未印刷件数へ含まれないこと
- 監査ログに担当者、承認責任者、理由が表示されること
- 800×480～1920×1080、表示サイズ・フォント倍率変更時の操作到達性

実機で確認するまでは確認済みとは扱わない。

# v0.40 リリースノート

## 概要

つぐレジ＋に、取り込んだ売上ジャーナルを営業日・店舗・端末で絞り込んで確認する売上集計基盤を追加した。

## つぐレジ＋ `0.2.0-dev.1`

- 営業日・店舗・端末フィルター
- SALE加算、REVERSAL減算による純売上
- 売上総額、取消額、売上件数、取消件数、有効取引件数
- 条件を満たす場合のみ客単価を算出
- 元売上に結び付かない取消を警告
- 金額不足イベントを警告し、合計を参考値として表示
- 点検・精算・入出金・営業状態・メニュー改定を売上集計から除外
- payloadに存在する場合の支払方法別内訳
- payloadに存在する場合の税額内訳
- 新しい順50件の取引詳細とpayloadプレビュー
- SQLite DB version 2移行と集計用索引追加

## つぐレジ `0.40.0-dev.1`

- 累積開発バージョンを更新
- 売上ジャーナル契約はschema version 1を維持
- 既存POS機能の仕様変更なし

## つぐレジ CD `0.14.0-dev.1`

- 本版での機能変更なし

## 集計上の重要事項

- `SALE`だけを売上加算対象とする。
- `REVERSAL`だけを取消減算対象とする。
- `INSPECTION`、`Z_SETTLEMENT`、`CASH_MOVEMENT`等は売上へ加算しない。
- 支払・税内訳がpayloadにない取引は推測補完しない。
- 金額不足または照合不能取消がある場合、客単価を表示しない。

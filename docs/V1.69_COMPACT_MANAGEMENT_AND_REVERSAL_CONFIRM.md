# v1.69 レジ管理・返品取消の改善

- 横画面レジ管理の操作エリアが480dp以上なら3列表示（以前は720dp）。
- 高さ470dp未満は70dpタイル、それ以外は86dp。ステータス欄は売上等を優先し、補足情報を「詳細」で展開。未印刷があるときは常に表示。
- 元取引指定の返品・取消の確定ボタンは、直接記帳せず最終確認ダイアログを表示。元売上No.・処理種別・商品数・返金予定額を再確認してから実行する。
- 共通破壊的モーダルの安全ルールを適用（外側タップ／Android Backでの意図しない確定を禁止、キャンセルは可能）。
- 既存の責任者承認、返金数量検証、冪等ID、実行後の印刷処理は変更しない。
- 3アプリのversionCodeを連続増分し、標準/予備CIの期待値と名称を同期。
- 実機受入待ち：800×480dp、画面高の短い端末、返品取消実操作、決済端末返金、Android15、アプリ内配布。

# v1.36 SalesJournal / Drive 小数数量契約

正式仕様 v2.5 §4.1 / §21.1 / §22.3 に従い、Google Driveへ出力する SALE / REVERSAL 明細で小数数量を失わない。

- `quantity`: 旧 reader 互換用の legacy 整数値。
- `quantityScaled`: 1/100単位の正本数量。例 0.50 = 50。
- `quantityScale`: 2 固定。
- `quantityMode`: INTEGER / DECIMAL。
- `quantityText`: 人間可読表示。
- SALEは `sale_items.quantity_hundredths` と売上時 `quantity_mode` snapshotを使用。
- REVERSALは `reversal_items.return_quantity_hundredths` と元売上明細の `quantity_mode` snapshotを使用。
- 税率別集計は legacy Int quantity ではなく exact quantity の CartItem から再計算する。
- つぐレジ＋は exact fields が存在する場合に範囲・scale・mode整合を検証する。
- exact fieldsを持たない旧 register.sale.v2 / register.reversal.v2 は引き続き受理する。

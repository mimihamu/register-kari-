# つぐレジ v0.93.0-dev.1 リリースノート

## 概要

v0.93では、初回リリース前に残っていた主要画面の小画面・フォント倍率耐性として、ログイン画面（SCR-010）と会計完了画面（SCR-320）を既存の共通レスポンシブ基盤へ接続した。

業務フロー、税、売上保存、支払確定、印刷、領収書の処理内容は変更していない。

## ログイン画面

- 担当者一覧を縦スクロール可能にした。
- Compact時は担当者ボタン、余白、パネル間隔、PINパネル幅を縮小する。
- PINパネルもCompact時に独立スクロール可能にした。
- PIN表示とテンキーは既存Compact寸法を再利用する。
- 担当者名はCompact時に2行まで表示可能とした。
- 担当者選択、PIN入力、ログイン処理そのものは変更していない。

## 会計完了画面

通常サイズでは従来の横一列操作を維持する。

Compact時のみ以下へ変更する。

- レシート／領収書を1段目
- 印刷キュー／売上一覧を2段目
- 4つの主要操作は48dpのタップ高を確保
- `次の取引` を独立した全幅54dpの主要ボタン
- 会計完了領域を縦スクロール可能にし、高さ不足時も操作へ到達可能にする

レシート、領収書、統合印刷キュー、売上一覧、次取引への遷移先は変更していない。

CI初回実行で検出したCompose `Modifier.weight` のスコープ誤りは、外側 `Column` のスコープ内で適用する形へ修正し、表示仕様や業務コールバックは変更していない。修正後も累積unit testと3アプリKotlin compileで成立を確認する。

## 累積維持

- v0.91 データ保護画面レスポンシブ対応を維持する。
- v0.92 APKリリース整合性ゲートを維持し、生成後の3 APK実体をpackage、version、SDK、Launcher、ZIP、v2署名、証明書SHA-256まで検査する。
- 3アプリの累積unit test、Kotlin compile、debug APK buildを継続する。

## データ保護

本版はMainActivity内の表示配置変更が中心であり、以下のデータを自動削除・破壊・上書きしない。

- 売上SQLite
- Sales Journal
- Google Drive JSON
- sync fingerprint
- imported sales
- SENT Outbox
- quarantine
- sync history
- レシート再印字監査
- バックアップDB
- rollback DB

税・インボイス計算、保留伝票税状態、通常レシートと領収書の分離も変更しない。

## 実機確認

ユーザー方針により、本版単独での個別実機確認は行わず、**最終総合実機試験へ繰越**する。

最終総合実機試験では800×480〜1920×1080、Androidフォント倍率、担当者多数時のログイン、ログイン失敗時、会計完了操作、各遷移先を確認する。

CI成功・APK生成成功を実機確認済みとは扱わない。

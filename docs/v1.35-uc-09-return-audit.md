# v1.35 UC-09 返品 仕様突合・実装監査

対象: 初版完成マスター Issue #137 `UC-09 返品`

基準仕様: 詳細仕様書 v2.5 第14章、RCP-010、E-RET-001、AT-010。

## 仕様要点

- COR-005: 元取引なし返品は返品モードで負数量・負金額を作成し、責任者権限を要求する。返品理由の必須/任意を設定可能にする。
- COR-006: 売上一覧から元取引を選び、全返品または一部返品を作成する。累計返品数量は元数量を超えない。
- COR-008: 原則として元支払種別へ返金する。自動返金できない場合は責任者が返金方法を選択する。
- RCP-010: 返品票は元取引番号、処理区分、理由、担当者、負数明細、返金支払を明示し、通常売上と判別可能にする。
- E-RET-001: 返品可能数量を超える要求を拒否する。
- AT-010: 一部返品が元数量を超えず、返品レシートを発行できること。

## v1.35 実装確認

### 元売上あり返品

- `OperationsActivity.kt` の返品・取消画面から元売上を検索/直接指定可能。
- 売上一覧からの遷移では対象売上を固定して開く。
- `OperationsStore.loadReturnableLines()` が元明細と累計返品数量を再集計する。
- `OperationsStore.createReversal()` はDB書込トランザクション内で返品可能数量を再読込して `PartialReturnPolicy.select()` を再評価する。
- 累計返品数量超過を `ReturnableSaleLine.toReturnItem()` で拒否する。
- 一部返品後も残数量がある売上は再度返品できる。
- 全量返品済/取消済売上は再処理対象から除外する。
- 元税区分スナップショットを復元して返品税額を計算する。
- 元支払内訳と既返金額から返金可能残高を計算し、支払種別ごとの未返金額を超えないよう配賦する。
- 元支払内訳を復元できない場合は責任者承認下で返金方法を明示選択する。
- `reversal_transactions / reversal_items / reversal_payments` に追記保存し、元売上を物理更新/削除しない。
- DB操作キーにより同一返品要求の重複確定を拒否する。
- 返品確定後に返品票印刷キューとDrive Outboxの実行フックを起動する。

### 元取引なし返品

- レジ管理ハブから `ManualReturnActivityV135` へ遷移可能。
- REVERSAL権限と責任者PINを要求する。
- 返品理由の必須/任意設定を保持する。
- `manual_return_transactions / items / payments` 専用追記台帳を使用する。
- 数量、金額、返金支払を負数制約付きで保存する。
- 現在OPENの営業セッションへ計上する。
- X点検/Z精算、支払別集計、現金理論残高へ1回だけ反映する。
- 返品票を `REVERSAL_RECEIPT` として印刷キューへ登録する。

## 今回の差分

RCP-010の「負数明細」に対し、元売上あり返品票では行金額は負数だったが数量が正数表示だった。

`OperationDocumentRenderer.renderReversal()` を修正し、返品/取消票の数量を `-数量 × 単価` と明示する。これにより元取引なし返品票と表記方針を揃える。

追加回帰テスト `V135Uc09ReturnAuditTest` で以下を固定する。

- 返品可能残数量超過の拒否
- 複合支払の未返金残高上限
- DBトランザクション内での残数量再読込
- 永続操作キーによる重複防止
- 元売上番号、負数量、負金額、返金支払の返品票表記
- 元取引なし返品の権限/責任者承認/負数DB制約
- 返品票印刷およびDrive Outbox起動フック

## v1.35での判定

コード・自動テスト・APK検証対象としてはUC-09の初版返品コアを実装済みとする。

ただしIssue #137の完了条件に従い、以下は実機確認が終わるまで「完了」扱いにしない。

1. 元売上からの一部返品UI操作、残数量表示、再返品
2. 元数量超過時の画面エラー
3. 現金/複合支払の返金内訳と現金理論残高
4. 元取引なし返品の権限/PIN/理由設定
5. 58mm/80mm実プリンタでの返品票（負数量・負金額・元売上・理由・担当・返金支払）
6. 実決済端末を伴うカード等の返金照合
7. X点検/Z精算への一重反映
8. 既存DB更新時の返品関連テーブル互換性

外部決済端末APIによる自動返金・結果不明照会はv1.38の周辺機器/決済端末連携範囲で扱う。

# v0.31.0-dev.1 リリースノート

## 修正

- 印字幅をプリンタ設定へ一本化
- 会計時の58mm／80mm指定を削除
- 売上詳細の再印字時の幅指定を削除
- 返品・取消確定時の幅指定を削除
- X点検・Z精算履歴再印字時の幅指定を削除
- ESC/POS生成時の幅引数を削除し、プリンタ設定から自動決定
- 画面には参照中のプリンタ設定幅だけを表示

## 内部互換

- 印刷ジョブの幅列は再試行用スナップショットとして維持
- 既存印刷ジョブ、売上、返品・取消、点検・精算履歴を維持
- 税計算、権限分離、営業セッション制御は変更なし

## 検証

- v0.14～v0.31累積ユニットテスト
- Kotlinコンパイル
- つぐレジ／つぐレジ CDデバッグAPKビルド
- SHA-256算出

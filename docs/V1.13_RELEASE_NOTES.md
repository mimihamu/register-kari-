# つぐレジ v1.13.0-dev.1 リリースノート

## 変更
- STAGED済み売上ジャーナルの外部配送にworker token / leaseを追加。
- 定期送信と「今すぐ送信」が重なっても同じOutbox行を二重claimしないよう強化。
- 送信完了・失敗・権限保留・再生成のDB更新を所有token一致時だけに限定。
- lease期限切れ行は安全に再取得可能。
- active delivery lease中のSTAGED行を再キューしない。
- v1.06〜v1.12の既存JSON非破壊、SAF表示名、重複名、query不能、rename例外、確定前後TOCTOU対策を継承。

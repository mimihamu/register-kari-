# v1.36 返品・取消の小数数量対応

正式仕様 v2.5 §16.3 の数量（整数または小数点以下最大2桁）を、SCR-400/410 の返品・取消経路へ適用する。

## 実装

- 返品数量入力は文字列で保持し、`QuantityV136` で 1/100 単位へ変換する。
- `0.25` / `0.5` / `1.25` / `1.50` 等を直接入力可能にする。
- 残数量を超える入力は確定不可とする。
- `PartialReturnPolicy.selectHundredths` を exact quantity の正本とする。
- 取消は未返品時のみ、全残数量を `remainingQuantityHundredths` で選択する。
- 値引按分は `originalQuantityHundredths` と返品数量hundredthsの比率で計算する。
- 返金額・税計算は exact quantity を持つ `CartItem.quantityHundredths` から計算する。
- `OperationsStore` / `SecureOperationsCoordinator` に `createReversalHundredths` を追加する。
- 既存 `Map<Long, Int>` API は後方互換ラッパーとして残す。
- 全量返品済み判定も `quantity_hundredths` / `return_quantity_hundredths` を使用する。

## 検証

`V136FractionalReturnQuantityTest` で以下を確認する。

- 0.5返品時の数量・金額・値引按分
- 0.25返品
- 残数量超過拒否
- 1.5全量取消
- 旧Int API互換
- 本番Store/Coordinator/UIがexact quantity経路を使用

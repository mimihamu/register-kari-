# v1.37 CDP-NET-001 同一LAN制限

- つぐレジCD初版は同一LANのprivate IPv4（10/8, 172.16/12, 192.168/16）またはリンクローカルIPv4（169.254/16）、リンクローカルIPv6（fe80::/10）へのみ接続する。
- ホスト名はDNSリバインディング/意図しない外部接続によるペアリングトークン送信を防ぐため受け付けない。Loopback, CGNAT, global, multicast, ULA IPv6も現段階で禁止。
- 設定読込時と接続確立時のisConfiguredで検証。mDNS自動検出でもホストを同ポリシーで検証し、不正な候補を採用しない。
- 旧設定が外部アドレスであれば接続をブロックする。レジ／CD未接続でもレジの会計・印刷動作へは影響させない。
- CIDR以外にも同一ネットワーク内かのルート/サブネット照合やWi-Fi/AP分離等の実機検証は別途必要。将来のWSSやVPN要件は本リリースの対象外。

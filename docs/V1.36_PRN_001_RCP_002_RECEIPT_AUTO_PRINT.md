# v1.36 PRN-001 / 正式仕様 RCP-002 レシート印刷 ON/OFF

## 仕様対応

Issue #137 の #19 `PRN-001 レシート印刷ON/OFF` は、正式仕様書 v2.5 の章16では `RCP-002 レシート自動印刷` に対応する。正式仕様の `RCP-001` は58mm/80mmのロール紙選択であり、Issue側の番号とは一致しない。

## 実装

- `receiptAutoPrintEnabled` をプリンター接続の `enabled` とは独立した設定として保存する。初期値は ON。
- ON: 会計確定と同一DBトランザクション内で売上レシートの PENDING ジョブを作る。
- OFF: 売上は通常どおり確定するが、自動売上レシートジョブを作らない。
- OFFでも会計完了／売上一覧から後レシートを登録できる。後レシートは `【再発行】` 扱いとし、初回自動印刷が0回でも通常初回レシートと混同しない。
- プリンター未設定・無効でも売上確定は妨げない。ONの場合はジョブを保持し、実送信は既存の印刷キュー／Workerの `configuration.usable` 判定に従う。
- 自動ジョブも後レシートも作成時点のプリンター紙幅（58mm/80mm）をスナップショットする。
- 現金ドロアは、レシート自動発行ONでは既存どおり初回レシートへ連動する。OFFでは会計確定後にドロアコマンドだけを独立送信し、後レシートで再度開かない。ドロア送信成否は売上確定を巻き戻さない。

## 今回の境界

正式仕様の文書別設定（レシート、領収書、仮締め票、点検票、精算票ごとの部数・ヘッダ・フッタ等）は #19 のレシート自動発行だけに混在させず、各残件で累積実装する。既存の印刷再試行、印刷キュー、紙幅設定、ESC/POS送信安全策は維持する。

## 実機確認

58mm/80mmの実機印字、実プリンターでの自動発行ON/OFF、紙切れ復旧、ドロア連動は未確認。最終統合受入へ繰り越す。

# v0.41 リリースノート

## 概要

つぐレジ＋をスマートフォン縦画面向けに再構成した。

v0.40までの売上集計機能を維持したまま、売上・取引・取込を下部ナビゲーションで分離し、狭い画面でも確認しやすい1列中心の画面構成へ変更した。

## 変更内容

### つぐレジ＋

- MainActivityを`sensorPortrait`へ変更
- 横画面固定を解除し、縦方向だけを許可
- 売上・取引・取込の3画面へ分割
- 下部ナビゲーションを追加
- 起動時は売上画面を表示
- 集計条件を縦並びの全幅ボタンへ変更
- 純売上を強調カードで表示
- 売上総額、取消額、有効取引、客単価を2列カードで表示
- 支払方法別と税額内訳を縦配置へ変更
- 取引をスマホ向けカード表示へ変更
- payload詳細をカード内で展開可能
- 取込状況、隔離データ、履歴を縦1列へ変更
- 画面単位のスクロールを`LazyColumn`へ変更
- MainActivityから画面描画を`ManagementMobileScreen.kt`へ分離

### つぐレジ本体

- 管理アプリ対応に伴う累積バージョン更新のみ
- 横画面固定は変更なし
- 既存販売・会計・印刷・同期機能は変更なし

### つぐレジ CD

- 変更なし

## 維持した機能

- 売上ジャーナルJSON取込
- 重複取込防止
- duplicateImportKey再計算
- 不正データ隔離
- 営業日・店舗・端末フィルター
- SALE / REVERSAL集計
- 取消相殺
- 客単価
- 支払方法別集計
- 税額内訳
- 取引詳細
- DB version 2

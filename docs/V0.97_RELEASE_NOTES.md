# つぐレジ v0.97.0-dev.1 リリースノート

## 概要

v0.97ではSCR-400「売上一覧・検索」とSCR-410「売上詳細」のレスポンシブ対応を行う。800×480級やAndroidフォント倍率を上げた環境で、検索条件、直接表示、売上一覧、再印字、領収書、返品・取消が画面外へ見切れるリスクを低減する。

## 主な変更

- SCR-400を共通レスポンシブ基盤へ接続。
- Compact時の検索条件を複数行化し、最大190dpのスクロールフォールバックを追加。
- Compact時の売上一覧を2段情報表示へ変更。
- 通常時の検索欄150dp、直接表示210dp、従来6列一覧を維持。
- SCR-410を共通レスポンシブ基盤へ接続。
- Compact時は明細1.1 / サマリ0.9の比率ペイン。
- サマリ本文のみ縦スクロール化し、再印字・領収書・返品操作を固定操作領域へ保持。
- 通常時の右サマリ380dp、操作ボタン52dpを維持。

## 変更していない機能

- 売上検索・直接売上No.表示。
- 売上明細・税率別集計・支払表示。
- レシート再印字。
- 領収書発行。
- 返品・取消の権限・業務ロジック。
- 印刷、Google Drive、つぐレジ CD、データ保護処理。

# v1.37 CD受信安全性と小計専用表示

基準：正式仕様 v2.5 §30.5–30.7 / CDP-NET-007 / CDP-AT-02。

- 既存のSUBTOTAL modeは小計値を直接表示する。入金・お釣りを含む会計画面はSUBTOTAL中は表示しない。CARTへ戻ったら現在合計表示へ戻す。
- CDは正式 `mode=CASH_RECEIVED` など、互換 `canonicalMode` がなくても正しい状態を復元し、旧 `mode=COMPLETE` かつお釣りありの受信では従来の釣銭表示を維持する。
- schema major未知、必須JSON項目不足、異常金額などのparse失敗は、再接続の表示猶予を待たず現在の金額キャッシュを破棄して直ちにE-CD-005の切断表示へ移る。payload全文をログへ残さない。
- CD本体の表示方式・旧POS wireとの互換テストを追加。実機、Wi-Fi瞬断、表示までの2秒要件は引き続き別途要検証。

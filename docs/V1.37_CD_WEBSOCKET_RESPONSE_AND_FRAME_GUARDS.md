# CD: WebSocket応答・受信フレーム安全性 (v1.37)

- POSの正式RFC6455応答（HTTP/1.1 101、Upgrade: websocket、Connection: Upgrade、正しいSec-WebSocket-Accept）だけを受理。旧CD向けPOS通信形式は変更しない。
- サーバー→CDフレームはRFC6455準拠の非マスク、予約ビット無し、FINフレームを要求する。従来と同じtext / ping / pong / closeを処理する。
- 非対応opcode、断片化、マスク付きサーバーフレーム、制御フレームの125バイト超過、1MiB超過、64bit長の符号あふれを拒否する。JSON解析・金額表示より前に遮断して再接続する。
- 変更ファイル: `customer-display/.../CustomerDisplayWebSocketClient.kt`。単体試験: `V137CdWebSocketInboundValidationTest`。
- TLS/WSS、CD端末単位の承認・失効、本番署名、実機Wi-Fi断復旧試験は **未対応/未実施**。本対策によって解決したとは扱わない。

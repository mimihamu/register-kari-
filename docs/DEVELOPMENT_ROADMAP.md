# つぐレジ 開発ロードマップ

更新日：2026-08-02

## 基本方針

- レジ本体：つぐレジ
- 管理アプリ：つぐレジ＋
- 顧客表示アプリ：つぐレジ CD
- レジ本体は顧客表示・プリンター・クラウドが停止していても販売を継続する。
- 売上、支払、税、印刷キューはSQLiteを正本とする。
- 各工程は単体テスト、CIビルド、実機確認項目を揃えてから次へ進む。
- Draft PRは明示的な指示があるまでマージしない。

### 完了済み

- 管理用浮動ボタンの廃止と正式メニュー化

### dev.6 完了条件

- 小計、支払追加、会計確定時の短時間切断を画面へ表示しない
- 通信断が3秒以内に復旧した場合は直前画面を維持する
- 3秒を超えて復旧しない場合だけ切断画面へ切り替える
- 遅延切断処理が復旧後の画面を上書きしない
- レジ再起動後の低いsequenceを配信元インスタンスIDで受け入れる
- レジ設定画面で接続中CD台数と最新表示状態を確認できる
- CD通信イベントを商品・売上・トークンなしでリングバッファとLogcatへ記録する
- 全単体テスト、2 APKビルド、SHA-256照合を成功させる

### 実機確認

1. 販売→小計で「レジへ接続できません」を表示しない
2. 現金・カード・商品券・掛売追加時に切断画面を表示しない
3. 会計確定→完了表示で切断画面を表示しない
4. 完了→待機、次取引で切断画面を表示しない
5. CD端末の縦横回転で表示を維持する
6. 1～2秒のWi-Fi瞬断では直前画面を維持する
7. 3秒を超える通信断では切断画面へ移る
8. Wi-Fi復旧後に最新状態へ戻る
9. レジアプリ再起動後にCDを再起動せず復旧する
10. レジ設定画面の接続台数が実台数と一致する

# REGISTER（仮） v0.8

## 目的

- 担当者マスターを販売ログインへ接続する
- 担当者ごとの操作権限を販売・管理導線へ適用する
- 営業終了、Z精算、返品・取消の固定PINを廃止する
- 設定済みTCPプリンターへ印刷キューを自動送信する

## 実装範囲

- 有効な担当者だけをSCR-010へ表示
- 担当者PINのハッシュ照合
- ログイン、ログアウト、認証失敗の監査記録
- 販売、保留、売上確認、設定、管理機能の権限制御
- v0.6画面の責任者認証を担当者マスターの責任者PINへ統一
- WorkManagerによる印刷キュー定期処理と即時処理
- ネットワーク接続時のみTCP 9100へ送信
- プリンター未設定時は販売を止めず、印刷キューを保持

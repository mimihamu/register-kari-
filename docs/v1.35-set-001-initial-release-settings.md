# v1.35 SET-001 初版設定差分解消

## 目的

詳細仕様書 v2.5 の各種設定に対し、つぐレジ本体で初版に必要な設定導線・保存・検証を追加する。
既存機能の正本を二重化せず、既に強化済みの安全条件を設定画面から弱めない。

## 画面

- `SCR-690` 各種設定ホーム
- `SCR-691` 店舗基本
- `SCR-692` 販売操作
- `SCR-693` 営業日・点検精算
- `SCR-694` 端末・アプリ
- `SCR-695` 初期設定

`SCR-690` は従来の担当者・商品・プリンタ・顧客表示・データ保全・同期等の導線を維持し、左側の設定状態パネルから `SCR-691～695` へ入る。

## SCR-691 店舗基本

実装値:

- `store.code`
- `store.name`
- `store.branchName`
- `store.postalCode`
- `store.address1`
- `store.address2`
- `store.phone`
- `store.registrationNo`
- `store.currency = JPY` 固定
- `store.timeZone = Asia/Tokyo` 固定
- `store.receiptHeaderMode`
- `store.footerMessage1..5`

店舗コードは初回確定後、この画面から変更不可。
店舗名・印刷住所・電話番号・適格請求書登録番号は既存の `TaxInvoiceSettingsStore` / `InvoiceIssuerProfile` を正本として再利用する。SET-001用SharedPreferencesへ同じ正本を二重保存しない。

店舗ロゴは既存印刷資産管理との統合を要するため、今回のSharedPreferencesへBase64等で重複保持しない。

## SCR-692 販売操作

保存・検証する主な設定:

- `sale.quantityInputMode`
- `sale.mergeSameItem`
- `sale.repeatKeyEnabled`
- `sale.priceOverridePolicy`
- `sale.zeroPricePolicy`
- `sale.negativeProductPolicy`
- `sale.lineDeletePolicy`
- `sale.transactionCancelPolicy`
- 値引率上限（0.01%単位のbasis points）
- `sale.quickCashEnabled`
- `sale.tenThousandKey`
- `sale.completeScreenSeconds`
- `sale.restoreWorkCart`
- `sale.operatorSwitchInCart`
- `sale.soundLevel`

今回、`sale.mergeSameItem` は販売画面の商品登録へ実結線した。OFFの場合は同一商品・同一価格でも新しい行として追加する。

その他の設定は初版設定値として永続化・入力検証・監査を実装した。既存販売処理との安全な結線は、既存操作を壊さない範囲で個別に進める。

## SCR-693 営業日・点検精算

保存・検証:

- `check.autoNumber`
- `check.numberRange`
- `check.longOpenMinutes`
- `check.printOnHold`
- `businessDate.mode`
- `businessDate.boundaryTime`
- `settlement.autoBackup`
- `settlement.zeroItemsPrint`

### v1.35 REP-003 安全条件を優先

詳細仕様書の初期値より、v1.35で既に確定したREP-003の安全条件が厳しい項目は弱めない。

- 現金実査: 必須
- 未会計伝票: `BLOCK`
- 未印刷: 責任者の明示確認が必要
- バックアップ失敗: 責任者の明示確認が必要

したがってこれらを単純なON/OFFやALLOWへ変更するUIは追加しない。

## SCR-694 端末・アプリ

初版端末設定として以下を保存する。

- 販売中の画面維持 `device.keepScreenOn`
- キオスク運用要求 `device.kioskModeRequested`
- 操作音有効 `device.operationSoundEnabled`
- 更新確認 `app.automaticUpdateCheck`
- 容量警告しきい値 `device.storageWarningMb`

`keepScreenOn` は `MainActivity` の `FLAG_KEEP_SCREEN_ON` へ実結線した。
キオスク運用要求は設定値を保持するが、Android Lock Task / Device Owner の権限が無い端末で強制有効化したとは扱わない。

## SCR-695 初期設定

初期設定順序を画面で明示する。

1. 店舗
2. 税・インボイス
3. 商品
4. 支払
5. 担当者
6. プリンタ
7. 練習取引
8. 初期バックアップ

既存の税設定、商品設定、担当者設定、プリンタ設定、データ保全画面へ遷移する。
「設定完了」は練習取引確認と初期バックアップ確認の両方が揃うまで保存不可。

## 監査

設定保存時に `operation_audit` へ以下を記録する。

- `SETTINGS_STORE_BASIC_UPDATED`
- `SETTINGS_SALES_OPERATION_UPDATED`
- `SETTINGS_BUSINESS_SETTLEMENT_UPDATED`
- `SETTINGS_DEVICE_APP_UPDATED`
- `INITIAL_SETUP_PROGRESS_UPDATED`

## 自動試験

`V135InitialReleaseSettingsTest` で以下を固定する。

- v2.5主要既定値
- 店舗コード、登録番号、数値範囲、営業日境界時刻の検証
- `SCR-691～695` の存在と `SCR-690` からの導線
- Manifest非export・横画面
- `TaxInvoiceSettingsStore` を正本として再利用
- `sale.mergeSameItem` の販売画面結線
- `keepScreenOn` のMainActivity結線
- REP-003安全条件をSET-001が弱めないこと
- 初期設定完了条件

## 実機確認

自動試験・APK検証とは別に、最終総合実機試験で以下を確認する。

- 800x480を含む横画面でSCR-690～695が欠けず操作できる
- 店舗情報保存後のレシート表示
- 行統合ON/OFFの販売操作
- 画面維持ON/OFF
- アプリ再起動後の設定保持
- 初期設定完了条件と導線
- 設定変更監査ログ

実機未確認の項目を確認済みとは扱わない。

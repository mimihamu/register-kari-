# つぐレジ v0.26.0-dev.1

## 追加

- 未会計伝票が残っている場合のZ精算禁止
- 未印刷データを残してZ精算する場合の責任者確認
- 未印刷承認の監査ログ
- X点検権限とZ精算権限の個別設定
- 旧点検・精算権限から新権限への互換変換

## 継承

- X点検とZ精算は別ボタン・別画面
- Z精算は責任者PINと最終確認が必要
- Z精算と営業セッション終了は同一トランザクション
- Z精算確定後に自動バックアップを要求
- 同一営業日に新しい営業セッションを開始可能

## 注意

- 未会計伝票は会計または伝票取消を完了するまでZ精算できない
- 未印刷データは自動的に破棄しない
- 未印刷のまま精算した場合も印刷キューは保持する
- 実機で画面サイズ、権限移行、印刷キュー継続を確認する必要がある

# v1.48 全画面UI再監査・正式仕様v2.5未完了差分の実装

## 適用範囲

正式仕様「REGISTER（仮）_Androidレジ_詳細仕様書_v2.5」の第4章、第27章、UI-AT-01/03/06、SAL-012を基準とし、ユーザー追加要望の紺色上部バー（#173F6B）・白アイコン・冗長な補助説明の削減を照合した。

### Activity単位の再監査

- **つぐレジ本体:** Kotlin Activity名称を含む45画面。Compose画面は `configureRegisterSystemBars(window)` と `RegisterSafeAreaV141` による上/下安全領域が存在。旧ネイティブ「元取引なし返品」は WindowInsetsCompat による余白補正あり。
- **見つかった抜け:** 3アプリそれぞれの `AppDistributionUpdateActivityV146` が固定Paddingのネイティブ画面だった。色指定はあったもののステータスバーのアイコン色、Android15 edge-to-edge余白、短い横画面でのスクロールに不備。
- **つぐレジ＋:** MainActivityと7つのDrive/税マスター画面は共通のシステムバー・安全領域を使用していなかった。追加 `PlusScreenChromeV148` を全7画面に適用し、MainActivityでも紺背景+WindowInsets.safeDrawingを設定。
- **つぐレジ＋の見出し:** 取込画面の上部へ紺 #173F6B・白文字の明瞭な単一アプリ見出しを設置。更新への入口を集約。下位画面の重複「つぐレジ＋」見出しと「スマホ縦画面で…」説明を廃止。
- **つぐレジ CD:** 顧客向けの既存ダーク表示デザインは仕様上維持する。Androidのシステムバーも同系統ダークにし、SafeDrawingによりタイトルと操作領域をシステムアイコンに重ねない。更新画面だけは3アプリ共通の紺ヘッダーと余白を適用。

### 実施した変更

1. Android標準更新画面3画面をScrollView化し、WindowInsetsCompat.systemBarsの上下左右余白を適用。状態表示と更新/通知/戻る操作を保持。
2. 更新画面のステータス・ナビゲーションアイコン色を白側に固定。上部タイトルを紺背景＋白文字で統一。
3. 管理アプリの全Compose Activityへステータス・ナビゲーションバー配色と安全領域を追加。
4. 顧客表示のダークモードと画面内表示内容は変更せず、Androidバー重なりのみ改善。
5. **正式仕様 SAL-012：選択販売行**の淡青背景・「選択中」表示に赤枠(2dp)を追加。非選択行への赤枠は描画しない。販売数・金額・SQLiteの計算ロジックは変更しない。
6. `V148CrossAppUiFormalSpecTest.kt` を追加。POS全ActivityとPlus/CDのバーデザイン/安全領域、アップデータのHTTPS・APK検証の不変条件、SAL-012を累積source-unit gate化。
7. v1.48版IDへ3アプリ、2 CI workflow、独立APK identity gate、更新テストを同期。POS=171/1.34.7-dev.1、Plus=39/0.33.6-dev.1、CD=17/0.15.9-dev.1。

## 「全画面のUI統一」の判定境界

- **ソース監査済み：** Activity入口ごとのバー配色・安全領域・更新画面のスクロール・選択販売行の赤枠。
- **未完了の視覚受入：** 各画面内部の全見出し・冗長ラベル・罫線・文言を漏れなく目視確認する工程、実機フォント倍率1.3、800×480/960×600/1280×800等の表示クリップ・色コントラスト、ソフトキーボード表示、OS8〜16系のシステム領域表示。全画面のUIデザインを完成と判定しない。
- **横断モーダル契約（Issue #137 #47）:** 初期フォーカス、Back/外タップ、重要操作の取消/確定、アクセシビリティの全ダイアログ統一は依然要監査。個別の`AlertDialog`が存在することのみでは達成扱いとしない。

- **v2.5 UI-AT-06：** 色覚、文字1.3倍、ダークモードは端末依存部分が残り、実機未確認。

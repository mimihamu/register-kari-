# v1.56 全画面UI統一（設定・ネイティブ画面の継続修正）

開発ブランチ `develop/v1.36`。正式仕様 v2.5 の UI-BASE-001 / MODAL-001 を基準とする。Draft PR #140。実機での最終受入は後日一括実施。

## 今回の変更

- 元取引なし返品のネイティブ画面: システムバー安全領域を親コンテナへ適用し、紺色の上部バーをスクロール対象外へ固定。商品一覧・入力・返品確定操作は従来と同一。
- 支払設定: 固定256dpサイドバーを廃止。支払方法一覧に画面幅を配分し、保存ボタンと外部決済結果確認の注意をリストの下へ固定。支払方法詳細の開閉、表示順、決済端末アダプタの NONE 保存契約を維持。
- つぐレジ＋ 税区分マスター: 共通 `PlusTopBarV155` に統一し、左上戻るを固定。税区分一覧のみスクロールし、新規追加/改定の保存経路は維持。
- 税区分編集ダイアログ: 編集途中の画面外タップとAndroid Backによる予期しない破棄を無効化し、「キャンセル」の明示操作で閉じる。

## 検証

- `V156SettingsAndNativeReturnLayoutTest`、`V156TaxMasterNavigationTest` を追加。
- テストは操作の構造・コード契約を検査するものであり、800×480実機表示、フォント倍率1.3、IME表示、外部決済端末、返品印刷の実機確認を代替しない。
- CI / 独立APK検証は各実行結果を確認するまで成功と断定しない。

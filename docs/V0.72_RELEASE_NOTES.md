# v0.72 Release Notes

## 通常レシート再印字台帳 任意日付範囲検索

- SCR-648に開始日／終了日の任意期間入力を追加。
- 開始だけ／終了だけの片側指定に対応。
- `yyyy/MM/dd` と `yyyy-MM-dd` を受け付ける。
- 入力日付・日付順序を適用前に検証。
- 開始日は `requested_at >= ?`、終了日は翌日0:00の `requested_at < ?` でDB検索。
- 日付境界値はSQLバインド引数で処理。
- 入力エラー時は現在の検索条件・結果を維持。
- v0.71の固定期間、200件ページング、時系列索引を維持。
- 読み取り専用性と統合印刷キューへの復旧集約を維持。

実機での日付入力操作性、大量履歴、タイムゾーン/DST境界は未確認です。

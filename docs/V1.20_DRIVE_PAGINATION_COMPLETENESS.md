# v1.20 Drive pagination completeness

つぐレジ＋のGoogle Drive売上JSON同期で、一覧件数が増えても後続ファイルを取りこぼさないための完全性境界を強化する。

- `files.list` は1ページ最大1000件で取得し、`nextPageToken` がなくなるまで処理を継続する。
- 旧 `MAX_FILES = 5_000` 打切りを同期本線から撤去する。
- 1ページごとに売上JSONをimportし、import成功後にそのページのfingerprintを記録してから次ページへ進む。
- 後続ページで一時失敗した場合、前ページは確定済みのため再実行時にserver version / SHA-256で冪等skipできる。
- Drive応答の `incompleteSearch=true` は完全同期として成功扱いせず、retryableな同期不完全として失敗させる。
- page tokenの循環を検知した場合も同期不完全として再試行する。
- v1.19のserver `version` fingerprintとSHA-256フォールバックは維持する。

Version:
- つぐレジ: 150 / 1.20.0-dev.1
- つぐレジ＋: 19 / 0.19.0-dev.1
- つぐレジ CD: 7 / 0.14.0-dev.1

正式CIでは累積unit test、3アプリKotlin compile、3 APK build、APK identity・SDK・launcher・ZIP・v2署名、Artifact、SHA-256独立再計算まで確認する。

実Google Driveで5000件超を使う長時間同期、途中通信断からの再開、実端末での総合動作は最終統合実機試験へ繰り越す。

# v1.35 UC-07 小計 仕様監査・実装記録

## 対象

詳細仕様書 v2.5 の UC-07 / CTL-1012、SCR-300、および Customer Display 第30章を `develop/v1.35` の現行実装へ突合した。

## 監査結果

従来実装では、販売画面の合計計算と「小計／会計」から会計画面への遷移、空カート時のボタン無効化は実装済みだった。一方、次の差分が残っていた。

- SCR-300 の税内訳が税率別の税額のみで、税率別対象額と非課税額を十分に表示していなかった。
- 商品値引後の結果は計算へ反映されていたが、会計内訳上の値引表示が不足していた。
- 顧客表示へは小計操作時から `ACCOUNTING` を送っており、v2.5 の `SUBTOTAL` 状態が欠けていた。

客数は既存 `SaleGuestCountRuntimeV135` で 1〜999名の明示入力、保留伝票への保存、呼出時の復元、確定売上への引継ぎが実装済みであるため再実装せず回帰確認対象とした。保留伝票の空カート禁止、客数保持、仮締め票導線も既存実装を維持する。

## v1.35で閉じるPOS側範囲

- `小計／会計` は空カート時に無効、商品があれば会計画面へ遷移する。
- 販売画面・小計・会計の金額計算は `TaxEngine.calculate(items)` を正本とする。
- SCR-300 の会計内訳に、商品金額、値引、商品計、税率別対象額・税額、非課税額、合計を表示する。
- 小計押下時、つぐレジ側 WebSocket snapshot に `SUBTOTAL` を明示してから会計画面へ遷移する。
- 現行つぐレジ CDには `SUBTOTAL` enum の最小互換を追加し、未知enumによる受信失敗を防ぐ。
- v1.35でのCD表示は既存会計レイアウトへ安全にフォールバックし、専用小計画面の完成はv1.37へ送る。

## compile guard

`CustomerDisplayMode.SUBTOTAL` 追加に伴い、つぐレジ本体の顧客表示接続設定画面で使用している表示状態ラベルの exhaustive `when` にも `SUBTOTAL -> 小計` を追加した。`ACCOUNTING` は状態の意味を分離して `会計中` と表示する。これによりenum追加時のKotlin compile漏れを解消し、小計と会計を設定画面上でも区別する。

## v1.37へ持ち越すCustomer Display範囲

UC-07のPOS小計契機とは分離し、Customer Display全体の確定状態機械をv1.37で完成させる。

- 既存legacy `SALES` / `ACCOUNTING` を v2.5正本の `CART` / `PAYMENT` へ移行する。
- `CASH_RECEIVED` / `CHANGE` の確定タイミングを実装する。
- `CHANGE -> COMPLETE -> STANDBY/CART` の表示時間と遷移を仕様どおり実装する。
- v2.5の完全snapshot項目（sessionId、lineId、quantityScaled等）の不足を整理し、schema互換を保って移行する。
- CDA-120相当の専用小計表示をv1.37で完成させる。

## 実機確認

本記録はコード監査、自動テスト、CI、APK検証を対象とする。次は未確認として残す。

- 800×480実端末でのSCR-300税内訳の視認性。
- バーコード入力・数量入力から小計へ連続操作した際の実機操作感。
- 別Android端末上のつぐレジ CDへのWebSocket送信順と表示タイミング。
- v1.37で完成させるCustomer Display全状態遷移。

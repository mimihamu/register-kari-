# v1.67 レジマイナス確認画面とつぐレジ＋バー

- 返金額・数量を固定表示し、返金方法、任意理由、PINだけがスクロールする構造に変更。
- スクロール領域は画面高に合わせて100〜260dpの上限を算出。小型横画面で確認ボタンが画面外に押し出されるリスクを低減。
- 選択中の返金方法を赤枠＋淡赤背景＋赤文字で強調。
- つぐレジ＋の白い戻るボタンを透明背景、白枠、白文字に変更。
- 負数台帳、承認、二重会計防止、通常販売カート、印刷には変更を加えない。

実機未確認：小型横画面でのスクロール/返金確定、Android15のバー、現金返金/外部端末返金、OSキーボード表示時のサイズ。

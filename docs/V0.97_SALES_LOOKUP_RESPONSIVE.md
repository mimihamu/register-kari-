# v0.97 売上照会フロー レスポンシブ仕様

## 対象

- SCR-400 売上一覧・検索
- SCR-410 売上詳細

## SCR-400

Compact時は検索条件を複数行に分割し、検索欄・金額範囲・条件クリア・印刷キュー・売上No.直接表示を横幅800dp級でも操作可能な構成へ変更する。検索条件領域は最大190dpとし、フォント倍率等で収まらない場合は縦スクロールを許可する。

一覧はCompact時に、1段目へ売上No.・日時・金額、2段目へ担当者・支払・印字回数を表示する。通常時は従来の固定6列表示を維持する。

## SCR-410

Compact時は明細側1.1、サマリ側0.9の比率ペインとする。通常時は従来の右側380dpを維持する。

税・支払サマリ本文だけを縦スクロール可能にし、レシート再印字・領収書・返品取消の操作ボタンはサマリ下部の固定操作領域に残す。

## 非変更事項

売上検索条件、直接売上No.参照、売上詳細取得、税計算、レシート再印字、領収書発行、返品・取消判定などの業務ロジックは変更しない。データベースの削除・更新処理は本対応では追加しない。

## 実機確認

本版単独では実機確認済みとしない。800×480〜1920×1080およびAndroidフォント倍率変更時の表示・タッチ操作は最終総合実機試験で確認する。

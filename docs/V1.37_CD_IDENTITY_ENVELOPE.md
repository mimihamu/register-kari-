# CD identity envelope: 2026-10-20

- POS側storeId/registerTerminalIdはSharedPreferencesで生成・固定したUUIDをpayloadに含める。
- CD側displayDeviceIdはSharedPreferencesで生成・固定し、再ペアリング時も保持する。接続時ヘッダX-Tsuguregi-CD-Device-Idに指定し、POSはUUID形式のヘッダのみ受け付け、個別CDへ返すcanonical1.0スナップショットへ付与する。
- IDは識別子であり認証済み端末の証明ではない。現行トークンによる認証と区別する。CD端末単位の認証・失効/承認リストは未実装で、初版運用はレジ側のトークン再生成を用いる。
- 旧CDにはdisplayDeviceIdを返さず、他端末のdisplayDeviceIdを混ぜない。
- 実機再起動、上書きインストール、ペアリング解除→再登録後のID保持は未確認。

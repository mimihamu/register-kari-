# v1.35 TAX-004 同一税率の内外税混在 — 登録・会計ガード監査

## マスター台帳との対応

Issue #137 の `TAX-004 税混在 許可/警告/禁止` を、詳細仕様書 v2.5 の `TAX-004 同一税率の内外税混在制御` と突合する。

詳細仕様書の受入条件は次のとおり。

- `ALLOW`: 商品登録・会計を継続できる。
- `WARN`: 商品登録時に警告し、会計画面でも明示確認後にのみ確定できる。
- `DENY`: 同一税率の内税・外税混在を新たに発生させる商品登録を拒否し、取込等で既に混在している場合も会計確定できない。
- 10%内税 + 8%外税など、税率が異なる内外税の組み合わせは許可する。
- ALLOW/WARNでは同一税率の内税由来・外税由来の未丸め税額を統一計算し、税率ごとに1回だけ端数処理する。
- WARNの会計確認は、確認者・日時・対象税率を監査保存する。

コード上の既存列挙値 `MixedTaxPolicy.BLOCK` は仕様上の `DENY / 禁止` に相当する。既存保存値との互換性を維持するため、列挙値名は変更しない。

## 実装

### 商品登録時

`MixedTaxCartPolicyV135`

- 登録前カートと登録候補を比較し、新しく発生する同率混在だけを検出する。
- 既に10%混在中のカートへ8%内税を追加しただけでは再警告しない。
- 既に10%混在中でも、8%外税の追加により8%混在が新規発生すれば8%について警告・禁止する。
- 将来追加された12%等も `taxRatePercent` で動的に判定する。

`SnapshotStateList<CartItem>.plusAssign`

- 販売画面の既存 `cart += CartItem(...)` の直前に登録ガードを挿入する。
- 巨大な販売画面本体の分岐を増やさず、既存の数量加算・会計・保留伝票処理を変更しない。

`MixedTaxWarningAuditV135`

- `WARN` は商品登録時の警告履歴保存に成功した場合だけ登録を継続する。履歴保存失敗時は安全側に倒して商品を追加しない。
- `DENY` は登録拒否を `MIXED_TAX_DENY` として保存する。
- 履歴は既存 `operation_audit` と同一スキーマを使用する。

### 会計確定時

`PaymentScreenV135`

- `ALLOW`: 警告確認なしで会計可能。
- `WARN`: 混在警告カードを押して確認履歴の保存に成功するまで `会計確定` を有効化しない。
- `BLOCK`: 混在状態では `会計確定` を有効化しない。
- WARN確認履歴を保存できない場合は確認済みにせず、会計確定を禁止する。

`MixedTaxPaymentAcknowledgementV135`

- WARNの会計確認を `MIXED_TAX_PAYMENT_ACK` として `operation_audit` へ保存する。
- `operator_name` で確認者、`created_at` で確認日時、`detail` で対象税率とWARNポリシーを保存する。
- 動的な第3税率を含め、実際に同率内外税混在となっている税率のみを対象にする。

### 税計算

既存 `TaxEngine.calculate` は、商品行単位ではなく `taxRatePercent` ごとに集約する。ALLOW/WARNの同率内外税混在でも、内税由来・外税由来の未丸め税額を合算して税率単位で一度だけ端数処理する。仕様例の10%内税1,100円 + 10%外税1,000円は、10%対象税込2,200円・税抜2,000円・税200円となる。

### 設定

`TaxInvoiceSettingsActivity`

- 「許可」「警告」「禁止」の3モードを選択できる。
- 保存値は `TaxInvoiceSettingsStore` の `mixedTaxPolicy` として保持する。

つぐレジ＋側での税区分マスター編集基盤はTAX-002で実装済み。つぐレジ＋からレジ本体へ設定を配送する同期経路はv1.36の同期実装で接続するため、v1.35ではレジ本体側の実行制御・監査を完成対象とする。

## 自動テスト

既存 `MixedTaxCartPolicyV135Test` に加えて `V135Tax004MixedTaxAuditTest` で以下を固定する。

1. ALLOW / WARN / DENY(BLOCK) の登録時挙動が分離されている。
2. WARNは商品登録時の警告履歴を要求する。
3. DENYは同率混在を発生させる商品登録を拒否する。
4. 異税率の内税・外税はDENYでも許可する。
5. WARN会計確認は動的な12%等を含む実際の混在税率を抽出する。
6. WARN会計確認履歴にはイベント種別・確認者・確認日時・対象税率を保存する。
7. WARN確認履歴保存に成功するまで会計確定条件を満たさない。
8. 10%内税1,100円 + 10%外税1,000円は税率統一計算で税200円・税込2,200円になる。
9. 設定画面に許可・警告・禁止の3モードが維持される。

## 実機確認へ繰り越す項目

- ALLOWで同率混在商品を登録し、警告なしで会計できること。
- WARN Toastが販売操作中に十分視認できること。
- WARN後、会計画面で警告カードを押すまで確定できないこと。
- WARN確認後に `MIXED_TAX_PAYMENT_ACK` が確認担当者・日時・対象税率付きで残ること。
- 監査保存を失敗させた場合にWARN確認済みにならず、会計確定できないこと。
- BLOCK(DENY)で商品がカートにもSQLite保存にも追加されないこと。
- 取込等で既に同率混在している状態はBLOCK(DENY)で会計確定できないこと。
- `operation_audit` に登録時WARN/DENYと会計確認が担当者名付きで残ること。
- 設定画面でALLOW/WARN/禁止を切り替えた後の登録・会計に反映されること。
- 10%内税 + 8%外税が禁止設定でも登録・会計できること。
- 12%等の追加税率でも同率混在だけが同じ規則で制御されること。

**実機未確認のため、Issue #137 の完了件数にはまだ加算しない。**

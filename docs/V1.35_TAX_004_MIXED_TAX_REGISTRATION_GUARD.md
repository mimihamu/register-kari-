# v1.35 TAX-004 同一税率の内外税混在 — 登録時ガード

## 仕様根拠

詳細仕様書 v2.5 `TAX-004` に合わせ、同一税率の内税・外税混在を `ALLOW / WARN / DENY` で制御する。

- `ALLOW`: 商品登録を継続する。
- `WARN`: 商品登録時に警告し、警告履歴を保存したうえで登録を継続する。会計画面の既存「確認済み」操作も必須のまま維持する。
- `DENY`: 混在を新たに発生させる商品登録を拒否する。
- 10%内税 + 8%外税など、税率が異なる内外税の組み合わせは制御対象外とする。

コード上の既存列挙値 `MixedTaxPolicy.BLOCK` は、仕様上の `DENY / 禁止` に相当する。既存保存値との互換性を維持するため、この段階では列挙値名を変更しない。

## 実装

- `MixedTaxCartPolicyV135`
  - 登録前カートと登録候補を比較し、新しく発生する混在税率だけを検出する。
  - 既に10%混在中のカートへ8%内税を追加しただけでは再警告しない。
  - 既に10%混在中でも、8%外税の追加により8%混在が新規発生すれば8%について警告・禁止する。
- `SnapshotStateList<CartItem>.plusAssign`
  - 販売画面の既存 `cart += CartItem(...)` の直前に登録ガードを挿入する。
  - 巨大な販売画面本体の分岐を増やさず、既存の数量加算・会計・保留伝票処理を変更しない。
- `MixedTaxWarningAuditV135`
  - `WARN` は履歴保存に成功した場合だけ登録を継続する。履歴保存失敗時は安全側に倒して商品を追加しない。
  - `DENY` は登録拒否を `MIXED_TAX_DENY` として記録する。
  - 履歴は既存 `operation_audit` と同一スキーマを使用する。
- `MixedTaxCartBootstrapProviderV135`
  - MainActivity開始前に設定・アプリContextを初期化する。

## 既存機能との関係

会計画面にはv1.34以前から次の安全弁があるため、そのまま維持する。

- `WARN`: 混在内容を確認済みにするまで会計確定不可。
- `BLOCK`: 混在カートでは会計確定不可。
- `ALLOW`: 税率単位で統一計算し会計可能。

したがってv1.35では「登録時ガード」を追加し、会計時ガードを削除・緩和しない。

## 自動テスト

`MixedTaxCartPolicyV135Test` で以下を固定する。

1. ALLOWの同一税率混在は登録可能。
2. WARNは登録可能かつ警告履歴必須。
3. BLOCK(DENY)は登録拒否。
4. 異税率の内外税は許可。
5. 非課税は混在判定対象外。
6. 既存の別税率混在があっても、新たな混在税率を検出する。
7. 既存混在と無関係な商品追加では警告を繰り返さない。

## 実機確認へ繰り越す項目

- WARN Toastが販売操作中に十分視認できること。
- WARN後、会計画面で「確認済み」にするまで確定できないこと。
- BLOCK(DENY)で商品がカートにもSQLite保存にも追加されないこと。
- `operation_audit` にWARN/DENYが担当者名付きで残ること。
- 設定画面でALLOW/WARN/禁止を切り替えた直後の登録に反映されること。
- 10%内税 + 8%外税が禁止設定でも登録・会計できること。

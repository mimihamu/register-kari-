# v0.46 リリースノート

## 追加

- つぐレジにGoogle Drive初期設定ガイドを追加。
- インストール中APKのapplicationId、署名SHA-1、SHA-256を自動表示。
- Google Cloud設定手順、drive.fileスコープ、Android OAuthクライアント作成手順を画面内表示。
- 値のコピーボタン、Google Cloud Console起動、Googleアカウント連携画面への導線を追加。
- Google Cloud設定不足、Drive API無効、認可失敗、接続確認失敗の確認ポイントを表示。

## 維持

- v0.45のDrive API直接アップロード／差分同期。
- drive.file限定スコープ。
- アクセストークン・更新トークン非保存。
- SAF互換用フォルダ連携。
- Driveを唯一の原本としない。

## 実機未確認

- Google Cloud設定済み端末でのGoogleアカウント選択とOAuth同意。
- 表示されたSHA-1を用いたAndroid OAuthクライアントの実動作。
- Drive APIへの直接アップロードとつぐレジ＋からの取得。

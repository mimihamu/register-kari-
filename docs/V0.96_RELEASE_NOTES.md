# つぐレジ v0.96.0-dev.1 リリースノート

## 概要

v0.96では、販売中の保留伝票操作に使用する SCR-200「伝票一覧」と SCR-201「伝票分割」のレスポンシブ対応を行う。

800×480級の画面やAndroidフォント倍率を上げた環境で、名称変更・削除・呼出・結合・分割操作や分割先サマリが画面外へ見切れるリスクを低減する。

通常画面では従来の操作配置・固定幅を維持し、Compact時のみ表示密度と操作配置を変更する。

## 主な変更

### SCR-200 伝票一覧

- 共通レスポンシブ基盤へ接続。
- Compact時は伝票情報と `名称変更` / `削除` / `呼出` を別行へ分離。
- `結合` / `分割` と結合確定系操作を別行へ分離。
- Compact時の名称変更UIを全幅入力欄＋ `取消` / `保存` 行へ変更。
- Compact時の結合元案内を縦配置化。
- 通常画面の従来横並び操作を維持。

### SCR-201 伝票分割

- 共通レスポンシブ基盤へ接続。
- Compact時は分割元 `1.2` / 分割先 `0.8` の比率ペイン。
- Compact時の移動数量入力幅を108dpへ縮小。
- 分割先サマリを縦スクロール可能化。
- 通常時の分割先350dp、移動数量130dpを維持。

## 変更していない機能

- 保留伝票の安全退避・呼出処理。
- 名称変更、削除、結合、分割の業務ロジック。
- 分割数量検証。
- 行値引の数量比按分。
- 税スナップショット維持。
- 販売・会計・税計算・印刷・Google Drive・つぐレジ CD・データ保護処理。

# v0.73 Release Notes

## 通常レシート再印字台帳 安定スナップショット・カーソルページング

- SCR-648をOFFSETページングから検索時点snapshot＋keysetカーソルへ移行。
- `(requested_at, id)` を安定した時系列キーとして使用。
- snapshot作成後の新規再印字要求は現在ページへ割り込ませない。
- Nextは直前ページ末尾より古い行だけを取得し、重複表示を防止。
- Previousは画面内カーソル履歴スタックで復元。
- 5秒更新ではsnapshot・ページ位置を維持しつつ印刷状態・試行回数・エラーは現在値へ更新。
- snapshotより新しい監査行の件数を表示し、検索再実行を案内。
- v0.70のOFFSET APIは互換用に残すがSCR-648では使用しない。
- v0.72の任意期間、v0.71の期間フィルタ・索引、200件ページサイズを維持。
- 読み取り専用性と統合印刷キューへの復旧集約を維持。

新規要求追加中の実機ページング、同一ミリ秒要求、深いページ移動性能は未確認です。

# つぐレジ v0.24.0-dev.1 リリースノート

## 変更点

- Z精算の正常確定を営業セッションの終了として扱う。
- Z精算レポート保存と営業終了状態更新を同一SQLiteトランザクションで確定する。
- 同じ営業日でも、終了済みセッションとは別の営業セッションを再開始できる。
- 売上集計、Z精算の冪等性、自動バックアップの関連付けを営業セッションID単位にする。
- 旧`Z_SETTLED`状態を`CLOSED`へ移行する。
- 別操作だった営業終了ボタンを廃止する。

## 制限

- 自動バックアップはアプリ内部保存であり、Google Driveへの自動アップロードは行わない。
- 実機での同日再開、Z精算の原子的終了、自動バックアップ動作は別途確認が必要。

# v1.37 CD正式形式の接続時ネゴシエーション

正式仕様 v2.5 §30.5–30.7：schemaVersion="1.0"、mode=CART/SUBTOTAL/PAYMENT/CASH_RECEIVED/CHANGE/COMPLETE、金額は整数。

旧CD互換を壊さないため、WebSocketの接続ヘッダ `X-Tsuguregi-CD-Wire: 1.0` を新CDから送信する。POSはヘッダ値が厳密に1.0のクライアントだけへ正式形式に変換したJSONを送信し、以前のCDには既存 `schemaVersion=1`／`mode=SALES/ACCOUNTING` を残す。変換は送信時に行い、POSの最新スナップショットや他のCDに副作用を及ぼさない。

接続直後の完全SNAPSHOT、STATE_UPDATE、SNAPSHOT_REQUEST再同期の全てが同一ネゴシエーションを利用。旧orderItemsを残し、canonical itemsと数字フィールドを持つ。受信側は文字列1.0で必須金額の欠損を拒否する。端末アップデート時に同一Wi-Fi内で旧CDと新CDが混在しても安全に段階切替できる。

注意：本ヘッダは形式選択であって認証手段ではない。認証は従前のペアリングトークンによる。WebSocketは同一LAN内の平文wsでありLAN内盗聴への防御（TLS等）は未対応。実機の旧新CD混在検証、1000更新、耐久試験は別途。

# v0.59 Release Notes

## つぐレジ

- versionName: `0.59.0-dev.1`
- versionCode: `89`

## 追加内容

- レジ管理メニューに「領収書発行」導線を追加
- 売上選択式の領収書操作画面を追加
- 売上合計／発行済み／発行可能残額を表示
- 宛名／但し書き／1枚金額／枚数を入力
- 発行合計を事前表示
- 発行前の二段階確認
- `4,000円 × 30枚`等の複数枚発行
- 一部領収の残額超過を拒否
- 発行履歴表示
- 再発行の二段階確認
- 再発行履歴は追記のみで削除しない
- v0.58の統合印刷キュー・二重発行防止をそのまま利用

## データ保護

元売上、Sales Journal、Drive同期データ、SENT済みOutbox、領収書履歴を破壊的に変更しない。

## 実機未確認

実タブレット、実プリンター、58mm/80mm実紙面、複数枚連続印字、紙切れ復旧、v0.58→v0.59上書き更新は実機未確認。

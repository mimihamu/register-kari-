# つぐレジ v0.19 部分返品・返品票正式統合

## 目的

正式な管理画面へ商品単位の部分返品を接続し、販売時の価格・値引・税スナップショットを維持した返金を行う。

## 返品と取消

- 返品：商品ごとに残数量以内で返品数量を指定できる。残数量がある限り複数回実行できる。
- 取消：一部返品が一度もない売上だけを対象とし、残商品を全量反対取引にする。
- 元売上と元明細は更新・削除せず、返品取引、返品明細、反対支払を追記する。
- v0.17以前の明細なし全額反対取引は、全数量返品済みとして扱う。

## 金額・税

- 単価、任意税率、内外税、非課税、軽減税率、税記号は販売時スナップショットを使用する。
- 商品値引は元数量で按分し、最後の返品で値引端数残額を全て回収する。
- 税計算は返品対象明細を税率単位で再集計する。
- 返金支払は元支払構成へ比例配賦し、最後の支払へ端数を集約する。

## 原子性・冪等性

返品・取消は以下を単一SQLiteトランザクションで処理する。

1. OPEN営業日の再検証
2. 永続操作キー取得
3. 元売上・最新返品残数の取得
4. 返品取引・明細・反対支払の作成
5. 返品票印刷ジョブの作成
6. 操作監査
7. 操作キー確定

取消キーは `CANCEL:<売上ID>`、部分返品キーは `RETURN:<売上ID>:<要求ID>` とする。同一プロセス内は売上ID単位の実行ガードを維持する。

## 返品票

- 58mm・80mm
- 設定済み店舗名、住所、電話番号、登録番号
- 元売上番号、処理番号、担当者、承認責任者、理由
- 商品、数量、単価、販売時税記号、値引配賦
- 税率別税額、返金合計、返金支払内訳
- 登録番号が未設定の場合は架空番号を印字しない

# CDランタイム再構成時の古い非同期配信の遮断

状況: CustomerDisplayRuntime.applySettingsで新サーバー/ポーラーへ切替える場合、旧CustomerDisplayPoller.stop()のshutdownNowは実行中のDB読み込みが完了する前に戻ることがある。旧ポーラーの遅延publishや旧WebSocketのclientCount/error callbackが新サーバーの画面や診断値を上書きしうる。

対策: stopLockedの最初にruntimeGenerationを増分。新たに構成したサーバーとpollerはその世代をキャプチャし、publish/error/clientCountChangedはロック内で世代一致を確認した時だけ適用する。UIから直接呼ばれるpublish APIは既存仕様を維持。端末トークンの再発行、サーバーON/OFF、ポート変更を含む再構成に作用する。

テスト: source累積ゲートで旧ポーラーのpublish遮断、旧サーバーのclientCountとerrorの遮断を確認。実機検証: 旧サーバー接続中にトークン更新/ON-OFF/ポート変更、Wi-Fi瞬断して旧スナップショットや接続台数が復活しないか確認。

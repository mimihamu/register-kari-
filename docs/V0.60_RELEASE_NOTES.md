# v0.60 Release Notes

## つぐレジ

- versionName: `0.60.0-dev.1`
- versionCode: `90`

## 追加内容

- 領収書発行画面から「運用台帳・印刷状態」へ遷移
- 領収書No.／元売上No.／宛名／但し書き／金額を横断確認
- 初回発行と再発行の印刷イベントを区別
- 統合印刷Job ID、用紙幅、試行回数、状態、最終エラーを表示
- 再発行回数・再発行担当者・再発行イベントを表示
- 要対応／未完了／完了／再発行ありフィルター
- 領収書No.、売上No.、宛名、Job ID、エラー等の検索
- FAILED / RETRYを要対応として可視化
- 領収書履歴に対応する印刷ジョブが無い場合も要確認として可視化
- 印刷障害の再試行・破棄・強制印刷は既存統合印刷キューへ一本化
- 運用台帳は読み取り専用で、元売上・領収書履歴・再発行履歴を削除しない

## 既存仕様維持

- v0.58の領収書金額配賦・二重発行防止・原子的バッチ発行
- v0.59の発行・再発行二段階確認
- 既存統合印刷キューの安全再試行・責任者承認・監査履歴
- 58mm／80mm印刷設定
- Google Drive同期・Outbox・Sales Journal

## 実機未確認

実タブレットの台帳レイアウト、実プリンター障害時の状態遷移、紙切れ・通信断・送信結果不明からの復旧導線、v0.59→v0.60上書き更新は実機未確認。

# v1.39 Google Driveフォルダ中心の導線・商品ボタン自動拡大

## Google Drive同期
- つぐレジ：同期画面の主操作「Google Driveの送信フォルダを選択」は従来から実装済みのAndroid SAF `OutboxDeliverySettingsActivity`を開く。フォルダ選択・永続書込権限・JSON送信・送信履歴は旧実装を再利用。設定保存や手動送信キュー登録はフォルダ送信スケジューラのみを呼ぶ。
- つぐレジ＋：既存の「フォルダ登録」「差分取込」を主操作にし、Google OAuth方式の入口を詳細メニューへ移動。選択済みURI・権限・取込履歴は変えない。
- Google OAuth方式とDrive APIは利用者の明示選択用に残し、**既にAPI方式を利用していた場合の定期タスクを黙って消さない**。移行時に二重送信を避けるためには設定を見直す必要がある。SQLite売上、同期履歴、既存バックアップは保持。
- Android SAFはGoogle Driveアプリ側のDocumentsProviderが機能を提供する場合のみ使用できる。Driveに「置くだけ」でも端末のファイル選択、権限維持、他端末反映にはGoogle Driveアプリの機能と回線が必要。Google Driveフォルダは別端末で同じGoogleアカウントから選択する。POS送信先内のサブフォルダをPlusが再帰読込できるか要実機検証。
- Google Cloud OAuth設定は通常のSAF経路では不要。ただしDrive APIを直接使う場合は引き続き必要。

## 販売画面
- `MainActivity.kt` の3列×8行・スロット番号1..24を維持。画面ごとの実パネル幅・高さを `BoxWithConstraints` から取得し、ボタンの高さを56dp以上116dp以下に自動調整。
- 商品エリアが低い場合は商品エリアのみ縦スクロール。空スロットも同じサイズを確保。
- セル幅とフォント倍率から文字サイズを11..16spに調整。ボタン内余白を小さくして商品名・金額を表示。
- ページ送りの操作領域を48dp高へ拡大。
- 既存の商品登録、販売・税・支払・会計ロジック、SQLiteは無変更。

## 検証保留
- 異なるAndroidディスプレイ・フォント倍率での商品配置、タップ・ページ送り
- POS側SAFフォルダへのJSON書込みとPlus側再帰読込（機種/Driveアプリ実機）
- 既存Drive API登録がある端末での経路移行による二重同期回避

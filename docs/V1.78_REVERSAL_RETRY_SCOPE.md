# v1.78 元売上返品・取消の再実行安全性

- 元売上に紐づく操作IDは、選択中の売上IDが変わったときだけ再発行。同じ売上を検索・一覧から再タップしてもIDと数量入力を保持する。
- 「別売上を検索」で一時的に選択解除しても元の操作IDとの紐づけを保持。同じ売上を選び直した場合は復元、実際に別の売上を選んだ場合のみ新規ID。
- Activity再生成後、直前に選択していた元売上ID、返品数量入力、返品／取消種別、理由、確定操作IDを保持。PINはセキュリティのため保持しない。
- 元売上選択からの通常経路（deep linkなし）でも、Activity再生成直後に対象売上と返品可能明細を再読み込み。取得不能なら選択解除し検索へ誘導してfail closed。
- DBの返品残量チェック、権限、冪等判定、取引台帳、印刷、一時的な通信失敗の扱いは既存のまま。

検証：`V178ReversalRetryScopeTest`、既存のv1.69/v1.75/v1.76/v1.77と累積テスト、3 APKのCI確認。
実機未確認：Android再生成／プロセスkill／返品がDB確定した直後の応答喪失／同じ売上の連続再タップと商品別の小数返品。

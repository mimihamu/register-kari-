# つぐレジ v0.89.0-dev.1 リリースノート

## 概要

v0.89では、APK上書き更新の成功判定を「MainActivityが表示できた」だけで終わらせず、**現在SQLiteの健全性確認まで通過した場合だけ更新成功版を確定**するよう強化した。

## 変更内容

- `AppUpdateTransitionBootstrapProviderV089` を追加
- v0.88 ProviderをManifest登録から外し、v0.89 Providerへ置換
- v0.88更新台帳SharedPreferencesをそのまま継承
- MainActivity RESUMED後に読み取り専用DB健全性チェックを実行
- `PRAGMA integrity_check`
- `PRAGMA foreign_key_check`
- 必須テーブル確認
- 主要必須列確認
- DB健全性NGでは更新成功版を確定しない
- DB健全性NGでは不健全DBへ監査ログを書かない
- NG証跡は別SharedPreferencesへ同期保存
- 次回起動で再検査
- NG→OK回復時に `APP_UPDATE_STARTUP_DB_HEALTH_RECOVERED` を監査追記
- 成功監査detailへDB health / user_version / integrity / FK件数を追加

## データ保護

健全性チェックは読み取り専用で、業務データの更新・削除、DDL、ロールバックDB削除を行わない。

## バージョン

- つぐレジ: `0.89.0-dev.1` / versionCode `119`
- つぐレジ＋: `0.14.0-dev.1` / versionCode `14`（変更なし）
- つぐレジ CD: `0.14.0-dev.1` / versionCode `7`（変更なし）

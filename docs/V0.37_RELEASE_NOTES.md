# つぐレジ v0.37.0-dev.1 リリースノート

## つぐレジ CD表示設定

つぐレジ側で背景、ロゴ、文字倍率、表示行数、行間、取消商品、税記号、
待機メッセージを設定し、接続中のつぐレジ CDへ自動同期する。

## 表示・互換性

- 既存の待機、販売、会計、会計完了画面を維持
- 表示行数を超える場合は最新商品を含む範囲を表示
- 取消商品を非表示にできる
- `内`、`外`、`内※`、`外※`、`非`の税記号を表示できる
- 旧schemaVersion 1を維持し、追加フィールドは任意として後方互換
- 旧形式受信時は従来の紺背景・標準文字・8行表示へフォールバック

## 状態復元・再接続

- 最新受信状態をCD端末内へ保存
- 30分以内の保存状態をプロセス再生成後に復元
- 通信断中は保存済み金額を表示しない
- 既存の3秒瞬断抑止、再接続、Heartbeat、レジ再起動復旧を維持

## バージョン

- つぐレジ: `0.37.0-dev.1` / versionCode `67`
- つぐレジ CD: `0.14.0-dev.1` / versionCode `7`

## 実機未確認

表示デザイン、実端末間同期、Wi-Fi切断復旧、プロセス強制終了後の状態復元、
端末回転、Doze・メーカー固有省電力制御は実機確認が必要。

# v0.74.0-dev.1 リリースノート

## 変更点

- SCR-648「通常レシート再印字 運用台帳」の新着件数を現在の適用済み検索条件に一致する要求だけへ限定
- 状態・期間・任意期間・検索語を新着COUNTにも適用
- snapshotより新しい行の判定を `(requested_at, id)` 複合条件で維持
- 「条件一致の新着 N件」表示
- 「新着を反映」操作を追加
- 新着反映時は入力中の未適用値ではなく `appliedCriteria` をそのまま再適用
- snapshot再取得時は1ページ目へ戻り、カーソル履歴をリセット
- v0.73のstable snapshot / keyset paging / 同一ミリ秒id tie-breakを維持
- 読み取り専用。監査履歴・売上・印刷jobの更新・削除は追加しない

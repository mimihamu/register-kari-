# v0.34 リリースノート

## 追加

- Androidフォルダ選択による外部自動保存先設定

- 保存先URIの永続権限管理
- 新規内部バックアップ完成後の即時外部保存要求
- 15分周期の未保存バックアップ再走査
- 従量課金でないネットワーク接続時のみ実行する設定
- `.partial`書込と正式名確定
- 保存先ごとの重複防止受領記録
- 外部保存状態、待ち件数、最終成功、最終エラー表示
- 失敗・保存先権限失効通知
- 外部自動保存監査ログ
- v0.34回帰テスト

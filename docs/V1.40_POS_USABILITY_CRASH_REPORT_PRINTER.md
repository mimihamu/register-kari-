# v1.40 販売画面・管理導線の実用性改善

## 操作画面
1. テンキーの横方向割当を小画面42%、中39%、広36%に拡大。数字キーの販売画面・会計画面での優先高さ72dp、上限96dp。ログイン用PINテンキーも小画面56dpへ拡大。高さ不足ではテンキー領域またはPIN入力欄をスクロール。ほかの従来画面の48dp最小値は維持。販売の数量変更・取消・会計処理ロジックは触れない。
2. `PrinterHealthBanner` を販売画面から外し、`ERROR`時に `AlertDialog` を表示。ポップアップを閉じる/診断画面への移動が可能。状態確認ポーリングと管理者向け継続異常通知は維持。未設定・警告は自動ポップアップしない。表示でスクリーン高さが変わらない。ポップアップは同じエラー表示が続く間、閉じるたび再表示しない。
3. レジ管理トップの旧 `その他の管理機能` を廃止。「当日売上」「入出金」「返品・取消」を直接選択可能に。内部の従来`OperationsActivity`の各画面を再利用し、`OperationsLegacyRouteV140` の明示的な行き先/起動時権限検査で不正遷移を阻止。戻ると管理トップに戻る。従来の管理画面は既存機能との互換用に残す。
4. `CrashReportUiV138` の画面右下フローティングボタン生成を廃止し、クラッシュレポートの保存・秘匿化・共有動作は維持。責任者PINで認証後の各種設定画面に、保留中の障害レポートがある場合のみ共有入口を出す。

## 注意
- 端末でのフォント倍率、キーボード・プリンター状態ダイアログ、管理画面戻り、各操作のタップ試験は未実施。
- 自動ポップアップはエラー時の表示であり、印刷失敗ジョブを勝手に再送する機能ではない。紙確認・再印刷は統合印刷キューの既存安全フローを使う。
- 画像によるUI実機確認を実施していないため、全端末の視認性を保証しない。

## 2026-10-24 追加修正（HEAD be049258に対応）
- 販売／会計テンキーの寸法の回帰テストは最新の72dp／上限96dpに追随させた。小画面でスクロールが必要なケースと、通常寸法の優先キーを別々に検査する。
- レジ管理画面のヘッダーから「各種設定」を直接起動可能にし、販売画面に戻って別の入口を探す操作をなくした。各種設定側の責任者PIN認証は既存どおり必要。
- レジ管理の「営業開始・状態」は営業開始専用の `BUSINESS_START` 権限で有効化する。Z精算と営業開始は独立権限のため、Z精算権限の有無で誤判定しない。
- 当日売上・入出金・返品取消はレジ管理から直接起動し、元の業務処理／責任者承認は流用する。旧「その他」中継メニューは復活させない。
- 補足テキストがない管理タイルには無用な空欄を描画せず、利用不可の場合のみ「権限なし」を表示する。
- 実機の小型画面・文字拡大・実プリンタの異常／復旧についての確認は引き続き未実施。

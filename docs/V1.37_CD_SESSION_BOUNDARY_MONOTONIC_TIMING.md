# v1.37 CDセッション境界・表示時間基準の修正

基準：正式仕様 v2.5 §30.5–30.7 / CDP-NET-003/004 / CDP-AT-03,06。

- `sessionId` は会計取引単位。1件の会計確定後、CHANGE（釣銭表示）→COMPLETE（お礼表示）へ進む間は同一sessionIdを維持し、sequenceを連番更新する。旧コードはどちらもenum COMPLETEだったため、COMPLETE→COMPLETEを新取引として扱う問題があった。
- 別の売上（異なるtransactionId）に切り替わった場合はsessionを更新する。完了から新規CARTへの遷移、COMPLETE→STANDBY、STANDBY→新規CARTも新セッション。
- 同一カート内のCART→SUBTOTAL→PAYMENT→COMPLETEはひとつの表示セッション。
- CHANGE・COMPLETEの時間計測のみ単調時間 `SystemClock.elapsedRealtime()` を使用する。端末の日時変更・NTP補正で釣銭表示が長引いたり直ちに終了したりする危険を避ける。送信日時 `sentAtMillis` は実時刻のままとする。
- 行ID仕様、プロトコル互換を維持。自動ユニットテストはセッション遷移と単調時間の使用を確認。
- 実機のCHANGE秒数・45秒切断・瞬断復帰・多数会計の受入試験は未実施。

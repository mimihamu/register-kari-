# v0.85 Release Notes

## つぐレジ 0.85.0-dev.1

初版完成前のデータ保全・上書き更新対策として、復元・更新後の主要後付けSQLiteスキーマをUI起動前に先行整備する仕組みを追加した。

### 変更

- `DatabaseStartupSchemaBootstrapV085` を追加
- `CatalogBootstrapProvider` の商品同期より前に起動前スキーマ整備を実行
- `DATABASE_VERSION=4` の既存DBでも `onUpgrade()` の有無に依存せず毎起動で冪等確認
- OperationsStoreを先行初期化し、営業日・返品取消・点検精算・監査・帳票印刷系スキーマを準備
- ReceiptVoucherStoreを先行初期化し、領収書発行・再発行台帳を準備
- SaleReceiptReprintAuditStoreを先行初期化し、通常レシート再印字監査を準備
- SaleCommitIdempotency / BusinessSession / SettlementSnapshot / DocumentPrintSafetyを起動前ensure
- 主要業務テーブル・主要列の存在を最終確認
- 不足スキーマが解消できない場合は部分運用へ進まずfail-closed
- v0.85専用回帰テストと仕様資料を追加

### データ保護

v0.85の新規ブートストラップは、既存の売上・保留・商品・領収書・再印字履歴・同期履歴等を削除・上書きしない。

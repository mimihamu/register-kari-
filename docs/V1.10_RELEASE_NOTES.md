# つぐレジ v1.10.0-dev.1 Release Notes

## 変更概要

SAF / DocumentsProviderへの外部JSON送信で、作成・rename後の表示名確認queryまたはサイズ確認queryが `null` を返した場合に、未検証の書込み結果を成功扱いしないようにした。

## 主な変更

- `OutboxProviderMetadataSafetyV110` 追加。
- `COLUMN_DISPLAY_NAME` query nullをretryableな一時障害として扱う。
- `COLUMN_SIZE` query nullをretryableな一時障害として扱う。
- 表示名確認不能時は、アプリ自身が直前に作成／renameした未検証オブジェクトのみcleanupして再試行する。
- 既存確定JSONの非破壊方針を維持。
- v1.06〜v1.09のSAF安全化を維持。

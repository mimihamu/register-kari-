# つぐレジ v0.18 営業日セッション統合

## 目的

v0.11.1で導入済みの`business_sessions`、`business_session_id`、`business_date`を、現在の正式なレジ管理画面へ再接続する。
暦日0時区切りの集計を廃止し、深夜営業でも営業開始からZ精算・営業終了までを同一営業日として扱う。

## 営業日の状態遷移

1. 営業開始前
2. `OPEN`：販売、入出金、返品・取消、X点検、Z精算が可能
3. `Z_SETTLED`：販売、入出金、返品・取消、再Z精算を禁止。責任者承認で営業終了のみ可能
4. `CLOSED`：終了済み。次の営業日を開始可能

## 集計基準

- 売上：`sales.business_session_id`
- 返品・取消：`reversal_transactions.business_session_id`
- 入出金：`cash_movements.business_session_id`
- 支払：売上・返品の営業セッションへ結合
- X点検・Z精算：`settlement_reports.business_session_id`
- 現金理論残高：開始釣銭 + 現金売上 - 現金返金 + 入金 - 出金

## 書込時検証

- UI表示だけでなくSQLiteトランザクション内で最新営業状態を再取得する。
- Z精算と営業終了の間、販売・入出金・返品取消を拒否する。
- Z精算は営業日単位の永続操作キーを維持する。
- 営業開始・終了は同一プロセス内の連打ガードを使用する。
- 営業終了は有効な責任者PINを処理直前に再検証する。

## 既存データ

`BusinessSessionSchema.ensure()`を使用し、既存の売上、入出金、返品取消、精算へ営業セッション列を追加する。
既存データは、保存済み`business_date`と一致する営業セッションを最優先で関連付け、営業日がないデータのみ開始・終了時刻範囲から補完する。営業セッションに安全に対応付けられないデータは推測で別営業日へ混入させない。

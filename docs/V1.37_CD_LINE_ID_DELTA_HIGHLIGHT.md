# v1.37 CD行単位更新・重複商品識別
基準：正式仕様 v2.5 §30.6–30.7（latestLineId、同一商品行統合時の最後の登録行強調）、CDP-AT-01。

- 変更検知は商品IDによる一括マップ（duplicate productIdで上書き）を廃止。保存済みCartItem.lineIdを優先し、個別行の数量・値引・価格・メモ・税属性変化を検出してlatestLineIdを通知する。
- 同じ商品IDの2行（異なる価格や税条件）でも変更した行だけを強調。商品登録・数量変更・取消の表示には行IDを用いる。
- fingerprintに行ID・税シンボル・軽減税等の属性を含め、複数行の並び替えでも新しい一覧を送信する。文字列フィールドは長さ接頭辞方式で区切り文字入りの商品名・メモも衝突しない。
- 行IDが空の旧レコードのみ暫定 `legacy-line-{行番号}` で表示。行を削除・並び替えた後まで永続的に安定する識別子ではないので、旧行ID移行は引き続き残件。
- Product IDのみ指定する既存APIのlatestProductId後方互換は維持。実機における2秒表示/1000更新/長時間安定性は未確認。

# つぐレジ v1.15.0-dev.1 リリースノート

## バックエンド／データまとめ強化
- 売上印刷キューに原子的claimを追加。
- 売上印刷完了を冪等化し、`print_count`の二重加算を防止。
- 業務帳票印刷を状態・試行回数CASへ統一し、送信結果不明時の自動再送を停止。
- 500件一覧経由のジョブ特定を廃止し、主キー直接取得へ変更。
- 返品・取消をトランザクション内スナップショット再検証で同時実行から保護。
- 入出金・返品を営業セッションOPEN再確認でZ精算との競合から保護。
- 精算集計を精算保存トランザクション内で再生成し、Z締め直前の売上・返品・入出金を取りこぼさない。
- v1.14までのOutbox外部配送lease／Drive JSON安全策を維持。

## 変更しないもの

- つぐレジ＋ versionCode 15 / 0.15.0-dev.1。

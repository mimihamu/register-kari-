# v1.37 CD旧カート行IDの永続補完

- 旧`cart_items.line_id`が空または同一カート内で重複していた場合、`loadCart()`はSQLiteの原子トランザクション内で読み込み、対象行の`line_id`**だけ**UUIDに更新する。`line_no`で元の行へ対応し、価格・値引・数量・税snapshotは更新しない。
- `saveCart`、訂正処理、保留登録も保存時に重複や未採番IDを補完する。補完済みの非空IDは次回以降変更しない。
- 自動テストはIDの重複解消、正常ID保持、数量訂正後のID不変、原データ不変を検証。
- 旧`held_ticket_items`の過去レコードでIDが空のものは、保留からカートへ復元後の`saveCart`で永続補完するため、保留DB自体の事前一括書換えは行わない。
- バックアップ/復元、実機カート混在、長時間運転の試験は未実施。

# v1.54 ダイアログ操作統一（MODAL-001 第1期）

正式仕様「REGISTER（仮） Androidレジ 詳細仕様書 v2.5」／操作確定・不可逆処理の安全性。作業ブランチ `develop/v1.36`、Draft PR #140。

## 実装済み

- `RegisterModalV154.kt` を共通導入。全ダイアログの背景は白、タイトルは共通紺、本文濃色。48dp以上の「キャンセル／閉じる」と主要実行ボタンを一貫したスタイルに。
- `destructive = true` の場合、Android Backキーとダイアログ外タップで暗黙に閉じない。明示的な「キャンセル」だけで取り消す。不可逆操作ボタンを初期フォーカスしない。
- 主要実行は共通紺、危険な確定は赤 `#B42318`。Z精算最終確認は責任者承認・事前チェックを従来どおり満たした場合にのみ実行可能。
- Z精算の新旧画面（`SettlementActivityV030`、`OperationsActivity`）、販売画面のプリンターエラー、商品検索、未登録バーコードのComposeダイアログ計5呼び出しを共通化。
- 商品検索は「キャンセル／コード一致を登録」。未登録バーコードは「キャンセル／仮商品」＋権限がある場合の「商品登録」。プリンターエラーは「閉じる／状態を確認」。取消表示を安全かつ予測しやすい操作順に整えた。
- `V154ModalUiContractTest.kt` を追加し、モーダル終了方法・ボタンサイズ・色・承認条件・販売画面導線が維持されることを静的に検査。

## 変更しない安全処理

精算対象営業日、実査額、過不足、未印刷・バックアップ失敗の責任者確認、返品・伝票の台帳、印刷ジョブのSENDING不確定送信と理由付き再印刷の実装は変更しない。UI確認で権限を迂回しない。

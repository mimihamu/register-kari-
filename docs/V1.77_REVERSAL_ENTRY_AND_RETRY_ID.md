# v1.77 返品・取消：元売上選択導線と操作IDの再生成防止

## 変更点
- 元売上指定で開く返品・取消画面に残っていた `LaunchedEffect(initialSaleId)` 内の操作ID再発行を撤去。 `rememberSaveable(initialSaleId)` の同一IDを維持し、再生成直後の意図しない新規実行を抑止する。
- 指定売上がない／全量返品済み／返品可能明細がない場合は、3ステップの最初「元売上」に戻す。エラーを出して商品欄に取り残さない。
- 「元取引なし → レジマイナス」を最初の元売上検索パネル上部へ移動。商品パネルで元売上未選択なら「元売上を選ぶ」で検索へ戻す。
- 既存の返品・取消のDB処理、担当者・責任者権限、冪等記録、税・印字、元取引なしレジマイナス独立台帳は変更しない。
- v1.76までの狭幅3ステップ、文字拡大、確定ボタン固定は維持。

## テスト
- `V177ReversalEntryAndDeepLinkRetryTest` で元売上指定時のUUID保存、無効リンクで検索ステップへ戻す処理、CTAの重複防止を検証。
- 開発版APKの3アプリversionCodeを次版へ更新後、累積テストと3 APKビルドをCI確認。
- 実機受入未実施（Android15 / 800×480 / キーボード / 元売上指定 / 実返金 / 実プリンタ）。

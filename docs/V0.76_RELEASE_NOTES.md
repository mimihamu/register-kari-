# v0.76.0-dev.1 リリースノート

## 変更点

- SCR-510「営業セッション売上簡易確認」から同じ営業セッションの売上明細へ直接遷移
- `SalesHistoryCriteria.businessSessionId` を追加
- `business_session_id = ?` をSQLiteバインド条件として追加
- 営業日＋営業セッションNo.を固定したSCR-620 context
- 同一営業日に複数セッションがあっても別セッションを混在させない
- 旧DBにbusiness_session_id列がない場合はfail-closed
- 固定中は検索条件変更・売上No.直接指定を禁止
- 「固定解除・同日全売上を表示」の明示操作でのみsession固定を解除
- VIEW_SALESを遷移元・遷移先で維持
- sales/business_date/business_session_idの更新・backfillは行わない

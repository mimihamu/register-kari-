# v0.41 つぐレジ＋ スマホ縦画面仕様

## 1. 目的

つぐレジ＋は、店舗責任者や管理者がスマートフォンで売上状況を確認する管理アプリとして運用する。

v0.40までの画面は横画面を前提とした複数列レイアウトだったため、スマートフォン縦画面では文字・ボタン・取引詳細が狭くなる問題があった。

v0.41では、つぐレジ＋だけをスマホ縦画面向けに再構成する。

- つぐレジ本体：従来どおり横画面固定
- つぐレジ CD：従来仕様を維持
- つぐレジ＋：縦方向を基本とする

## 2. 画面方向

`management-app/src/main/AndroidManifest.xml`のMainActivityを次の設定とする。

```xml
android:screenOrientation="sensorPortrait"
```

`sensorPortrait`により、通常の縦向きと上下反転した縦向きの両方を許可し、横向きには切り替えない。

固定方向をつぐレジ本体と共有しない。管理アプリだけに適用する。

## 3. 画面構成

下部ナビゲーションで次の3画面を切り替える。

1. 売上
2. 取引
3. 取込

アプリ起動時は「売上」を表示する。

### 3.1 共通ヘッダー

縦画面上部に次を表示する。

- アプリ名：つぐレジ＋
- 説明：スマホ縦画面で売上確認・取引確認・JSON取込
- JSON取込ボタン
- 更新ボタン
- 取込結果・エラーメッセージ

JSON取込と更新は横2分割とし、片手操作でも押しやすい幅を確保する。

### 3.2 売上画面

表示順は次のとおり。

1. 売上概要タイトル
2. 集計条件
3. 純売上
4. 売上総額・取消額
5. 有効取引・客単価
6. 確認事項
7. 支払方法別
8. 税額内訳
9. 集計データの状態

集計条件は、横並びではなく縦に配置する。

- 営業日
- 店舗
- 端末

各条件ボタンは画面幅いっぱいに表示する。

純売上は最も重要な数値として、専用の強調カードへ表示する。

### 3.3 取引画面

現在の売上集計条件に該当するイベントを、新しい順に表示する。

各取引カードには次を表示する。

- イベント種別
- 発生日時
- 金額または集計対象外表示
- 営業日
- 店舗ID
- 端末ID
- 取引ID
- 詳細表示ボタン

詳細を開くと次を表示する。

- payload schema
- 取込元ファイル名
- 元売上ID（取消時に存在する場合）
- payload JSONプレビュー

画面表示上限は新しい順50件とする。

payloadプレビューは先頭1,200文字までとする。

### 3.4 取込画面

表示順は次のとおり。

1. 取込済件数
2. 隔離件数
3. 店舗数
4. 最終取込時刻
5. 直前取込結果
6. イベント別取込件数
7. 最近の取込
8. 隔離データ
9. 取込履歴

v0.39で実装した重複防止、不正データ隔離、取込履歴は維持する。

## 4. レイアウト方針

### 4.1 縦1列を基本とする

支払方法別と税額内訳、最近の取込と隔離データなどを横並びにしない。

画面幅の狭いスマートフォンでも内容が途中で切れないよう、縦方向に積み上げる。

### 4.2 数値カード

純売上以外の数値は、2列の小型カードで表示する。

- 売上総額 / 取消額
- 有効取引 / 客単価
- 取込済 / 隔離
- 店舗数 / 最終取込

長い値は省略表示し、カード幅を超えてレイアウトを壊さない。

### 4.3 リスト

大きな画面全体を`verticalScroll`で包まず、画面単位で`LazyColumn`を使用する。

これにより、取引件数や履歴が増えた場合の描画負荷を抑える。

## 5. 既存機能との互換性

次のロジックは変更しない。

- 売上ジャーナル固定契約
- duplicateImportKey再計算・重複防止
- 不正JSON隔離
- SALE加算
- REVERSAL減算
- 元売上照合
- 非売上イベント除外
- 支払方法別・税額内訳
- DB version 2

MainActivityはデータ取得と状態管理を担当し、画面描画を`ManagementMobileScreen.kt`へ分離する。

## 7. テスト

`V041ManagementPortraitMobileTest`で次を固定する。

- つぐレジ＋が`sensorPortrait`
- つぐレジ＋に`landscape`が残っていない
- つぐレジ本体は`landscape`を維持
- 下部ナビゲーションが売上・取引・取込の3画面
- 起動時画面が売上
- `LazyColumn`を使用
- JSON取込導線を維持

- payloadプレビュー1,200文字
- バージョン番号
- CI成果物名

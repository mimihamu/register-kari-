# v0.44 リリースノート

## バージョン

- つぐレジ：`0.44.0-dev.1` / versionCode `74`
- つぐレジ＋：`0.6.0-dev.1` / versionCode `6`
- つぐレジ CD：`0.14.0-dev.1` / versionCode `7`

## 概要

Google Drive連携を、Google Driveアプリからフォルダを選ぶ方式だけではなく、Googleアカウントを明示的に登録してDrive APIを認可する方式へ拡張しました。

v0.43のSAFフォルダ方式は、USB・端末フォルダ・既存運用のための互換機能として維持します。

## 追加機能

### つぐレジ

- Googleアカウント連携画面
- 端末上のGoogleアカウント選択
- `drive.file`権限要求
- Google Drive API `about.get`接続確認
- 接続アカウントのメールアドレス・表示名表示
- 別アカウントへの変更
- 接続再確認
- Google側アクセス権限の取消
- 同期設定画面からアカウント連携へ遷移
- 従来のフォルダ配送を「互換用フォルダ送信設定」として維持

### つぐレジ＋

- スマートフォン縦画面のGoogleアカウント連携画面
- 端末上のGoogleアカウント選択
- `drive.file`権限要求
- Google Drive API `about.get`接続確認
- 接続アカウントのメールアドレス・表示名表示
- 別アカウントへの変更
- 接続再確認
- Google側アクセス権限の取消
- メイン画面からアカウント連携へ遷移
- v0.43のフォルダ診断・差分取込を互換機能として維持

## セキュリティ

端末へ保存する情報：

- メールアドレス
- 表示名
- Drive permissionId
- 最終確認日時

保存しない情報：

- Googleアカウントのパスワード
- アクセストークン
- 更新トークン
- OAuthクライアントシークレット

Drive全体の無制限スコープではなく、限定スコープ`drive.file`を使用します。

## エラー対応

- Google CloudのAndroid OAuthクライアント未登録
- applicationId・署名SHA-1不一致
- Google Drive API未有効
- アカウント認可失敗
- 利用者による認可キャンセル
- Drive API接続確認失敗
- 連携解除結果を確認できない場合

## 開発設定

Google Cloudで次が必要です。

- Google Drive APIの有効化
- OAuth同意画面
- テストユーザー登録
- つぐレジ開発版・本番版のAndroid OAuthクライアント
- つぐレジ＋開発版・本番版のAndroid OAuthクライアント
- 各applicationIdに対応する署名SHA-1

## 今回含まない機能

- Drive APIへの売上JSON直接アップロード
- Drive APIからの売上JSON直接ダウンロード
- DriveフォルダAPI自動作成
- Drive Changes API差分同期
- アプリ終了中の完全自動同期

v0.44では、アカウント選択・認可・Drive API接続確認を先に固定します。直接送受信は次段階です。

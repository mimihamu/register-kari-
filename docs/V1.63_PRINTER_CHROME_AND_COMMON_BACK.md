# v1.63 プリンタ診断7画面の白帯解消・共通「戻る」操作

## 発見した不統一

Android POS本体の Activity 45画面を逐一ソース点検した結果、フル幅の `.background(Color.White)` が残っていたのは次の7画面。いずれも画面下端の診断・試験用ステータス領域であり、上部バーではなかった。

- `PrinterNotificationSettingsActivity.kt`：通知・連続印刷試験案内
- `PrinterSoakTestActivity.kt`：結果CSVと実機目視警告
- `PrinterSoakTestHistoryActivity.kt`：履歴・印刷不確定注意
- `PrinterStatusAnalysisActivity.kt`：状態分析候補の信頼性表示
- `PrinterStatusLabActivity.kt`：機種互換性に関する注意
- `PrinterStatusProbeActivity.kt`：RAWプローブCSVと結果表示
- `PrinterStatusValidationActivity.kt`：候補審査と注意

## 実施内容

1. 上記7画面の画面下端の白い全幅帯を、既存共通色 `RegisterSecondaryActionBarColorV159`（`#E3EDF7`）へ変更。警告・CSV保存ボタン・印字の試験ロジック・画面高さは変更しない。
2. `RegisterTopBarV141` の「戻る」を白い塗りボタンから**透過背景＋白枠＋白文字**へ統一。濃紺`#173F6B`およびレジマイナスの赤背景でも一貫したコントラスト。画面戻りハンドラ自体を変更しない。
3. `V163PrinterDiagnosticChromeRegressionTest` で7画面の白帯再発を禁止。印字試験の注意文、データ出力ボタン、共通safe-area/ヘッダー維持、共通「戻る」白枠を自動検査。

## セキュリティと印刷の注意

この変更は視認性・統一感のみ。プリンタステータス、送信不確定の扱い、プリンタ機種の正式認証、実機での紙切れ・再印刷・ドロア試験、記録ファイルの出力が正しく機能することは実機受入項目として残す。

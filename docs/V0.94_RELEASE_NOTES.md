# つぐレジ v0.94.0-dev.1 リリースノート

## 概要

v0.94では、起動直後の `SCR-001 起動・自己診断` を既存の共通レスポンシブ基盤へ接続する。

800×480やAndroidフォント倍率を上げた環境でも、診断内容と `診断完了・担当者選択へ` に到達できることを優先する。診断内容、復元判定、印刷キュー判定、ログインへの遷移ロジックは変更しない。

## 起動・自己診断

- 共通 `rememberRegisterResponsiveMetrics()` を利用する。
- 診断本文を縦スクロール可能にする。
- Compact時は診断カードを全幅化し、固定700dp幅による見切れを避ける。
- Compact時はタイトル・余白を縮小する。
- Compact時の担当者選択ボタンを全幅54dpにする。
- 通常サイズでは従来の700dp診断カードと340dpボタンを維持する。
- 診断完了後は従来どおり `SCR-010 担当者選択／ログイン` へ進む。
- MainActivityの変更はDiagnosticScreen関数だけを完全一致ガード付きで適用し、他の販売・会計画面を同時変更しない。

## データ保護

本版は起動画面の表示配置変更のみを対象とし、売上SQLite、Sales Journal、Drive JSON、sync fingerprint、SENT Outbox、quarantine、sync history、再印字監査、backup / rollback DB、税・会計・印刷処理を変更しない。

## 実機確認

ユーザー方針により、本版単独での個別実機確認は行わず、**最終総合実機試験へ繰越**する。

最終総合実機試験では800×480〜1920×1080、Androidフォント倍率、復元件数・印刷キュー件数の各状態、担当者ログインへの遷移を確認する。

CI成功・APK生成成功を実機確認済みとは扱わない。

# v1.36 → v1.37 つぐレジ CD 数量通信契約補修

正式仕様 v2.5 §30.6のCD明細数量`quantityScaled`/`quantityScale`を既存v1 WebSocket JSONへadditiveに追加する。

- POS送信側は`quantityScaled`を`quantityHundredths`と同じ1/100整数として出力し、`quantityScale=2`を明示する。
- 既存の`quantity`, `quantityHundredths`, `quantityText`, `amount`は削除しない。
- `lineAmount`は既存の`amount`と同値で添付。
- CD受信側は`quantityScaled` > `quantityHundredths` > `quantity×100`の優先順位で読み取り、二つのexact字段が矛盾すると受信拒否する。
- 不正な小数数字を`getLong`に通して切り捨てないよう文字列表現の整数性を検証する。
- `quantityText`欠落時もBigDecimalの文字列化で1.25を正確に復元する。
- 旧通信形式/旧端末との後方互換性を維持するため、`schemaVersion=1`と既存`orderItems`キーは維持する。
- 正式仕様の上位`items`配列・`lineId`・全状態名移行は、v1.37のCD統合契約変更で別途対応する。
- 実機の2台間通信、断線・再接続、商品の連打時の視認性は未確認。

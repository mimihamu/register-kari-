# v1.76 元取引あり返品・取消：操作性と再試行安全性

- 横幅1250dp未満は従来通り元売上→数量→確定の3ステップ。
- 文字倍率1.2以上は1500dp未満、倍率1.5以上は1850dp未満で3ステップを使用し、固定3列の文字切れを防止。
- 数量入力の一覧を残余領域でスクロールし、48dp以上の「返金内容を確認」を画面下に固定。
- 同じ元売上の操作IDはAndroidのActivity再生成後にも維持。すでに選択中の返品／取消を再タップしても操作IDを変更しない。
- 既存の権限・責任者PIN・返金台帳・冪等処理・税計算・印刷ルートは変更しない。
- 実機未確認：800×480、1024×600、文字拡大120/150%、キーボード表示、回転／再生成、返品・取消の実処理。

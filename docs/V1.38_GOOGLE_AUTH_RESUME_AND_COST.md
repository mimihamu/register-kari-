# Google連携再開時の認証結果保護とGoogle側料金（v1.38）

## 不具合と修正
Google認可画面からアプリへ戻った後、Activity onResumeの画面更新が直前の認可失敗、Google認証エラーコード、Google Cloud初期設定への導線を上書きしてしまう場合があった。

POS/Plusの両アプリ・かんたん接続/詳細連携の4入口にGoogleDriveAuthorizationRefreshPolicy.mergeを適用した。CONNECTING、CLOUD_CONFIGURATION_REQUIRED、AUTHORIZATION_FAILED、VERIFICATION_FAILEDかつ保存済みメールアドレスが同一なら直前状態を保持する。アカウント変更・解除時、正常状態では最新の永続情報を優先。売上SQLite・同期履歴・権限スコープは変更しない。

## Google側の料金（2026-10-24時点）
Google Drive APIの標準的な利用は追加料金なし。ただしGoogle公式文書は2026年後半にquotaを超える使用へ課金を予定すると明示。Google Drive保存容量は個人アカウントで最大15GB無料（Gmail/Photos共用）。drive.fileは非機密スコープで、限定アクセスの基本OAuthアプリ確認対象。
- https://developers.google.com/workspace/drive/api/guides/limits
- https://developers.google.com/workspace/drive/api/guides/api-specific-auth
- https://support.google.com/googleone/answer/9004014?hl=ja

基本方針：独自の有料Google Cloudサービスは追加しない。1時間間隔の既存同期と制限付き再試行を継続。料金ゼロを無条件には保証できないため、商用運用前にGoogle Cloud API quota、請求設定、保存容量を確認する。

実機でのOAuth認可成功・Google Cloud本番登録は未検証。開発版Google OAuthはPOS/Plusの2クライアント登録が必要。

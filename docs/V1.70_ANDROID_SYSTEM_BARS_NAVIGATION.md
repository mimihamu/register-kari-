# v1.70 ステータスバー背景と画面戻り先の統一

- Android 15+ のedge-to-edgeで従来のstatusBarColorのみでは白い帯が残るため、WindowCompat.setDecorFitsSystemWindows(false)でシステムバー領域まで描画する。
- つぐレジ（紺色）、レジマイナス（赤色）、つぐレジ＋（紺色）、つぐレジ CD（濃紺）の背景を、各画面の安全領域の外まで塗る。明色アイコン設定、API29+のOSコントラスト強制無効化。
- Androidシステム領域に文字やボタンを配置しないよう、ComposeのsafeDrawingとネイティブ更新画面のsystemBarsパディングを維持。
- 会計完了→売上一覧→戻る＝会計完了、販売→売上一覧→戻る＝販売、行編集→割引→戻る＝行編集、販売→割引→戻る＝販売。
- 売上詳細→返品・取消→戻る＝売上詳細、レジ管理→返品・取消→戻る＝レジ管理。画面内の戻るとAndroid Backを揃える。
- 会計入力から戻る際は保存途中の会計確定を邪魔せず、既存の支払下書き・顧客表示の復元処理を共通化。
- 3アプリの実機ではAndroid 12/15/16、ジェスチャー/3ボタン、回転/キーボード表示と画面間遷移を受入試験として確認すること。

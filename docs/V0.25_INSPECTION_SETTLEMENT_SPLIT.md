# v0.25 X点検・Z精算の導線分離

## 目的

点検と精算を同じ画面内の切替操作にせず、業務上の意味と影響が異なる処理として独立させる。

## 画面構成

- `SCR-500-X X点検`
  - 営業中の数値を保存する。
  - 営業セッションは`OPEN`のまま継続する。
  - 責任者PINは要求しない。
- `SCR-500-Z Z精算・営業終了`
  - 責任者PINを要求する。
  - 確認ダイアログに営業日、セッション番号、純売上、現金実査、過不足を表示する。
  - 確定後はZ精算と営業終了を同一トランザクションで完了する。

## 誤操作防止

- レジ管理メニューにX点検とZ精算を別ボタンで表示する。
- 各画面内で処理種別を切り替えられない。
- Z精算は赤系表示とし、最終確認を経なければ実行しない。
- Z精算の確定ボタンは責任者PIN入力後のみ有効にする。

## 併行修正

v0.24で崩れていた入出金保存結果ブロックのインデントを修正し、入出金処理から精算種別への誤参照がないことをテストする。

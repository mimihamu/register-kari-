# CD正式通信 WebSocket同時接続の実統合試験とIPv6 Host修正

- Loopback上のPOS WebSocketをJVMで起動し、旧版CD相当と新版CD相当の2本のTCP/WebSocketを実際に接続。両者の初回SNAPSHOTとSNAPSHOT_REQUEST再同期で、旧版は1/ACCOUNTING、新版は"1.0"/CASH_RECEIVEDとなることを検証する。sessionId、sequence、金額も検証。
- 既存のLAN制限は維持。リンクローカルIPv6が[]付き設定でも、Socketには裸のliteralを使い、HTTP Hostヘッダーには[IPv6]:portを使うよう修正。
- ホスト名と外部アドレスは引き続き拒否する。
- CIは実WebSocketだが、別端末・Wi-Fi・ルータの疎通や画面応答時間を測定する実機試験ではない。

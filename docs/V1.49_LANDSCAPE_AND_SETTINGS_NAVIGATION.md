# v1.49 横向き・戻る位置・設定簡素化

基準: 正式仕様 REGISTER（仮） Androidレジ 詳細仕様書 v2.5 の UI-AT-01/03/06 およびユーザー追加要件（不要な補助ラベル・枠線を減らしレイアウトで意味を伝える）。

## 実装内容
- 共通 `RegisterTopBarV141` に任意 `onBack` を追加。戻るボタンは **画面左上** を原則とし、既存右側action・画面タイトルとの共存を維持。
- **商品設定・部門・税ハブ** と **任意税率・メニュー改定ハブ**：高さ600dp未満や `metrics.isCompact` を原因とした強制縦1列を廃止。幅700dp未満は狭幅向け縦、700〜1079dpは2列、1080dp以上は元のワイド配置。800×480横画面では二列。縦スクロールは不足時のみ内部に残す。
- **各種設定トップ**：固定360dpの状態一覧パネルと冗長な説明を削除。設定検索、日常設定、保守・診断・データの実操作を優先し、幅540dp未満1列、540〜1049dp 3列、1050dp以上4列のタイル。警告がある場合だけ要確認情報を表示。カテゴリ、機能入口、担当者権限の検査は維持。
- レジ管理、商品/税・改定ハブ、商品・税マスター編集、税・支払、税計算、支払、レシート、顧客表示、定期バックアップ、初期設定、同期、各種設定内部（担当者/プリンター/PIN/監査）の戻るを上部左に揃え、対応する下部・右端の重複戻るを撤去。
- 初期設定のタブ・保存ボタン、バックアップの保存バー等はそのまま保ち、戻る導線だけ移動。販売確定、印刷、権限、返金、同期、マスター保存ロジックは変更しない。
- タイトル行に開発者向け `SCR-xxx` を表示していた編集画面はタイトルのみ表示し、内部のID定義・遷移契約は維持。

## 限界・実機
- 実機で幅800×480、960×600、1280×800、フォント1.3倍、入力キーボード、スクロール終端、横向き/縦向き＋CDの視認性は最終総合試験へ繰越。
- 認証エラー、安全警告、保存失敗等は短縮の対象外。
- 個別ダイアログの全操作統一（MODAL-001）と、残る設定補助画面の細部の視覚監査は後続項目。**全画面の最終UI受入完了とは判定しない**。

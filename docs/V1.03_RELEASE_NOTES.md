# v1.03 Release Notes

## つぐレジ CD 長時間接続・半断線回収

v1.02のCD接続別送信分離に続き、POS側WebSocketサーバの接続livenessを強化した。

### つぐレジ

- TCP accept後のHTTP/WebSocket handshake待ちを5秒上限化。
- WebSocket成立後は15秒間隔でread側livenessを確認。
- CDからのframe受信、またはPOSからのframe正常送信をtransport activityとして記録。
- transport activityが45秒以上無い接続のみstaleとして回収。
- 販売中にPOS→CD表示更新が正常なら、CD側Pingが無くても誤切断しない。
- 半断線でtext writerが停止しても、read側liveness判定はwriter lockを取らずsocket closeへ進める。
- v1.02のlatest-only送信mailbox、複数CD分離、token認証、snapshot重複除外、自動再接続、Ping/Pongを維持。

### つぐレジ＋ / つぐレジ CD

アプリ本体のコード変更なし。

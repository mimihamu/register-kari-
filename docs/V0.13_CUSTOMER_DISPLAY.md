# v0.13 つぐレジ CD 基本連動

## 1. 目的

つぐレジ本体とは別のAndroid端末に、販売中の商品、点数、合計、会計途中、会計完了、お預り、お釣りを表示する任意の顧客表示アプリを追加する。

顧客表示の未設定、電源OFF、LAN切断、アプリ停止は、つぐレジ本体の販売・会計・印刷・精算を停止させない。

## 2. アプリ構成

| アプリ | package | 役割 |
|---|---|---|
| つぐレジ | `jp.co.tenposinfo.register` | 販売・会計・SQLite正本・顧客表示配信・一時ペアリング受付 |
| つぐレジ CD | `jp.co.tenposinfo.register.cd` | 顧客向け表示・自動再接続・同一LAN探索 |

開発版はそれぞれ `.dev` のapplicationIdSuffixを持つため、本番版と併存できる。

## 3. 通信

- 表示通信：LAN内WebSocket
- 初期ポート：`18080`
- 固定パス：`/customer-display/v1`
- 認証：接続トークン
- データ形式：UTF-8 JSON
- `schemaVersion`：`1`
- `sequence`：レジ本体が単調増加させる
- つぐレジ CDは、現在表示済み以下のsequenceを破棄する
- 切断中は直前金額を表示せず、接続確認画面へ切り替える

### 主なJSON項目

- `mode`: `STANDBY` / `SALES` / `ACCOUNTING` / `COMPLETE` / `DISCONNECTED`
- `storeName`
- `numberOfProducts`
- `subtotalAmount`
- `totalAmount`
- `paymentMethod`
- `receivedAmount`
- `shortageAmount`
- `changeAmount`
- `orderItems[]`

## 4. かんたんペアリング

### 手順

1. レジとつぐレジ CDを同じWi-Fiへ接続する
2. レジの［設定］→［顧客表示］を開く
3. ［2分間ペアリング受付を開始］を押す
4. つぐレジ CDの接続設定で［同じWi-Fiのレジを探す］を押す
5. 表示された店舗を選び［このレジに接続］を押す

選択すると、レジIP、ポート、接続トークンを保存し、自動接続を開始する。

### 方式

- Android NSD（DNS-SD / mDNS）を使用する
- サービスタイプ：`_tsuguregi-cd._tcp.`
- ペアリング受付時間：120秒
- CD側の1回の探索時間：12秒
- 公開項目：通信形式、店舗名、パス、接続トークン、ポート
- 接続情報は常時公開せず、レジで受付を開始した時間だけ公開する
- 受付停止または120秒経過でNSDサービスを解除する
- 受付開始直後に画面を閉じた場合も、遅れて登録されたNSDサービスを即解除する
- CDは通信形式、パス、トークン長、ポートを検証し、不正な広告を候補へ出さない
- Android実装によるサービスタイプ末尾ドットの差を吸収する
- 自動探索できないネットワーク向けに、従来の手動入力を残す

## 5. レジ本体側

責任者設定画面の［顧客表示］から以下を設定する。

- ON / OFF
- 店舗名
- 待受ポート
- 接続トークン
- お釣り・会計完了表示秒数
- 2分間ペアリング受付

初期値はOFF。OFF時はWebSocket待受けを行わない。ペアリング受付を開始した場合は顧客表示をONにし、設定を保存してWebSocket待受けを開始する。

レジ本体側はSQLiteの作業中カートを300ms間隔で監視する。カート変更時に販売表示を更新し、会計画面では支払入力のたびに合計、支払済、不足、お釣りを配信する。新規売上確定時は保存済み売上・支払スナップショットから会計完了表示を生成する。

## 6. つぐレジ CD側

- Androidスマートフォンとタブレットに対応
- 縦画面・横画面の回転に対応
- 画面常時点灯
- 同一Wi-FiのレジをNSDで探索
- 検出したレジを選択して即接続
- レジIP／ホスト名、ポート、トークンの手動設定
- 起動時自動接続
- 接続失敗時は1秒、2秒、5秒、10秒、30秒の順で再試行
- 待機表示
- 商品一覧、数量、単価、行金額
- 最新変更商品の強調と自動スクロール
- 点数、合計
- 会計途中の支払方法、お預り、不足、お釣り
- 会計完了、支払方法、お預り、お釣り
- 切断時の金額非表示

### 画面サイズ別レイアウト

画面幅と高さから以下を自動判定する。

| 判定 | 基準例 | 表示方式 |
|---|---|---|
| スマホ縦 | 360×800dp | 合計・会計情報を上、商品一覧を下に配置 |
| スマホ横 | 800×360dp | 商品一覧と合計・会計情報を左右に配置 |
| タブレット縦 | 800×1280dp | 上下配置、文字と余白は拡大型 |
| タブレット横 | 1280×800dp | 従来の左右配置を維持 |

端末の最短辺が600dp未満の場合をスマホ向けコンパクト表示とする。回転時は接続設定と受信済み表示状態を保持したまま再配置する。

### スマホ向け調整

- ヘッダーを2段化して店舗名、接続状態、接続先、設定ボタンを収める
- 商品名を最大2行まで表示し、長い名称は末尾省略する
- 商品一覧部分を独立してスクロール可能にする
- 最新変更商品が表示領域外の場合は該当行へ自動スクロールする
- 合計金額、お釣り、完了表示の文字サイズを画面幅に合わせて縮小する
- 設定画面全体を縦スクロール可能にする
- スマホ縦では検索・保存・接続ボタンを画面幅いっぱいにする

## 7. 安全方針

- 顧客表示通信は売上確定トランザクションへ参加させない
- 顧客表示送信失敗を理由に売上保存・印刷をロールバックしない
- 顧客表示アプリからレジ本体の販売データを変更しない
- 接続トークン不一致のWebSocket接続を拒否する
- ペアリング情報を常時LANへ公開しない
- 通信形式・パス・トークン検証に失敗した探索結果を使用しない
- 受信した古いsequenceで表示を巻き戻さない
- 実Wi-Fiで確認するまでは探索・接続安定性を確認済みと表現しない
- 開発署名を本番署名として扱わない

## 9. 実機確認項目

1. 同一Wi-Fi上で2分間ペアリング受付を開始できる
2. CDの検索結果へ正しい店舗名・IP・ポートが表示される
3. ［このレジに接続］だけで接続設定が保存される
4. 120秒経過後は新規探索でレジが見つからない
5. 受付停止後は新規探索でレジが見つからない
6. 受付開始直後に設定画面を閉じても探索候補が残らない
7. 別SSID、ゲストWi-Fi、端末間通信禁止Wi-Fiでは見つからない旨を表示する
8. 自動探索できない場合も手動入力で接続できる
9. 商品追加・数量変更・削除が表示へ反映される
10. 表示件数超過時も最新変更商品へ自動スクロールする
11. 会計途中の現金・カード・商品券・掛売がCDへ反映される
12. 現金会計でお預り・不足・お釣りが正しく表示される
13. 完了表示時間経過後に待機表示へ戻る
14. レジ／表示端末のWi-Fi切断時に金額が隠れる
15. Wi-Fi復旧後に自動再接続する
16. 顧客表示OFF・表示端末停止中でもレジ販売を継続できる
17. Android 8.0以上の対象端末に両APKをインストールできる
18. 開発版2アプリのホームアイコンが、それぞれ1個だけ表示される
19. 360×800dp相当のスマホ縦画面で商品・合計・設定が見切れない
20. 800×360dp相当のスマホ横画面で商品一覧と合計が同時表示される
21. 表示中に端末を縦横回転しても接続先設定と接続状態が維持される

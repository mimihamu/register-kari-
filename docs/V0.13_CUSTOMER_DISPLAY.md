# v0.13 つぐレジ CD 基本連動

## 1. 目的

つぐレジ本体とは別のAndroid端末に、販売中の商品、点数、合計、会計完了、お預り、お釣りを表示する任意の顧客表示アプリを追加する。

顧客表示の未設定、電源OFF、LAN切断、アプリ停止は、つぐレジ本体の販売・会計・印刷・精算を停止させない。

## 2. アプリ構成

| アプリ | package | 役割 |
|---|---|---|
| つぐレジ | `jp.co.tenposinfo.register` | 販売・会計・SQLite正本・顧客表示配信 |
| つぐレジ CD | `jp.co.tenposinfo.register.cd` | 顧客向け表示・自動再接続 |

開発版はそれぞれ `.dev` のapplicationIdSuffixを持つため、本番版と併存できる。

## 3. 通信

- 接続方式：LAN内WebSocket
- 初期ポート：`18080`
- 固定パス：`/customer-display/v1`
- 認証：接続トークン
- データ形式：UTF-8 JSON
- `schemaVersion`：`1`
- `sequence`：レジ本体が単調増加させる
- つぐレジ CDは、現在表示済み以下のsequenceを破棄する
- 切断中は直前金額を表示せず、接続確認画面へ切り替える

### 主なJSON項目

- `mode`: `STANDBY` / `SALES` / `ACCOUNTING` / `COMPLETE` / `DISCONNECTED`
- `storeName`
- `numberOfProducts`
- `subtotalAmount`
- `totalAmount`
- `paymentMethod`
- `receivedAmount`
- `shortageAmount`
- `changeAmount`
- `orderItems[]`

## 4. レジ本体側

責任者設定画面の［顧客表示］から以下を設定する。

- ON / OFF
- 店舗名
- 待受ポート
- 接続トークン
- お釣り・会計完了表示秒数

初期値はOFF。OFF時はWebSocket待受けを行わない。

レジ本体側はSQLiteの作業中カートを300ms間隔で監視する。カート変更時に販売表示を更新し、新規売上確定を検出した場合は保存済み売上・支払スナップショットから会計完了表示を生成する。

## 5. つぐレジ CD側

- 横画面固定
- 画面常時点灯
- レジIP／ホスト名、ポート、トークンを手動設定
- 起動時自動接続
- 接続失敗時は1秒、2秒、5秒、10秒、30秒の順で再試行
- 待機表示
- 商品一覧、数量、単価、行金額
- 最新変更商品の強調
- 点数、合計
- 会計完了、支払方法、お預り、お釣り
- 切断時の金額非表示

## 6. 安全方針

- 顧客表示通信は売上確定トランザクションへ参加させない
- 顧客表示送信失敗を理由に売上保存・印刷をロールバックしない
- 顧客表示アプリからレジ本体の販売データを変更しない
- 接続トークン不一致のWebSocket接続を拒否する
- 受信した古いsequenceで表示を巻き戻さない
- 実Wi-Fiで確認するまでは接続安定性を確認済みと表現しない
- 開発署名を本番署名として扱わない

## 8. 実機確認項目

1. 同一Wi-Fi上でレジIP・ポート・トークンを入力して接続できる
2. 商品追加・数量変更・削除が300ms程度で表示へ反映される
3. 最新変更商品だけが強調される
4. 保留・取引中止で待機表示へ戻る
5. 現金会計でお預り・お釣りが正しく表示される
6. カード等の非現金会計で支払方法とお釣り0が表示される
7. 完了表示時間経過後に待機表示へ戻る
8. レジ／表示端末のWi-Fi切断時に金額が隠れる
9. Wi-Fi復旧後に自動再接続する
10. 顧客表示OFF・表示端末停止中でもレジ販売を継続できる
11. Android 8.0以上の対象端末に両APKをインストールできる
12. 開発版2アプリのホームアイコンが、それぞれ1個だけ表示される

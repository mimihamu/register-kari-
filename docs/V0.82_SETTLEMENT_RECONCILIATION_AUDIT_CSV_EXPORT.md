# v0.82 点検・精算 整合確認監査 CSV出力

## 目的

v0.81で追加した `SCR-521 整合確認監査台帳` の監査結果を、店舗から本部・サポート・監査担当へ受け渡せるCSVとして安全に保存できるようにする。

v0.82では `SCR-522 整合確認監査 CSV出力` を追加し、OK / INFO / ALERTと検索文字の条件を指定して、条件一致する監査を全件出力する。

## 導線

`SCR-520 点検・精算履歴` の整合確認エリアから「整合確認監査をCSV出力」で開く。

## 権限

利用には以下の両方が必要。

1. `VIEW_SALES`
2. `X_INSPECTION` または `Z_SETTLEMENT`

画面表示中はログインセッションを定期的に再取得する。保存先選択から戻った時点でも権限を再確認し、失効していればCSV出力を中止する。

## 出力条件

- すべて
- OK
- INFO
- ALERT
- レポートNo.
- 担当者
- 営業日
- 営業セッション
- 比較証跡内の文字列

検索文字は最大80文字。SQLiteのselectionArgsでバインドし、SQLへ文字列連結しない。

## スナップショット

CSV保存ボタンを押した時点で、現在条件に一致する最新監査の `(created_at, id)` を固定する。

出力SQLには以下の上限条件を追加する。

- `created_at < snapshot.createdAt`
- または `created_at = snapshot.createdAt AND id <= snapshot.auditId`

これによりAndroid標準の保存先選択画面を表示している間に新しい整合確認監査が追加されても、開始済みCSVへ混入させない。

対象が0件の場合はsnapshotをnullとして固定し、そのCSVはヘッダーのみを出力する。保存先選択中に後から追加された監査を0件CSVへ混入させない。

## CSV列

1. `audit_id`
2. `executed_at`
3. `severity`
4. `report_id`
5. `report_type`
6. `business_date`
7. `business_session_id`
8. `snapshot_type`
9. `difference_count`
10. `operator_name`
11. `event_type`
12. `detail`

`report_type`、`business_date`、`business_session_id`、`snapshot_type`、`difference_count` はv0.79で保存した比較証跡detailから列分けする。元の `detail` もそのまま残し、証跡を欠落させない。

## CSV形式

- UTF-8 BOM付き
- 改行はCRLF
- 全セルをダブルクォートで囲む
- セル内ダブルクォートは二重化
- 改行はLFへ正規化
- 先頭空白を除いた最初の文字が `=` / `+` / `-` / `@` の文字列は先頭へ `'` を付け、表計算ソフトの数式解釈を抑止

## 保存

Android Storage Access Framework の `CreateDocument("text/csv")` を使用する。

アプリは保存先URIを監査ログ・診断ログへ記録しない。

## データ保全

CSV出力は読み取り専用とする。

- `operation_audit` へのINSERTなし
- `operation_audit` のUPDATEなし
- `operation_audit` のDELETEなし
- 売上SQLite既存行の変更なし
- 税・支払・返品・点検精算snapshotの変更なし
- Sales Journalの変更なし
- Google Drive JSONの変更なし
- sync fingerprint / imported sales / SENT Outbox / quarantine / sync historyの変更なし

CSVへ以下を含めない。

- OAuth token
- Authorization header
- content URI
- raw sales JSON

## 実機確認

CIでは以下を実機確認済みとは扱わない。

- SCR-520からSCR-522へ実際に遷移できること
- Android標準の保存先選択UI
- 日本語CSVをExcel等で開いた場合の表示
- 0件時にヘッダーだけのCSVになること
- OK / INFO / ALERTフィルターの実データ一致
- レポートNo.・担当者・営業日・営業セッション検索
- 保存先選択中に新規監査が追加されてもCSVへ混入しないこと
- 保存先選択中の権限失効で出力中止になること
- 多数監査時のCSV出力性能
- 書き込み失敗時のエラー表示

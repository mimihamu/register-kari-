# v1.37 CD通信契約：lineId・金額検証・新旧wire共存

基準：正式仕様 v2.5 §30.5–30.7、CDP-NET-007。

- POS は CartItem.lineId を独立の lineId として orderItems/items の両方に送信する。同一商品IDに複数行があっても一意な行IDを維持する。旧カート行に lineId がない場合のみ legacy-line-{index+1} を生成するが、編集や行削除に対する恒久的安定性は保証しない。最新行の強調は商品ID一致の最後の行のみを選び、latestLineId を送信。
- 正式項目 sentAt（ISO-8601 UTC）、remainingAmount、payment（receiptName/tenderedAmount/appliedAmount）を旧フィールドへ追加する。過去端末を守るため、既存 schemaVersion=1 / mode=SALES・ACCOUNTING 等 / WebSocket path は変更しない。
- CD は正式 schemaVersion="1.0" と旧 int 1 の両方を読める。CART/PAYMENT/CASH_RECEIVED/CHANGE は現行表示モードへ互換写像し、未知 major、必須項目欠損、非整数金額、負のお釣りを拒否する。正式 items を持つpayloadのみ必須金額検証を行い、旧 orderItems の欠損項目ゼロ補完を一時維持する。
- 発行側 mode を正式 enum へ切り替えること、CHANGE/CASH_RECEIVED の個別画面の完全遷移、schemaVersion 正式string送信、未知モードを受けた際の E-CD-005 専用UI・即時表示遮断、保存済み旧 lineId の移行は未完了。今回を正式 §30.6 完了とは扱わない。
- 自動テストは POS lineId/payments/ISO日付と CD version/金額異常/旧wire互換を確認。実機Wi-Fi瞬断/1,000更新の受入は未確認。

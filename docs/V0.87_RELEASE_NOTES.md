# v0.87 リリースノート

## つぐレジ 0.87.0-dev.1

v0.86で安全化した復元前ロールバックDBを、責任者がSCR-767「データ保全・バックアップ・復元」から確認できるようにする運用可視化版。

## 追加内容

- 復元前ロールバックの保管件数表示
- 最新ロールバックの検証状態表示
- 最新ロールバックのファイル名表示
- 最新ロールバックの作成日時表示
- 最新ロールバックのサイズ表示
- SHA-256先頭表示
- 検証失敗時のNG表示とエラー内容表示
- 読み取り専用「ロールバック再検証」操作
- 初回表示・画面復帰・関連操作完了時の状態再読込
- SQLite/ハッシュ検証は `Dispatchers.IO` で実行

## 変更しないもの

- v0.86のWAL-safeロールバック作成ロジック
- 復元予約の責任者PIN要件
- 復元ブロッカー
- 売上・税・支払・保留・印刷ロジック
- Sales Journal / Drive JSON / sync fingerprint / SENT Outbox
- ロールバックDBの自動削除

v0.87からロールバックを削除・手動復元する操作は追加しない。

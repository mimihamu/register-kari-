# つぐレジ v1.11.0-dev.1 Release Notes

## 変更概要

SAF / DocumentsProviderへの外部JSON送信で、rename時の例外をrename非対応と誤認してcopyフォールバックへ進まないようにした。

## 主な変更

- `DocumentsContract.renameDocument()` がnullを返した場合だけcopy-to-finalへフォールバック。
- rename例外はcatchでnullへ変換せず上位へ伝播。
- Providerメタデータ一時障害は通常retry。
- Provider名不一致／同名衝突は既存の永久衝突経路。
- 権限異常は既存の権限喪失経路。
- rename異常後の不要な確定JSONコピーを禁止。
- v1.06〜v1.10のSAF安全性を維持。

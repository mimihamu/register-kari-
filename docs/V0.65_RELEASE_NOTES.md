# v0.65 Release Notes

- レジ管理メニューへ「営業日別 売上検索」を追加。
- 既存 `sales.business_date` / `business_session_id` を読み取り専用で参照。
- 営業日From/To、売上No.、担当者、支払方法、金額範囲による検索を追加。
- 営業日形式不正、From > To、金額範囲不正はfail-closedで拒否。
- 営業日未記録の旧売上は勝手に推定せず「営業日未記録」と表示。
- 一覧外の古い売上も売上No.直接表示でSQLiteから参照可能。
- 選択売上から同じ売上No.を保持して領収書発行へ進める。
- `REVERSAL`権限がある場合だけ同じ売上No.を保持して返品・取消へ進める。
- 検索処理では `BusinessSessionSchema.ensure()` を呼ばず、旧売上のバックフィルを発生させない。
- v0.64までの売上検索、領収書、返品・取消安全導線を維持。

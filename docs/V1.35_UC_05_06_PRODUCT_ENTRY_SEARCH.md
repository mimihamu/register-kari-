# v1.35 UC-05 / UC-06 商品コード入力・検索 / 商品選択・登録

## 実装範囲

- 既存 `products.id` を商品コードの正本として維持し、既存DB・売上参照との互換性を保持。
- `product_meta` に検索用 `kana` / `barcode` を冪等追加。バーコードは空欄可、入力時は一意。
- 商品マスターで「かな（検索用・任意）」「バーコード（任意・一意）」を編集可能。
- 販売画面の商品検索は名称・かな・商品コード・バーコードを対象。
- 商品コードまたはバーコードの完全一致は検索ダイアログから直接登録可能。
- キーボードウェッジ型バーコードスキャナの高速ASCII＋Enterを販売画面で捕捉し、コード/バーコード完全一致なら即登録。
- 置数後の「数量」は、選択行がある場合は従来どおり行数量訂正、未選択時は次に登録する商品の数量予約として動作。例: `3 → 数量 → 商品A` で3点登録。
- SET-001 `sale.mergeSameItem` が有効な場合、数量予約で登録した数量を既存同一行へ加算。

## 安全性 / 互換性

- 商品コード主キーを変更しない。新しい別コード主キーは導入しない。
- 既存DBでは `PRAGMA table_info` により列の有無を確認してから `ALTER TABLE`。
- 非空バーコードには部分UNIQUE INDEXを設定し、保存前にも重複を拒否。
- スキャナ捕捉は販売画面表示中だけ有効で、4文字未満や低速入力のEnterは消費しない。
- コードと他商品のバーコードが衝突して完全一致候補が複数になる場合は fail-closed で自動登録しない。

## 自動テスト

`V135ProductEntrySearchTest` で以下を固定する。

- 商品コード / バーコード完全一致
- 名称 / かな / 商品コード / バーコード部分検索
- 曖昧完全一致の自動登録禁止
- 選択行数量訂正 / 次商品数量予約の分岐
- バーコード正規化・空白拒否

## 実機確認が必要な項目

- 実バーコードリーダー（USB/Bluetooth HID）の入力速度・Enter終端
- 日本語IME表示中の検索操作
- 800×480端末で検索ダイアログと商品ボタン操作
- 連続スキャン時の登録順・数量予約解除

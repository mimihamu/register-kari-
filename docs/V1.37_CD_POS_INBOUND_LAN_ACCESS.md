# v1.37 CD接続先のLAN制限をPOSサーバー受信側にも適用

CD側のprivate/LAN限定に加え、POSのWebSocketサーバーでも接続開始直後のソケット実送信元IPを検証する。IPv4 RFC1918（10/8、172.16/12、192.168/16）、169.254/16、IPv6 link-local、loopbackを許可。その他のグローバルIP、CGNAT、IPv6 ULA等は403で拒否し、トークン検証前に閉鎖する。HTTP HostやX-Forwarded-Forなど改竄可能な文字列では判断しない。

ループバック許可は同一端末接続/CIローカルTCP統合試験のため。これは「同一LAN」という厳密な到達範囲証明ではなく、RFC1918ネットワーク内にL3ルートがある場合にも接続可能。必要なら本番ネットワークのサブネット/インターフェース判定、無線AP/VLAN隔離、WSS/TLSも検討する。

認証は従前のペアリングトークンを引き続き必要とする。実機LAN疎通は未検証。

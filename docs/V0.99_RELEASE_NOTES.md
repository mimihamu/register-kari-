# つぐレジ v0.99.0-dev.1 リリースノート

## 概要

v0.99では、実プリンター投入前の送信競合対策として、同一TCPプリンターへのESC/POS送信をendpoint単位で直列化した。

v0.98時点では自動Worker、統合印刷キューの手動送信、`MemoryPrinterGateway`経由の実送信がそれぞれ独立した `TcpEscPosPrinterGateway` を生成しており、同一host:portへの送信が重なる余地があった。

## 主な変更

- `PrinterEndpointSendGate` を追加。
- `host:port` 単位でTCP ESC/POS送信を直列化。
- `TcpEscPosPrinterGateway.send()` の入口からconnect/write/flush/close完了までを共通permitで保護。
- 同一endpointは1送信ずつ、異なるendpointは並行可能。
- permit待機上限はプリンター設定のtimeoutを使用。
- 待機タイムアウトはTCP接続前に失敗し、`SAFE_TO_RETRY` として扱う。
- protected blockが例外終了してもpermitを必ず解放。

## 維持する既存安全仕様

- TCP 9100 / ESC/POS。
- 58mm / 80mm。
- カット / ドロア設定。
- EPSON DLE EOT状態確認。
- `CONNECTING` / `CONNECTED` / `WRITE_STARTED` / `FLUSHED` の送信フェーズ。
- `WRITE_STARTED`以降の失敗は送信結果不明として自動再送しない。
- v0.98の売上／業務帳票横断の古い順。
- v0.98の1run最大20件。
- v0.98の最初の失敗で停止。
- v0.98のperiodic / immediate自動Worker単一実行。
- 手動再印字・責任者PIN付き強制印刷・監査ログ。

## 変更していない機能

- 売上・会計・税計算。
- レシート・領収書・返品取消の内容。
- Google Drive。
- つぐレジ CD。
- データ保護・バックアップ・復元・ロールバック。

売上DBを削除・上書きする処理は追加していない。

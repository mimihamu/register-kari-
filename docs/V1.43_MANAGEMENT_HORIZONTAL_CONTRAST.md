# v1.43 レジ管理画面 横向きレイアウト／バー視認性

## 対応理由
v1.42以降、管理画面の `metrics.isCompact || maxWidth < 1_050.dp || maxHeight < 560.dp` 判定によって、横向き800×480dp程度のタブレットでも管理項目が縦一列に並び、画面が極端に長くなっていた。また紺色ヘッダー上で `OutlinedButton` の背景が白、文字も白となって設定入口が見えにくかった。下部システムナビゲーション領域も白地で画面との境界が不明確だった。

## 改修
- 横向き幅700dp以上では、左に営業状況・右に2～3列の管理ボタンを常時並べる。
- 管理ボタン用領域が720dp未満なら2列、720dp以上なら3列。画面高に関係なく左／右それぞれ独立してスクロール。
- 管理ボタンは82～94dp高さ。縦に伸びる固定1列表示を廃止。幅700dp未満のみ上下2エリア。
- 旧「その他」経由の当日売上／入出金／返品・取消は、すべて管理トップから直接選べる状態を維持。
- 「各種設定」は紺色バー上の白塗りボタン＋紺文字に変更。白地に白文字の組合せを防ぐ。
- 「販売へ戻る」のフッターは紺色、青い戻るボタン＋白文字。システムナビゲーション領域も紺色＋白いアイコンで統一。
- 共通 `RegisterSafeAreaV141` の背景を紺色に変更し、Android 15以降の edge-to-edge 描画でも上下の背景が白抜けしないようにする。
- 売上管理・権限・入力処理は変更しない。

## 自動試験・実機試験
`V143ManagementHorizontalAndBarContrastTest.kt` で管理画面の横2ペイン判定、2～3列表示、対象機能と権限付きルートの保持、設定ボタンとシステムバーの色を検査する。
実機では800×480、960×600、1280×800などの横向き、ステータス・ナビゲーションアイコン、スクロール、管理11機能への遷移および権限を確認する。実機未確認は総合試験へ繰り越す。

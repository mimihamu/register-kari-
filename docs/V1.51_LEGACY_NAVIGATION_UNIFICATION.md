- **点検・精算履歴:** SCR-520と独自ナビゲーションを共通バーへ置換し、空の戻る専用下部バーを削除。条件検索・売上プレビュー・再印字承認は保持。
- **整合確認監査CSV:** SCR-522/担当者をバーから省き、共通バーの「戻る」を導入。CSVフィルター・出力・数式インジェクション保護/個人データ排除は維持。
- **領収書発行・運用台帳:** 共通ヘッダー左上「戻る」。下部は「運用台帳・印刷状態」「発行・再発行」「統合印刷キュー」などの操作に絞る。領収書発行・再発行確認・履歴監査の処理は変更なし。

- **プリンター応答分析・状態ラボ・検証・連続印刷試験履歴:** 共通紺ヘッダー、左上「戻る」。状態ラボでは採取中の離脱禁止を維持。後部バーから重複「閉じる」を撤去し、重要な互換性警告・送信結果不明/削除安全性・実行結果は残す。

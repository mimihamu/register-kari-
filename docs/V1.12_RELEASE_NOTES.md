# つぐレジ v1.12.0-dev.1 Release Notes

## 変更概要

SAF / DocumentsProviderへの外部JSON送信で、最初の確定JSON存在確認からrename/copy完了までの間に別の同名JSONが作成される競合を検出するため、確定直前・直後の再照合を追加した。

## 主な変更

- `.partial` 検証後、確定直前に同名確定JSONを再検索。
- 競合側が同内容なら `.partial` を削除して既送信扱い。
- 異内容／directory／同名複数は既存項目を変更せず衝突停止。
- rename/copy後、確定JSON名を再検索。
- 確定URIのdocument IDと検索で見えるdocument IDを照合。
- 確定直後に同名項目が見えない場合は成功扱いせずretry。
- 確定直後の競合時はアプリ自身の `committedUri` だけをcleanup。
- v1.06〜v1.11のSAF安全性を維持。

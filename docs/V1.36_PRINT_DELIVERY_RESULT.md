# v1.36 印刷結果 `PRINTED / ACCEPTED`

正式仕様書 v2.5 §16.9 の印刷結果区分を、既存キュー状態と分離して永続化する。

## 状態と結果

- キューの終端状態 `COMPLETED` は既存互換のため維持する。
- `print_jobs.delivery_result` / `document_print_jobs.delivery_result` に次を保存する。
  - `PRINTED`: メーカー仕様確認済みの状態取得で送信後に異常なしを確認した。
  - `ACCEPTED`: TCP送信は成功したが、信頼できる自動状態取得を使用できない。
- 既存の `COMPLETED` 行は結果を推測して埋めず `NULL` のまま残す。

## 送信後確認

EPSON TM 日本語プロファイル (`EPSON_DLE_EOT`, メーカー仕様確認済み) のみ、送信成功後にリアルタイムステータスを取得する。プロトコル妥当・オンライン・カバー閉・用紙あり・停止/エラーなしを確認した場合だけ `PRINTED` とする。

STAR / 汎用 ESC/POS の DLE EOT 互換方式は「要実機確認」のため自動照会せず `ACCEPTED` とする。

送信後照会の timeout、通信断、用紙切れ、カバーオープン、エラー等では、印刷済みか否かをソフトウェアから確定できない。ジョブは `SENDING` のままとし、「送信結果が不明」と記録して自動再送しない。担当者が紙を確認して「完了扱い」または新しいジョブとして「再印刷」を選ぶ。

## 実機確認

以下はソフトウェア検証とは分け、実機確認完了まで **実機未確認** とする。

- EPSON TM-m30 / TM-m30II で送信後 DLE EOT が正常応答し `PRINTED` になること。
- WRITE_STARTED/FLUSHED 後のLAN断・電源断で `SENDING` が維持され二重印刷されないこと。
- 用紙切れ・カバーオープン時に `PRINTED` と誤確定しないこと。
- STAR / 汎用機で `ACCEPTED` と記録され、未検証状態照会を自動実行しないこと。

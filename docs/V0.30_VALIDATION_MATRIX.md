GitHub Actionsで次を毎回実行する。

- v0.14～v0.30累積ユニットテスト
- つぐレジのKotlinコンパイル
- つぐレジ CDのKotlinコンパイル
- つぐレジdebug APK生成
- つぐレジ CD debug APK生成
- 両APKのSHA-256生成

- v0.30対象ソース・権限ポリシー・レスポンシブ構成の静的確認

## 営業開始前の権限ケース

### ケースA

- SALESあり
- Z_SETTLEMENTあり

期待結果:

- `営業開始・状態画面へ`を表示
- ボタンから営業開始・状態画面を直接開く
- 営業開始保存時にもZ_SETTLEMENTを再確認

### ケースB

- SALESあり
- X_INSPECTIONのみ

期待結果:

- 営業開始ボタンを表示しない
- X点検権限だけでは営業開始画面へ入れない
- レジ管理メニューのX点検は営業開始後に使用する

### ケースC

- SALESあり
- SETTINGSあり
- Z_SETTLEMENTなし

期待結果:

- `各種設定`を表示
- `担当者を切替`を表示
- 営業開始ボタンを表示しない

### ケースD

- 保存データは旧SETTLEMENTのみ

期待結果:

- 読込時にX_INSPECTIONとZ_SETTLEMENTへ互換展開
- 新規保存時は旧SETTLEMENTを保存しない
- 互換展開後に営業開始ボタンを表示

## レスポンシブ対象

- SCR-200 商品・分類・税・販売プロファイル
- SCR-270 任意税率・メニュー改定
- SCR-700 レジ管理メニュー
- SCR-490 営業開始・状態
- SCR-500-X X点検
- SCR-500-Z Z精算・営業終了
- SCR-520 点検・精算履歴

確認条件:

- 800×480dp相当
- 1280×800dp相当
- 1920×1080dp相当
- Android表示サイズ変更
- Androidフォント倍率変更

期待結果:

- 主要領域が重ならない
- 文字・ボタンが欠けない
- Compact時は縦積みまたはスクロールへ切り替わる
- 最小操作領域48dpを維持する
- 保存、戻る、営業開始、点検、精算、再印字へ到達できる
- 大画面では主要パネル自体を拡大する
- 上部バーはつぐレジの紺色で統一する

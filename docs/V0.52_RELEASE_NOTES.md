# v0.52 Release Notes

## バージョン

- つぐレジ: `0.52.0-dev.1` / versionCode `82`
- つぐレジ＋: `0.11.0-dev.1` / versionCode `11`
- つぐレジ CD: `0.14.0-dev.1` / versionCode `7`

## 追加

- Google Drive運用セットアップ・復旧画面を統合
- 自動選択／Drive API固定／互換フォルダ固定
- 接続状態から実際に利用可能な方式を判定
- 推奨設定の一括適用
- Drive APIと互換フォルダの自動処理を同時に有効化しない制御
- 初回セットアップ状況の一括表示
- 6項目の実機確認チェックリスト
- 運用モードと確認チェックの端末内保存

## 維持

- `drive.file`スコープ
- アクセストークン・更新トークンを保存しない
- SQLiteを売上正本として維持
- Drive上の削除をローカル売上削除へ連動しない
- duplicateImportKeyによる重複取込防止
- SAF互換フォルダ方式
- 既存の診断・初期設定・接続テスト
- つぐレジ CDのv0.14表示復旧状態

## 注意

実機確認チェックは作業者が確認結果を記録する機能であり、アプリによる自動試験ではない。Google Drive、OAuth、フォルダ永続権限、再起動後の動作は実機で確認する。

# v0.54 Release Notes

## つぐレジ 0.54.0-dev.1

- `Googleかんたん接続`画面を追加
- Googleアカウント選択後、接続確認JSON作成、Outboxステージ、定期送信、初回送信要求を自動化
- 通常操作を「Googleと連携」「今すぐ同期」「連携解除」「保守・復旧」に整理
- 従来の初期設定ガイド、診断、互換フォルダ送信は保守用として維持

## つぐレジ＋ 0.13.0-dev.1

- `Googleかんたん接続`画面を追加
- Googleアカウント選択後、Drive APIを通常経路として自動設定
- 互換フォルダ自動取込を停止し、Drive API自動同期との二重実行を防止
- 接続確認JSONの自動検索と初回売上差分同期を追加
- 接続確認JSONが未作成の場合は、つぐレジ側の準備待ちとして案内
- 従来の方式選択、互換フォルダ、全件再確認、診断は保守・復旧画面に維持

## つぐレジ CD

- v0.14.0-dev.1を継続
- v0.54では機能変更なし

## 安全性

- OAuthアクセストークン・更新トークンを永続保存しない
- Google連携解除時も売上、同期履歴、Drive上JSONを削除しない
- SQLiteを原本として維持
- 実Googleアカウント、実Google Drive、本番署名は実機確認が必要

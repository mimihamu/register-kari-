## v1.61追加の実装安全性
- レジマイナスでは同じ取引カートで決済ダイアログを開き直すと、確定操作IDを再生成していた。
- 再生成を撤廃し、同じ商品カートのダイアログ再オープンは**同一の操作ID**でDBの既存コミット復旧経路を再使用。
- 「取引中止」の明示操作でのみIDを更新し、異なる取引としての追加を許可する。
- `V161RegisterMinusReopenSafetyTest` で新規IDの発行タイミングを自動監査。

# v0.70 UI Plan

SCR-648 will switch from client-side filtering of a fixed list to an applied database criteria model:

- draft query input
- explicit Search action
- state filter applies with offset reset
- 200-row current page
- Previous / Next navigation
- current range and total matching count
- 5-second refresh keeps the same applied criteria and offset
- selection is constrained to the current page

No recovery mutation is added to SCR-648.

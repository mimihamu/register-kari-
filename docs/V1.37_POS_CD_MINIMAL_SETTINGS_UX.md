# POS顧客表示設定：ミニマル操作画面

画面に必要な要素を操作順で配置する。上から「顧客表示状態（停止・待受・接続台数）」「ON/OFF＋店舗名＋ペアリング受付」「表示」「接続の詳細」「保存」。一段落の説明文・何度も繰り返す項目名・通信内部パス等は常時表示しない。

- ペアリング開始は基本カード内の大きな主ボタン。受付中は残り秒数と停止ボタンに入替え。
- 表示デザインはテーマ選択・ロゴ・待機メッセージを普段の画面に表示し、頻度の低い取消商品・税記号・文字倍率・行数・完了時間は「表示の詳細」で開く。
- 手動のIP／ポート／トークン再発行／URLコピーは「接続の詳細」で開く。
- 通信エラー・必須入力エラー・トークン失効後の再設定案内は削除せず該当操作の近くに表示する。
- 登録/認証方式、配信処理、設定保存値は変更しない。OFFでも販売・会計を継続する既存仕様を維持する。

実機では横長Androidタブレットの画面幅、小型端末、ソフトキーボード、ペアリング受付時の再表示、保存しない設定変更、旧CDとの接続互換性を確認する。

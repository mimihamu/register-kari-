## 主な変更

### Z精算の現金実査を必須化

従来はZ精算の現金実査欄を空欄にすると、理論現金を自動的に実査額として保存していた。

v1.05ではZ精算に限り、実査額の明示入力を必須とする。

- Z精算の空欄を拒否
- `0円` は明示入力された有効値として許可
- 負数は拒否
- Z空欄時はプレビューを `未入力 / 未計算` と表示
- Z空欄時は確認画面へ進めない
- UIだけでなくCoordinatorとDB Storeでも同じ規則を適用

### X点検の互換性維持

X点検は従来通り、現金実査が空欄の場合に理論現金を使用できる。営業途中の参考点検の操作性は変更しない。

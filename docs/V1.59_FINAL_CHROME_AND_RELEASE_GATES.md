## 正式版判定：未完了を数値だけで誤認しない

Issue #137 は正式仕様書 v2.5 由来の**61項目**を列挙しているが、Issue本文の完了数 `0/61` は初回作成時のままで最新コード監査が反映されていない。**実装率や完了率には使用しない**。

現在確実に根拠があるのは v1.58 の累積テストと3 APK独立検証 PASS の事実。次の受入ゲートは独立で、各ゲートが合格しない限り正式版と呼ばない。

| ゲート | 判定 | 主な残作業 |
|---|---|---|
| G1: CI/ソース監査 | v1.58 PASS、v1.59は要実行 | 全61項目のソース・テスト・ドキュメント証跡を紐付け |
| G2: UI/操作の受入 | 未実施 | 800×480 / 960×600 / 1280×800、文字倍率、システムバー、全画面の往復操作、レジマイナス |
| G3: 実機・周辺機器 | 未実施 | プリンタ58/80mm、ドロア、スキャナ、CD、Plus、決済端末、ネット断・復帰 |
| G4: 継続性・データ | 未実施 | 会計二重確定、データ移行、復元、同期途中kill、長時間運転、Z精算整合 |
| G5: リリース | 未実施 | 正式署名、既存導入端末からのアップグレード、本番配布URL、店舗受入、リリース判断 |

実機試験は機能修正の前提条件にしない。未確認事項を PASS 扱いしない。正式署名や本番公開には明示承認が必要。

## 受入の最低ケース

1. 通常販売→複数商品→小計→現金・非現金会計→釣銭・レシート。
2. 通常販売中にレジマイナスを開き、商品・数量を登録し、赤画面、負数表示、責任者承認、専用台帳、売上・件数集計を突合。
3. 返品/取消/訂正と重複・連打・バック操作、権限不足・PIN未入力。
4. X点検→Z精算→翌営業日→戻入・レジマイナスを含む純売上/現金理論残高照合。
5. 58mm/80mm、紙切れ、送信不確定、再印字、ドロア、外部カード返金の責任分界。
6. POS/Plus/CD同期と通信断・復旧、端末起動、アプリ強制終了・バックアップ復元。
7. 旧版上書きインストール、DBマイグレーション、署名連続性、更新配信。

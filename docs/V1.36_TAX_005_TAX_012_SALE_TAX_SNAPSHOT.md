# v1.36 TAX-005 / TAX-012 売上税スナップショット

## 対象

初版完成マスター Issue #137 の `TAX-005 適格請求書計算・表示` と、正式仕様 v2.5 `TAX-012 混在時インボイス集計` の履歴固定部分。

正式仕様では、同一税率の内税・外税混在時に `invoiceAggregationBasis = TAX_INCLUDED / TAX_EXCLUDED` のどちらかへ税率別対価額を統一し、税率ごとに1回だけ税額を記載する。また `sale_txn snapshot` と `invoice_tax_summary snapshot` に会計時の計算条件・確定額・内外税由来額・丸め差を保存し、DB・レシート・CSVで一致させる。

## v1.36 実装

### 会計時に固定する値

`SaleTaxSnapshotStoreV136` を追加し、売上確定と同じSQLiteトランザクション内で以下を保存する。

- `same_rate_mixed_mode_policy_snapshot`
- `tax_rounding_mode_snapshot = FLOOR`
- `tax_round_unit_snapshot = RATE_PER_INVOICE`
- `invoice_aggregation_basis_snapshot`
- 税率別 `taxable_amount / net_amount / tax_amount / gross_amount`
- 税率別 `included_gross_source_amount / excluded_net_source_amount`
- 税率別 `rounding_delta`
- 集計元 `source_tax_keys`

既存 `line_tax_snapshots` は引き続き明細単位の税区分キー、税率、内外税、軽減対象、レシート税記号を保持する。取引全体の計算条件と税率別確定値を今回のsnapshotが補完する。

### 設定

SCR-275「税計算・インボイス設定」に税率別対価額の集計基準を追加した。

- 税込へ統一: `TAX_INCLUDED`（既定）
- 税抜へ統一: `TAX_EXCLUDED`

設定変更は新しい会計にだけ適用する。確定済み売上の再印字では現在設定を参照しない。

### 再印字・履歴

`RegisterDatabase.loadSaleDetail()` はv1.36以降の売上では保存済み税snapshotから `TaxSummary` と `invoiceAggregationBasis` を復元する。したがって税マスタや集計基準を後から変更しても、過去売上の税率別対象額・税額・合計は再計算で変化しない。

v1.35以前などsnapshotを持たない既存売上は、従来の明細税snapshotから計算する互換fallbackを維持し、`taxSnapshotLegacyFallback = true` として内部的に区別できる。

### レシート

税率別対象額は売上時の集計基準を使用する。

- `TAX_INCLUDED`: `10%対象額（税込）` のように税込対価額を表示
- `TAX_EXCLUDED`: `10%対象額（税抜）` のように税抜対価額を表示

商品明細の `内 / 外 / 内※ / 外※ / 非` は既存 TAX-011 の明細snapshotを継続使用する。

### CSV・つぐレジ＋同期

`SaleTaxSnapshotCsvV136` はDBと同じsnapshotから税率別CSV行を生成する固定契約を持つ。SALE journalも売上確定トランザクション内で同じsnapshot値へ拡張し、`invoiceAggregationBasis` と `invoiceTaxes[]` を出力する。

これによりDB、再印字、CSV契約、つぐレジ＋向け同期JSONが別々に税再計算を行わない。

## 自動テスト

`V136SaleTaxSnapshotTest` で以下を固定する。

1. 10%内税1,100円 + 10%外税1,000円を税率10%の1bucketへ統合。
2. `TAX_INCLUDED` は対象額2,200円、`TAX_EXCLUDED` は対象額2,000円。
3. どちらの基準でも税額200円、税込合計2,200円は不変。
4. 同率内外税の未丸め合算で発生する `rounding_delta` を保存。
5. snapshot再構築、CSV、SALE journalが同じ確定額を使用。
6. 再印字レシートが保存済み `TAX_EXCLUDED` を使用し、現在設定へ戻らない。

## 実機確認

この変更では実機確認を完了扱いにしない。最終統合実機受入で以下を確認する。

- SCR-275で税込/税抜基準を切り替えて会計する。
- 会計後に設定と税マスタを変更しても再印字が元伝票と一致する。
- 58mm / 80mmで税率別対象額ラベルと金額が欠落しない。
- つぐレジ＋取込時に `invoiceTaxes[]` がDBと一致する。

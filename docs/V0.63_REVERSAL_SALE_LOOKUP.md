# v0.63 返品・取消 元売上検索

## 目的

返品・取消画面の元売上候補が直近200件に限定されていたため、長期運用後の古い売上を安全に指定できるようにする。

## 方針

- v0.62の `SalesHistoryLookupPolicy` を再利用する。
- 通常候補は直近最大1,000件を表示する。
- 売上No.、担当者、支払方法で候補を絞り込む。
- 一覧上限外の売上は売上No.をSQLiteへ直接照会する。
- 存在しない売上No.では別売上を選択しない。
- 全量返品済み／取消済み売上は既存 `reversedSaleIds()` 判定を維持し、再処理できない。
- 直接指定した古い売上も、既存の `loadReturnableLines()`、`PartialReturnPolicy`、責任者PIN、冪等要求ID、SQLite原子処理へ接続する。
- 元売上・売上明細は更新・削除しない。返品・取消は従来どおり反対取引を追記する。

## 実機確認が必要な項目

- 1,000件より古い売上No.の直接指定
- 部分返品済みの古い売上で残数量だけ返品できること
- 全量返品済みの古い売上が再処理不可になること
- 返品候補検索のソフトウェアキーボード操作
- v0.62→v0.63上書き更新

# つぐレジ v0.56 リリースノート

## バージョン

- つぐレジ: `0.56.0-dev.1` / versionCode `86`
- つぐレジ＋: `0.14.0-dev.1` / versionCode `14`（機能変更なし）
- つぐレジ CD: `0.14.0-dev.1` / versionCode `7`（機能変更なし）

## 主な変更

### 保留伝票の結合・分割安全基盤

開発ロードマップに残っていた保留伝票の結合・分割に着手した。

- 2つの保留伝票を1つへ安全に結合する処理を追加
- 明細ごとの数量指定分割処理を追加
- 一部数量を分割する際の行値引を数量比で按分
- 分割前後を合算した値引額と値引後金額を維持
- 商品ごとの動的税スナップショットを結合・分割後も維持
- 同一伝票結合、数量超過、空分割、全移動を拒否
- 結合・分割はSQLiteトランザクション内で完結
- 途中失敗時はロールバックし、中途半端な伝票状態を残さない

### 累積互換

v0.55までの以下の機能は維持する。

- Googleかんたん接続
- Drive API通常同期
- 互換フォルダ復旧経路
- 同期運用ダッシュボード
- 隔離データ個別再試行
- Outbox個別再試行
- 売上・同期・隔離履歴の非破壊運用
- 印刷、データ保全、税・インボイス、つぐレジ CD

## テスト

新規 `V056HeldTicketMergeSplitTest` で、結合順序、数量分割、値引按分、税スナップショット、異常入力拒否を固定する。

CIでは従来どおり、全累積ユニットテスト、3アプリKotlin compile、3アプリdebug APK build、SHA-256作成、Artifact保存を必須とする。

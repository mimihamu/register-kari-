# v0.84.0-dev.1 リリースノート

## レガシーDB上書き更新のデータ保全

古いSQLite DBからの `SQLiteOpenHelper.onUpgrade()` に残っていた、主要業務テーブルをDROPして再作成する経路を廃止しました。

### 変更点

- POS versionCode `114`
- POS versionName `0.84.0-dev.1`
- `LegacyDatabaseMigrationV084` を追加
- 旧DBはテーブル／列の存在を確認して不足分だけ追加
- 商品・作業中カート・保留伝票・売上を自動DROPしない
- 既存商品マスターがある場合は初期商品を再投入しない
- 旧カートの `line_no` 移行は行をコピーして保持
- 異常な一時移行テーブルが残る場合は自動削除せずfail-closed
- `V084LegacyDatabaseMigrationSafetyTest` を追加

### 維持事項

v0.83以前の販売、税、インボイス、支払、保留伝票、返品・取消、点検・精算、印刷、バックアップ、Google Drive、つぐレジ＋、つぐレジ CDの累積機能は維持します。

### 実機確認

上書き更新の実機試験は未実施です。v0.2／v0.3／v0.4相当DBからの更新、データ保持、更新後の販売・保留呼出・印刷は実機確認が必要です。

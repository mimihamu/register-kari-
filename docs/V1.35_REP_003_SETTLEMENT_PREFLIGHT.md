# v1.35 REP-003 精算前確認

## 仕様の再確認

詳細仕様書 v2.5 の REP-003 は、X点検の読取専用化ではなく **Z精算前の未処理確認** である。

精算前に次の5項目を表示し、警告項目ごとに継続可否を決める。

1. 未会計伝票
2. 未完了決済
3. 未印刷
4. バックアップ失敗
5. 現金実査未入力

REP-001 のX点検は別要件であり、期間を締めずに現在値を出力する既存経路を維持する。X点検では営業セッションを終了しない。

## v1.35 実装

### 精算前確認モデル

`SettlementPreflightCategoryV135` で上記5項目を固定し、`SettlementPreflightContinuationV135` で各項目の継続方針を明示する。

| 項目 | 検出元 | 継続方針 |
|---|---|---|
| 未会計伝票 | `held_tickets` + 現在の `cart_items` | 解消必須・継続不可 |
| 未完了決済 | 現在カートに対応する `payment_draft_meta` | 解消必須・継続不可 |
| 未印刷 | `print_jobs` + `document_print_jobs` の未完了件数 | 責任者が明示確認した場合のみ継続可 |
| バックアップ失敗 | `AutoBackupStatusStore` の直近結果 | 責任者が明示確認した場合のみ継続可 |
| 現金実査未入力 | Z精算画面の現金実査入力 | 入力必須・継続不可 |

`FAILED` に加えて容量不足で実行できなかった `SKIPPED_LOW_STORAGE` もバックアップ失敗警告として扱う。

### 二重の実行防止

画面側だけでなく、`OperationsStore.recordSettlement()` のDBトランザクション内で営業セッションと集計値を再取得し、5項目を再評価する。

したがって、画面表示後に未会計伝票・未印刷等が変化しても、Z精算の固定保存直前で再判定される。`preflight.mayProceed` が false の場合、`settlement_reports` への保存や営業終了には進まない。

### 継続可能な警告

未印刷とバックアップ失敗は、責任者PINに加えてそれぞれ個別の確認チェックを要求する。片方だけ確認しても、もう一方が未確認ならZ精算は実行できない。

確認して継続した場合は監査履歴へ以下を追記する。

- `Z_SETTLEMENT_PENDING_PRINTS_ACKNOWLEDGED`
- `Z_SETTLEMENT_BACKUP_FAILURE_ACKNOWLEDGED`

未会計伝票・販売途中取引、未完了決済、現金実査未入力には確認による迂回経路を設けない。

### X点検の復元・維持

前段で一時的に入った「REP-003=X点検を固定保存・印刷しない」という解釈は誤りだったため、その差分は取り消した。

現在のX点検は、REP-001に従い以下を維持する。

- 営業期間を締めない。
- 現在の営業セッション値から点検レポートを作成する。
- `settlement_reports` に点検レポートを保存する。
- 点検帳票の印刷ジョブを作成する。
- X点検後も営業セッションをOPENのまま維持する。

PDF保存要件の完全性はREP-001として別途初回リリース差分監査を行う。

## 自動試験

`V135SettlementPreflightRep003Test` で次を固定する。

- 5項目が常に同一順序で評価される。
- 未会計保留伝票・販売途中カートは継続不可。
- 未完了決済は継続不可。
- 未印刷は明示確認後のみ継続可能。
- バックアップ失敗は明示確認後のみ継続可能。
- 現金実査未入力は継続不可。
- 複数の確認可能警告がある場合は全項目の確認が必要。
- Storeが5項目の状態を収集し、固定保存より前に再評価する。
- X点検の保存・印刷・営業継続経路を維持する。
- 通常管理画面とレスポンシブ精算画面の双方がREP-003状態を表示する。

## 実機確認として残す項目

- 保留伝票がある場合、未会計伝票が警告されZ精算できない。
- 販売画面に未確定カートが残る場合、販売途中取引として警告されZ精算できない。
- 支払入力途中で精算へ移動した場合、未完了決済として警告される。
- 未印刷だけが残る場合、未確認では進めず、責任者確認後に進める。
- 直近バックアップ失敗状態では警告され、責任者確認後にのみ進める。
- 未印刷とバックアップ失敗が同時にある場合、両方の確認が必要。
- 現金実査未入力ではZ精算確認へ進めない。
- 画面確認後から確定直前までに状態が変わった場合、Store側の再判定で不正確定しない。
- 警告確認を経てZ精算した場合、監査履歴に確認記録が残る。
- X点検は帳票を保存・印刷しても営業を終了せず、販売を継続できる。

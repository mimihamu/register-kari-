# v0.71 Release Notes

## 通常レシート再印字台帳 期間検索・時系列索引

- SCR-648に全期間 / 今日 / 7日以内 / 30日以内の期間フィルタを追加。
- 期間境界を `requested_at >= ?` のバインド条件でSQLiteへ渡す。
- 状態・期間・文字列条件をDB側で組み合わせる。
- 全売上横断の時系列検索向けに `requested_at DESC, id DESC` 索引を追加。
- 期間変更時は先頭ページへ戻す。
- 5秒更新では適用済み条件と現在ページを維持。
- 監査履歴の追記専用性と統合印刷キューへの復旧集約を維持。

大量履歴での実機性能、日付境界、タイムゾーン変更時の挙動は未確認です。

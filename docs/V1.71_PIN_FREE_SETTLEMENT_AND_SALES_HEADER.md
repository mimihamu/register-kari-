# v1.71 販売ボタン・PINなし責任者のZ精算

- 販売画面のヘッダーから「レジマイナス」のショートカットを撤去。レジ管理→レジマイナスは維持する（独立負数台帳、承認、返金、レシート機能は従来どおり）。
- PINを使わないログインが許可された責任者は、現在のログインセッションとDB登録（role=MANAGER、enabled=1、pin_required=0）による検証でZ精算を承認できる。
- 新旧2つのZ精算画面は、PINなし責任者のセッション承認が成立した場合、PIN欄を非表示にして「責任者承認済み（PIN不要）」と表示する。
- バックエンドは実行時にZ_SETTLEMENT権限と責任者承認を再検証。一般担当者（PINなしを含む）の責任者承認の省略は許可しない。
- PINなし責任者の認証を古いPIN欄の内容より優先し、PIN設定を外したあとに残る入力の影響を防止。
- 現金実査額の入力、未会計・未完了・未印刷・バックアップ失敗の精算前確認は従来どおり必要。PIN不要と精算前チェック不要は異なる。
- 実機受入：PINなし責任者のZ精算、一般担当者拒否、PINあり責任者、現金実査0円、商品画面のボタン削除。

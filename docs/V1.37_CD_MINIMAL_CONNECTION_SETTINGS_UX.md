# CD接続設定：レイアウトが導く画面

操作の順番は「接続先」→「レジを探す」→候補を選び「接続」。検索が使えない場合だけ「IP・トークンで設定」を開く。IP/ポート/トークンの必須ラベルと入力エラーは残し、説明文、通信パスの常時表示、重複する見出しを撤去した。

- レジ検索が主ボタン（全幅）、手動設定は二次ボタン。見つかったレジは店名を大きく、アドレスを小さく表示する。
- 小画面は項目の縦並び、大画面はホスト・ポートを一行にする。誤入力は入力欄の直下で短く表示する。
- 初期設定が無い場合でも手動入力を開ける。再検索・手動入力の切替では進行中のNSDを停止する。
- 必須の状態情報と誤操作を防ぐ案内だけは必要な位置で残す。アプリの通信仕様、認証、データ保持方式は変更しない。

※見た目の簡素化はアクセシビリティラベルや操作上のフィードバックを無くす意味ではない。実機で小型/横長タブレットのスクロール・入力欄のソフトキーボード被りを確認すること。

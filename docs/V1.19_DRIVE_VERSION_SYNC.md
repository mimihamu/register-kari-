# v1.19 Drive server version fingerprint

つぐレジ＋のGoogle Drive差分同期で、未変更判定の根拠を強化する。

- Drive一覧からserver `version` を取得する。
- 保存済み `remote_version` と現在versionが一致する場合だけdownloadを省略する。
- versionが未保存または取得できない場合はdownloadし、SHA-256で内容を確認する。
- `modifiedTime` は保持するが、単独の未変更判定には使用しない。
- ManagementDatabaseはversion 6とし、`drive_sync_files.remote_version` をnullable列で保持する。
- 既存DBの行はremote version未保存のため、v1.19初回同期で内容hashを再確認する。

Version:
- つぐレジ: 149 / 1.19.0-dev.1
- つぐレジ＋: 18 / 0.18.0-dev.1
- つぐレジ CD: 7 / 0.14.0-dev.1

正式CIでは累積unit test、3アプリKotlin compile、3 APK build、APK identity・SDK・launcher・ZIP・v2署名、Artifact、SHA-256独立再計算まで確認する。実アカウントDrive同期と実端末DB v5→v6移行は最終総合実機試験へ繰越す。

# v0.81 Release Notes

## 点検・精算 整合確認監査台帳

- `SCR-521 整合確認監査台帳` を追加
- SCR-520の整合確認エリアから監査台帳へ遷移
- `operation_audit` の `SETTLEMENT_RECONCILIATION_%` を読み取り専用で一覧表示
- OK / INFO / ALERT の件数・フィルターを表示
- レポートNo.、担当者、営業日、営業セッションを検索可能
- 新しい監査から順に表示
- v0.79で保存した比較証跡を詳細表示
- 閲覧は `VIEW_SALES` と `X_INSPECTION` または `Z_SETTLEMENT` を要求
- 画面表示中もログインセッションを再確認
- 監査・売上・税・支払・点検精算データへのUPDATE/DELETEは行わない
- v0.79の監査追記fail-closed、v0.80のレスポンシブ整合確認を維持

## 累積テスト保守

v0.80のテストから「v0.80が現在版であること」という版番号・Artifact名固定を除去し、v0.80機能の意味検査は維持した。これにより次版以降でも旧機能テストが現行バージョン更新だけを理由に失敗しないようにした。

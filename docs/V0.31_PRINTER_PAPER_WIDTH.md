# v0.31 印字幅のプリンタ設定一本化

## 1. 決定事項

印字幅はプリンタ設定で固定する。

- 選択可能値はプリンタ設定画面の58mm／80mmのみ
- 会計、売上再印字、返品・取消、X点検、Z精算、点検・精算履歴再印字では幅を指定しない
- 各印刷要求は、要求作成時点のプリンタ設定から幅を自動取得する
- 印刷ジョブには、その要求で採用した設定幅を再試行用スナップショットとして保持する
- 既存の印刷ジョブとデータベース列は互換性のため維持する

## 2. 画面仕様

### プリンタ設定

58mm／80mmを選択して保存できる。ここが印字幅の唯一の変更箇所となる。

### 印刷・再印字画面

幅選択ボタンを表示しない。代わりに次の形式で参照中の設定を表示する。

`印字幅：プリンタ設定 80mm（この画面では変更できません）`

## 3. 実装方針

`PrinterPaperSettingPolicy`で設定値の正規化と`ReceiptPaper`への変換を一元化する。

次の公開APIから`paperWidthMm`または`ReceiptPaper`引数を削除する。

- `RegisterDatabase.saveSale`
- `RegisterDatabase.enqueueReprint`
- `OperationsStore.createReversal`
- `OperationsStore.previewSettlement`
- `OperationsStore.reprintSettlement`
- `SecureOperationsCoordinator.createReversal`
- `SecureOperationsCoordinator.reprintSettlement`
- `EscPosEncoder.encode`

下位の帳票レンダラーと印刷ジョブ保存列は、設定から自動決定された幅を受け取る内部実装として維持する。

## 4. 互換性

- 既存の`print_jobs.paper_width_mm`を維持する
- 既存の`document_print_jobs.paper_width_mm`を維持する
- 既に待機中のジョブは保存済みの幅と帳票文字列を使用して再試行する
- プリンタ設定以外の業務データ構造、税計算、権限、監査ログは変更しない

## 5. 実機確認

以下は実機確認前のため未確認とする。

- プリンタ設定58mm時のレシート、返品・取消票、X点検票、Z精算票
- プリンタ設定80mm時の同帳票
- 設定変更後に作成した新規印刷ジョブへ幅が反映されること
- 既存待機ジョブの再試行結果
- 58mm／80mm実紙での欠け、折返し、カット位置

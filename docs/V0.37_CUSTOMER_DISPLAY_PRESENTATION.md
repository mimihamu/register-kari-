# v0.37 つぐレジ CD 表示設定・状態復元

## 目的

つぐレジ CDの待機・販売・会計・完了画面を店舗ごとに調整できるようにし、
設定はつぐレジからWebSocketの状態スナップショットへ含めて同期する。

## 表示設定

- 背景プリセット: 紺、明るい、和風
- ロゴ表示ON/OFF
- ロゴ文字（最大12文字）
- 文字倍率: 80～150%
- 表示行数: 3～20行
- 行間: 0～24dp
- 取消商品の表示ON/OFF
- 税記号の表示ON/OFF
- 待機メッセージ（最大80文字）

設定正本はつぐレジ側であり、CD側は受信した表示プロファイルを使用する。
外部資格情報、Google API、クラウドサービスは使用しない。

背景プリセット変更時は待機画面の主文字、副文字、強調文字もテーマ連動で切り替える。
販売・会計・完了画面の情報カードは従来の濃色配色を維持し、金額と商品情報の視認性を優先する。

## 通信互換性

`schemaVersion=1`を維持し、以下を任意フィールドとして追加する。

- 最上位 `presentation`
- 明細 `taxSymbol`

旧CDは未知フィールドを無視して従来表示を継続できる。
新CDは旧形式で`presentation`や`taxSymbol`がない場合に安全な初期値を使用する。

## 状態復元

CDは正常受信した最新スナップショットを端末内SharedPreferencesへ保存する。
30分以内の保存状態だけを起動時に復元し、通信断中は古い金額を顧客へ表示しない。
WebSocket接続成立後は保存状態を一時的に利用し、直後にレジから届く最新状態で更新する。

既存の3秒瞬断表示抑止、4秒接続セッション保持、500ms高速再接続、
15秒Heartbeat、serverInstanceIdによるレジ再起動検出は変更しない。

## 実機確認が必要な項目

- 3種類の背景と各画面の視認性・背景別コントラスト
- 文字倍率80～150%での欠け、重なり、操作到達性
- 表示行数、行間、最新商品追従
- 取消表示ON/OFFと税記号
- 待機メッセージ、ロゴ表示
- つぐレジ設定保存後のCD同期
- CD強制終了・再起動後の30分以内状態復元
- 30分超のキャッシュを表示しないこと
- 1～2秒Wi-Fi瞬断、3秒超切断、復旧
- レジ再起動、CD再起動、端末回転
- メーカー固有省電力制御下での再接続

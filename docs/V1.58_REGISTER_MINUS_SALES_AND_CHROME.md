# v1.58 レジマイナス・販売バー統一

- つぐレジ販売画面の上部操作を紺背景＋白文字の透過ボタンで統一。白い帯状ボタンを撤廃。
- 販売画面上部とレジ管理画面に「レジマイナス」を配置。REVERSAL権限が必要。
- レジマイナスは通常販売画面の**同じ商品配置・数量テンキー・検索**を使用し、赤色上部バーと薄赤背景で通常販売と区別。
- 独立した一時カートを使う。通常の販売カート・会計草稿・売上原本へは書き込まない。
- 商品数量および会計金額はマイナス記号で表示。返品の理由は任意。
- 返金方法選択 → マイナス数量・金額確認 → 責任者承認 → 確定。二重送信防止を維持。
- DBは従来の `ManualReturnCoordinatorV135` / `ManualReturnStoreV135` を経由し、`manual_return_transactions` / `manual_return_items` / `manual_return_payments`、監査・印刷ジョブ・現金ドロアを維持。
- 非現金返金は決済端末側で別途返金操作・完了照合が必要。POSだけで返金が完了したとは表示しない。
- 未確定カートを破棄する前に確認。権限のない担当者には操作を開かない。
- 通常売上件数を直接マイナスにはしない。負の金額・商品数量とマイナス件数は返品台帳として分け、純売上へ合算する既存契約を維持。
- 画面目視、800×480/960×600/1280×800、フォント1.3、キャッシュドロア、外部決済端末、実機印刷は最終受入に繰り越す。

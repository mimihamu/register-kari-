# つぐレジ v0.33.0-dev.1 リリースノート

## 追加

- 毎日／7日ごとの定期内部バックアップ
- 実行時刻設定（0〜23時）
- Z精算バックアップ保持営業日設定（1〜90日）
- 定期バックアップ保持月数設定（1〜36か月）
- バックアップ失敗・容量不足のAndroid通知
- 通知権限確認とAndroid通知設定への導線
- データ保全画面への次回予定、周期、保持設定表示
- 定期バックアップ設定変更の監査ログ

## 維持

- Z精算正常確定後の自動バックアップ
- 手動バックアップ、外部保存、外部取込、安全な復元
- バックアップSHA-256、SQLite整合性検査、原子的確定
- 手動・外部取込・復元予約中バックアップの保護
- 容量不足でZ精算結果を巻き戻さない仕様
- Google Drive API未使用、Storage Access Frameworkによる手動外部保存

## バージョン

- つぐレジ：`0.33.0-dev.1` / versionCode `63`
- つぐレジ CD：`0.13.0-dev.6` / versionCode `6`

## 実機未確認

WorkManagerの実行時刻、端末再起動後の継続、バッテリー・容量制約、Android通知、実ファイル世代整理は実機確認が必要であり、CI成功だけで確認済みとはしない。

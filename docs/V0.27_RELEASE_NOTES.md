# v0.27.0-dev.1 リリースノート

## 追加

- 営業セッション別の点検・精算履歴画面
- X点検／Z精算フィルター
- 点検・精算時点の開始釣銭、入出金、支払別金額の完全スナップショット
- X点検票／Z精算票の初回自動印刷ジョブ
- 履歴からの58mm／80mm再印字
- 再印字表示、再印字日時、再印字担当者
- Z精算票再印字時の責任者PIN確認
- SETTLEMENT_REPRINT監査ログ

## 互換性

- v0.26以前の点検・精算レコードは維持する
- 旧レコードに保存済み帳票payloadがあれば再印字可能
- 完全スナップショットも保存済みpayloadもない旧レコードは、不正確な再計算をせず再印字不可とする
- X点検権限とZ精算権限の分離を維持
- Z精算前チェック、営業終了、自動バックアップを維持

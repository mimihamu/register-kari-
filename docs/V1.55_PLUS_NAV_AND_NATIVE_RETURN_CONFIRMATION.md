# v1.55 つぐレジ＋ナビ統一／ネイティブ返品確定の安全化

正式仕様: REGISTER（仮）_Androidレジ_詳細仕様書_v2.5。作業先 `develop/v1.36`、Draft PR #140、初版完成 Issue #137。main直接変更・merge不可。

## つぐレジ＋の共通操作

- `PlusTopBarV155.kt`: 紺 `#173F6B`、白字「つぐレジ＋」、左上「戻る」、タイトル省略対応、高さ64dp。Android 15のステータスバー回避は既存 `PlusSafeAreaV148` と併用。
- Google Driveかんたん接続、アカウント、運用セットアップ・復旧、診断・ログ、初期設定、売上同期検証・復旧の**6画面**を共通バーへ統一。
- 上部ナビは固定し、内容領域のみスクロール。画面右端・本文上部の「戻る」や長い冗長説明を廃止。
- つぐレジ＋アカウントは「登録／変更」「今すぐ同期」を上位に集約。接続テスト、全件再取込、連携解除などの詳細操作は開閉式とし、既存コールバックは維持。
- 運用復旧の詳細なDrive API／互換フォルダ／実機6項目確認は開閉式。通常画面には現状・選択モード・一括適用・安全確認を残す。取込済みデータの削除は行わない。

## 手動返品（元取引なし返品）

- 旧ネイティブ画面に紺バー・左上戻るを設置し、画面下部の重複戻るを削除。
- 「返品を確定」押下で即時DB保存していた動線を、**返品商品件数・返金合計・返金方法を再確認する非自動閉鎖ダイアログ**へ変更。
- 危険な確定は赤い「返品を確定」、もう一方は「キャンセル」。画面外タップで閉じない。ダイアログ表示前に明細と税計算・金額を検証。
- DBトランザクション、責任者承認とPIN任意設定、`ManualReturnSubmissionGateV135`による二重送信防止、印刷ジョブ、台帳・履歴・監査は維持。
- 現金以外の実端末返金をつぐレジが自動処理したかのように表示しない。

# v0.71 再印字台帳 期間検索・時系列索引

## 目的

v0.70で通常レシート再印字台帳を全履歴対象のSQLite直接検索へ変更しました。長期運用では全期間のCOUNT・LIKE検索を毎回行う必要がないケースが多いため、v0.71では再印字要求日時でDB側を先に絞る期間フィルタと、全売上横断の時系列表示に適した索引を追加します。

## 期間フィルタ

- 全期間
- 今日
- 7日以内
- 30日以内

「今日」は端末ローカルタイムゾーンの0:00を境界にします。7日／30日は現在時刻からの経過時間で判定します。

## SQL

期間指定時は `r.requested_at >= ?` をWHERE句へ追加します。境界時刻はSQL文字列へ埋め込まず、バインド引数として渡します。

状態・期間・文字列検索は同一WHERE句へAND条件で組み合わせます。

## 索引

既存:

- `idx_sale_receipt_reprint_sale_time(sale_id, requested_at DESC, id DESC)`

追加:

- `idx_sale_receipt_reprint_requested_time(requested_at DESC, id DESC)`

既存索引は1売上のSCR-647履歴表示向け、新索引は全売上横断のSCR-648時系列検索向けです。`CREATE INDEX IF NOT EXISTS`による追加型変更で、既存データは削除しません。

## UI

SCR-648に「期間」行を追加します。期間変更時はoffsetを0へ戻し、選択行を解除します。5秒更新では現在の適用済み期間・状態・検索文字列・ページを維持します。

## データ保護

監査履歴、売上、税、支払、印刷jobの更新・削除APIは追加しません。FAILED/RETRYの復旧は引き続き統合印刷キューだけで行います。

## 実機未確認

大量履歴に対する索引効果、今日境界をまたぐ連続表示、端末タイムゾーン変更時の挙動は実機未確認です。

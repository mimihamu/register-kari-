# v1.36 #32 PRN-PREVIEW-002 コピー／無効化／エラー導線

## 正式仕様との突合

Issue #137 の `PRN-PREVIEW-002` は正式仕様 v2.5 の独立要件 ID ではないため、名称だけから新しい印刷仕様を作らない。

正式仕様 v2.5 で根拠となる範囲は以下。

- SCR-640 は 58mm / 80mm の印刷プレビューを持つ。
- §16.10 `ReceiptLayoutConfig` は文書別の `copies` を保持する。
- 既存 RCP-016 実装では点検票／精算票のみ部数 0 を許可し、「電子保存のみ」として扱う。
- 自動印刷 OFF は文書自体の無効化とは別であり、手動印刷可能な状態として扱う。
- レシート店舗固定文は保存時と同じ制約で検証し、不正な設定を正常なプレビューとして見せない。

## 実装

`DocumentPrintPreviewPolicyV136` / `DocumentPrintPreviewStateV136` を追加し、保存前プレビューに次の状態を明示する。

- 1～3部: `プレビュー: 印刷部数 N部`
- 点検票／精算票の0部: `印刷無効（電子保存のみ）`
- 自動印刷 OFF: `自動印刷OFF（手動印刷可）`
- レシート店舗固定文が不正: プレビュー生成を失敗させ、保存時と同じ理由に `設定項目を修正してください` を付けて画面の既存エラー表示へ渡す。

0部を許可しないレシート／領収書／仮締め票は既存ポリシーどおり1部へ正規化する。自動印刷 OFF を「印刷無効」と誤表示しない。

状態表示は画面プレビュー専用で、ESC/POS の印字本文には追加しない。実印刷の複数部制御は既存の本番経路を変更しない。

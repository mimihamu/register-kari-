# つぐレジ v0.38.0-dev.1 リリースノート

## 売上ジャーナル外部送信の運用強化

外部自動送信設定へ店舗向け運用ダッシュボードを追加した。

- `PENDING`、`PROCESSING`、`RETRY`、`STAGED`、`SENT`、`FAILED`の状態別件数
- 未送信合計
- 最終送信成功時刻と直近エラー
- 直近Outbox一覧
- 失敗データの個別再試行
- 端末内JSONプレビュー、サイズ、SHA-256
- 送信先フォルダの書込・再読込・一時ファイル削除テスト
- 外部送信監査履歴

個別再試行は`FAILED`だけを対象とし、端末内JSONの有無に応じて`STAGED`または`PENDING`へ安全に戻す。
送信先テストで作成する一時ファイルは削除まで検証する。

## 既存機能

v0.31～v0.37の印刷幅固定、統合印刷キュー、定期バックアップ、外部バックアップ複製、
Outbox外部配送、売上JSON固定契約、つぐレジ CD表示設定・状態復元を累積維持する。

## 実機未確認

Google Drive、USB、端末フォルダでの送信先テスト、個別再試行後の実送信、
JSONプレビュー表示、容量不足、URI権限失効、USB抜差し、Doze後の継続は実機確認が必要。

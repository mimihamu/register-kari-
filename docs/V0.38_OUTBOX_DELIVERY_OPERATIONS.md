# v0.38 売上ジャーナル外部送信 運用ダッシュボード

## 目的

v0.35で追加した外部自動送信を、店舗担当者が状態確認・原因切分け・復旧できる画面へ拡張する。
SQLiteと`sales_journal`を正本として維持し、本画面の操作で売上、返品、点検、Z精算、印刷を巻き戻さない。

## 状態別件数

画面には次の6状態を個別表示する。

- `PENDING`: JSON生成待ち
- `PROCESSING`: JSON生成中
- `RETRY`: JSON生成再試行待ち
- `STAGED`: 端末内JSON完成、外部送信待ち
- `SENT`: 外部ファイルの検証完了
- `FAILED`: 最大試行回数到達、管理者対応待ち

未送信合計は`PENDING + PROCESSING + RETRY + STAGED`とする。

## 直近データ

直近30件について営業日、イベント種別、objectKey、状態、試行回数、更新時刻、エラーを表示する。

### 個別再試行

- `FAILED`だけを対象とする。
- 端末内JSONが存在する場合は`STAGED`へ戻す。
- 端末内JSONがない場合は`PENDING`へ戻し、JSON生成から再実行する。
- 試行回数、次回実行時刻、エラー、Workerリース情報を初期化する。
- 操作を`SYNC_OUTBOX_ITEM_RETRY_REQUESTED`として監査記録する。

### JSONプレビュー

- アプリ専用`drive-sync-staging`配下だけを参照する。
- canonical pathを検査し、ディレクトリ外参照を拒否する。
- 最大20MiBのJSONだけを対象とする。
- 画面表示は先頭64KiBまでとし、全ファイルのサイズとSHA-256を表示する。
- JSONの編集・削除機能は提供しない。

## 送信先テスト

選択済みStorage Access Frameworkフォルダ直下へ一時JSONを書き込み、次を検査する。

1. 永続書込権限
2. 一時ファイル作成
3. 全バイト書込み
4. 再読込内容一致
5. SHA-256算出
6. 一時ファイル削除

テストファイルは`tsuguregi-v038-write-test-<時刻>.json.partial`とし、成功・失敗を監査記録する。
テストはDocumentsProviderの書込・読込・削除確認であり、Google Driveアプリ側のクラウド同期完了までは確認しない。

## 監査履歴

`operation_audit`から`SYNC_OUTBOX_%`の直近20件を表示する。
対象には送信成功、重複スキップ、送信失敗、権限失効、一括再試行、個別再試行、送信先テストを含む。

## 実機確認が必要な項目

- Google Drive、USB、端末フォルダでの状態表示
- 大量Outbox時の一覧表示と操作性
- 個別再試行後の実送信
- JSONプレビューの文字化け・長文表示
- 各DocumentsProviderでの送信先テストと一時ファイル削除
- USB抜差し、容量不足、URI権限失効時の表示
- Google Driveアプリ側のクラウド同期完了
- 再起動、Doze、メーカー固有省電力制御後の状態更新

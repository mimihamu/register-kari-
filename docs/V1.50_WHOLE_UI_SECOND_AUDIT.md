# v1.50 全画面UI再監査（第2巡）・販売画面・詳細設定簡素化

正式仕様: REGISTER（仮）_Androidレジ_詳細仕様書_v2.5
作業ブランチ: develop/v1.36 / Draft PR #140 / Issue #137。main直書き・mergeは禁止。

## 活動

Kotlinソース上のActivity 45画面を走査し、以下の観点で横断確認した。
1. 紺色（#173F6B）背景の上部バー、Androidのシステムバーとアイコンの重なり。
2. 戻る／閉じる／保存／取消・操作位置、販売画面の操作部が白い行に残っていないか。
3. 横800×480の２列と短い縦サイズでの画面内スクロール。
4. レシート、支払方法、店舗・販売・営業日・端末、担当者権限、プリンター設定の冗長情報・常時表示の詳細オプション。

前回v1.48の管理アプリ9・CD2画面のソース監査結果も継続管理し、3アプリ計56の入口画面が監査対象。ただしCompose内の全ダイアログ・設定サブパネル・端末画面の目視受入は別工程。

## 実装済み

- **商品を打つ販売画面**: 48dpの白い二段目バーを削除し、共通紺上部バーに「担当」「レジ管理」「設定（権限時）」「担当切替」を統合。権限制御・アクセス警告を保持。画面幅が狭い場合もテキスト長を制約して主要ボタンのスペースを確保。固定の「サンプル居酒屋」等の実店舗と無関係な文言を撤廃。
- **レシート設定**: 基本／詳細の1画面切替。詳細内に文書別印字条件・58/80mmプレビュー・文字/画像スタンプを維持。自動発行と印字項目設定、保存、登録番号/店舗情報への導線は基本に保持。
- **店舗・販売・営業日・端末設定**: 共通「詳細設定」の開閉を設置。普段使う選択（店舗名・住所、販売入力、営業日、画面維持、音、更新）を手前に出し、通貨など変更不可情報、伝票番号上限、特殊許可、キオスク、高度な容量しきい値を詳細に移動。既存の保存と監査・安全条件は維持。
- **支払方法設定**: 一覧では有効・無効と順序を優先。レシート表示名・過入金・釣銭・ドロア設定・端末状態は各決済方法の「詳細」に畳む。固定・未実装の自動決済端末連携は有効にしない。決済結果を外部端末で確認する注意を維持。
- **担当者・権限設定**: 従来3枚の固定幅の「一覧/編集/権限」パネルを廃止。通常は幅配分した一覧+編集の2枚、必要時だけ権限編集に切り替える。変更後に元画面で保存するよう明示。既存ロール・PINの任意設定・権限・保存・監査ロジックは維持。
- **プリンター・ドロア設定**: 大きな右側の適用内容・内部処理説明を除去し、接続/用紙/機種/ドロア/保存/テスト操作を全面表示。文書ごとの既定プリンター割当は「文書別出力先の詳細」に収容。複数台割当のデータ・監査・印刷送信の安全条件は変更しない。
- **保守の旧バー**: プリンター状態診断、RAWプローブ、連続印刷試験、通知設定の上部を共通 `RegisterTopBarV141` に統一し、左上に戻る。プローブ・連続印刷中の離脱制限を残す。
- `V150WholeScreenSettingsUsabilityTest.kt` に白バー再発・開閉・保存入口・テスト中離脱制限の回帰チェックを追加。

## 現状を完成としない項目

ソース巡回で、ほかにも独自描画ヘッダーがある。例：外部バックアップ、Google Drive設定各種、レシート再印字・領収書・台帳・整合監査、精算/精算履歴、印刷キュー、詳細プリンタ解析など。ステータス色が紺でも、戻る位置やボタンの間隔は統一途上。

またCompose内の全子画面やダイアログ（`MODAL-001`）・全設定の情報階層・フォント倍率1.3倍・800×480/960×600/1280×800実機操作・画面遷移での入力保持・TalkBackは未受入。コード上のソースゲートを通過しても「全画面目視UI完成」とは断定しない。

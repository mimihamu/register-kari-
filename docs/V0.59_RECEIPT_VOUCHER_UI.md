# v0.59 領収書発行・再発行 操作UI

## 目的

v0.58で追加した領収書の追記専用安全基盤を、つぐレジの日常運用から操作できるようにする。

## 導線

レジ管理メニューに「領収書発行」を追加する。

利用には売上確認権限（`VIEW_SALES`）を必要とする。

## 発行操作

1. 対象の売上No.を選択する。
2. 売上合計、領収済み金額、発行可能残額を確認する。
3. 宛名、但し書き、1枚の金額、枚数を入力する。
4. `1枚金額 × 枚数 = 発行合計` を画面上で確認する。
5. 「発行内容を確認」を押す。
6. 最終確認カードで「発行を確定」を押す。
7. v0.58の`ReceiptVoucherStore.issueBatch()`へ要求を渡し、既存統合印刷キューへ登録する。

例：宴会で4,000円を30名分発行する場合は、`4,000円 × 30枚 = 120,000円`として1回の原子的バッチで登録する。

## 一部領収

発行済み金額は削除・上書きしない。

`売上合計 - 発行済み金額 = 発行可能残額`として表示する。発行合計が残額を超える場合はUIで確定操作を無効化し、ドメイン側のv0.58検証でも拒否する。

「残額全額」では現在の発行可能残額を1枚の金額へ設定し、枚数を1枚にする。

## 二重発行防止

発行画面は要求ごとにUUIDを生成し、確定後に新しいUUIDへ更新する。同一要求IDが再送された場合はv0.58のidempotency処理を使用する。

## 再発行

売上に紐付く既存領収書履歴を表示する。

再発行は「再発行」→「再発行確定」の二段階操作とし、元履歴は削除しない。印字には`【再発行】`を付け、再発行イベントを追記する。

## データ保護

以下はこのUIから削除・変更しない。

- 元売上
- Sales Journal
- Drive上JSON
- 同期fingerprint
- SENT済みOutbox
- 領収書発行履歴
- 領収書再発行履歴
- 統合印刷キューの完了履歴

## 実機確認が必要な項目

CIでは以下を確認済みとは扱わない。

- 実タブレットでの横画面レイアウト
- ソフトウェアキーボード表示時の操作性
- 実プリンターへの複数枚連続印字
- 58mm／80mmの実紙面
- 紙切れ・通信断時の復旧
- v0.58からv0.59への上書き更新

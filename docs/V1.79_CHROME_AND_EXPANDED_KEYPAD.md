# v1.79 POS上部バーと拡大テンキー

- レジマイナス画面：Androidステータスバー、ナビゲーションバー、Compose安全領域、販売画面内タイトルバーの赤色を#B42318に統一。システムバーはアイコンを白のまま表示。
- 通常POSの共通タイトルバー：フォント倍率120%以上で68dp以上、150%以上で76dp以上の高さを確保。その他は従来の画面サイズ別高さを維持。
- Androidの小型横画面用に拡大テンキーを追加。既存販売・担当PIN・会計のテンキーのコールバックを**そのまま再利用**し、独自の会計・返品DB処理は実装しない。
- 拡大表示は「拡大」操作で開き「閉じる」で元の画面へ戻る。実際の画面高でキー寸法を計算。足りない場合はダイアログの数字領域のみスクロール。
- v1.79はユニット・ソース検査、Kotlin compile、3 APK署名/ハッシュを確認する。Android15実機（800×480、1024×600、120/150%フォント倍率、ジェスチャー/3ボタン）は未受入。

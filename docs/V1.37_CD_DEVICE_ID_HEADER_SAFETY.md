# CD端末IDの永続性と安全なWebSocketヘッダ

- CD起動時の復元IDはUUIDの正式8-4-4-4-12形式で検証する。不正なIDは新しいUUIDで置き換える。
- 接続先IP・トークンの設定を保存する操作ではCD自身の端末IDを書き換えない。正しい既存IDだけを維持。
- WebSocketリクエストのX-Tsuguregi-CD-Device-Idは正式UUIDのときのみ送出。HTTPヘッダへの不正改行混入を防止。
- POSは受信側でもUUID形式で検証済み。端末IDは識別情報であり承認/失効のための秘密情報ではない。
- データ消去・端末変更で新UUIDとなりうる。正式な端末引継ぎ/失効運用の設計は別途。

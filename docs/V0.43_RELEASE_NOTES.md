# v0.43 リリースノート

## 概要

つぐレジ＋のGoogle Driveフォルダ連携を運用しやすくするため、接続診断、提供元表示、権限失効検知、起動時差分取込を追加した。

v0.42で追加した取込フォルダ・差分一括取込を維持し、その接続状態を利用者がスマートフォン縦画面から確認できるようにした。

## つぐレジ＋の変更

### Google Drive・DocumentsProvider接続診断

- 登録URIの提供元アプリを表示。
- Google Driveかどうかを提供元パッケージ・表示名から判定。
- 永続読取権限の有無を確認。
- 登録フォルダのドキュメント情報を実際に読み取り、利用可能か確認。
- 診断日時と詳細メッセージを表示。

### 接続状態

- 未登録
- 診断中
- 接続済み
- 永続権限失効
- 提供元アプリ利用不可
- フォルダ読取失敗

接続済み以外では、差分取込と全件再確認を無効にする。

### 再接続

永続権限が失効した場合や、Google Driveアプリ・アカウント・フォルダの状態が変わった場合に、同じ画面からフォルダを選び直せるようにした。

### 起動時差分取込

- 初期値は有効。
- アプリ起動時に接続診断を実行。
- 接続済みの場合だけ差分取込を開始。
- 前回開始から10分以内は自動取込を再実行しない。
- 設定スイッチで無効化可能。

### 画面表示

- `Drive／フォルダ登録`
- `接続診断`
- `提供元`
- `永続読取権限`
- `起動時に差分取込`
- `再接続`
- Google Drive選択時の設定案内

## Google Drive REST APIについて

v0.43ではDrive REST API、OAuth 2.0、Google Cloudプロジェクトは使用しない。

Android Storage Access Frameworkを使用し、利用者が選んだフォルダだけを読み取る。

アプリ終了中の確実な同期、Driveフォルダの自動作成、Googleアカウント単位の中央管理が必要になった場合にDrive REST APIまたは管理サーバー方式を検討する。

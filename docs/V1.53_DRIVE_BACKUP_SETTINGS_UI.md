# v1.53 Google Drive・外部バックアップ設定UI統一

正式仕様 `REGISTER（仮）_Androidレジ_詳細仕様書_v2.5` とユーザー指定UI原則（画面左上「戻る」、紺色 `#173F6B` 共通上部バー、不要なセカンダリラベルや説明の削減）に準拠。

## 実装済み

- **Googleかんたん接続**: 共通紺ヘッダーと左上「戻る」。横向きでは「Googleと連携」「今すぐ同期」を同列に配置。「連携解除」「保守・復旧」は別行。最下部の技術者向け定型説明パネルを削除し、実際のアカウント状態・送信結果を優先。
- **Google Driveアカウント**: 共通ヘッダーを固定し内部のみスクロール。通常表示はアカウント状態、送信状態、「登録/変更」「接続確認」「今すぐアップロード」。再試行・連携解除・診断/ログ・接続テストJSON・技術仕様の説明は「詳細操作」の開閉内へ。接続認可エラー時の初期設定案内は常時確認可能。
- **Google Drive診断**: 共通ヘッダー固定。従来の6ボタン横一列を3ボタンずつの2行に分け、画面幅が狭い場合でも操作できるよう修正。ログ出力の個人情報/トークン除去と実際の診断データは変更なし。
- **Google Drive初期設定ガイド**: 共通ヘッダー・戻るを固定。OAuthパッケージID・署名SHA-1の表示/コピー、Google Cloud Console、つぐレジとつぐレジ＋のクライアント別登録案内は保存。
- **外部自動バックアップ**: 独自バーを共通バー化し左上「戻る」。下部は保存を主操作として保持。保存先に含まれる内部URI文字列は普段の画面に表示しない。実行履歴・失敗通知等は「実行状態・通知の詳細」に格納。ただし `status.lastError` は常時表示。Z精算・SQLite売上・内部バックアップを変更せず、設定保存/外部保存要求/監査ログは維持。

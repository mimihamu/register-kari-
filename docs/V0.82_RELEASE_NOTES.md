# v0.82 Release Notes

## 点検・精算 整合確認監査 CSV出力

- `SCR-522 整合確認監査 CSV出力` を追加
- SCR-520から直接開く導線を追加
- OK / INFO / ALERTと検索文字で条件指定
- 条件一致監査を表示上限500件に依存せず全件CSV出力
- CSV開始時点の `(created_at, id)` を固定し、保存先選択中の新着監査混入を防止
- 0件時はヘッダーだけを出力し、保存先選択中の後発監査を混入させない
- 監査No.、日時、判定、レポートNo.、種別、営業日、営業セッション、snapshot種別、差異件数、担当者、イベント、比較証跡を出力
- UTF-8 BOM / CRLF / 全セルquoted
- CSV数式注入を抑止
- Android Storage Access Framework `CreateDocument("text/csv")` を利用
- 保存先選択から戻った時点で権限を再確認
- `operation_audit`・売上・税・支払・点検精算snapshotは読み取り専用
- OAuth token / Authorization header / content URI / raw sales JSONをCSVへ含めない
- v0.81の監査台帳、v0.79の追記専用監査、v0.78の整合比較を維持

# v1.37 顧客表示: サーバ再設定時の旧金額排除・発行順直列化

正式仕様v2.5 §30.2 / §30.5 / §30.11。

- 顧客表示の再設定・再起動時に前回のPAYMENT/COMPLETE/CHANGE状態を直ちにWebSocket接続先へ送信しない。
- POS内の新しいWebSocketサーバは、初回DB pollの最新状態を受信するまで金額を持たないSTANDBYから開始する。
- 起動時STANDBYもsequence/serverInstanceId/sentAtMillisを付加し、同一process内の更新順を維持する。
- Cart pollerと決済画面の同時publish競合を防ぎ、sequence更新→latest置換→send queue投入を同一lock内で実行する。
- 表示端末は通信101成功後にもsnapshot受信まで旧金額を表示しない（別コミット`6153ef51`）。
- 既存印刷・会計処理ではCD ACK待ちを行わない。実Wi-Fi切断・再接続試験は未実施。

# v0.12 プリンター信頼性強化

## 目的

TCP 9100／ESC/POS印刷を実店舗運用向けに強化し、通信切断時の二重印刷、プリンター異常時の誤送信、印刷キューの放置を防止する。

- 売上レシート、返品・取消レシート、X点検票、Z精算票への安全処理
- 開発版専用パッケージと固定署名
- EPSON TM、STAR ESC/POS、汎用ESC/POSのプロファイル基盤
- 58mm／80mm選択

- キャッシュドロア有効／無効
- DK1／DK2選択

- ドロア単体テスト
- 既存プリンター設定のSQLite移行

## v0.12.0-dev.5 プリンター状態診断

EPSON ESC/POSのリアルタイムステータスコマンド`DLE EOT n=1～4`を一括送信し、4バイトの応答を解析する。

取得項目：

- オンライン／オフライン
- カバー開閉
- ロール紙ニアエンド
- ロール紙切れ
- 紙送り停止
- 復帰可能エラー
- オートカッターエラー
- 復帰不可能エラー
- 自動復帰エラー
- オンライン復帰待ち
- 紙送りボタン状態
- ドロア信号
- RAWステータス4バイト
- 応答時間

開発版には`つぐレジ プリンター診断`を追加した。保存済みプリンター設定を読み込み、手動確認または5秒間隔の自動監視を実行できる。

STAR／汎用プロファイルではDLE EOT互換モードとして問い合わせる。機種が双方向応答に対応しない場合はタイムアウトとして表示し、印刷成功と状態取得成功を混同しない。

## v0.12.0-dev.6 統合印刷キュー

開発版に`つぐレジ 印刷キュー`を追加し、次のジョブを1画面で管理する。

- 売上レシート
- 返品・取消レシート
- X点検票／Z精算票

機能：

- 全件、待機中、要確認、完了の絞り込み
- PENDING／RETRY／PRINTING／FAILED／COMPLETED件数表示
- 試行回数、最終エラー、用紙幅、帳票プレビュー表示
- 再試行待ちへの手動復帰
- プリンター状態の手動確認
- 安全印刷
- 確認済み強制印刷

### 安全印刷

印刷前にリアルタイムステータスを取得する。

- `READY`：印刷を許可
- `WARNING`：用紙ニアエンド等として印刷を許可
- `OFFLINE`／`ERROR`：印刷を停止
- 状態取得失敗：印刷を停止

### 確認済み強制印刷

送信結果不明で`FAILED`になったジョブについて、担当者が紙出力なしを確認した後にだけ使用する。状態取得を省略して明示的に送信する。

`FAILED`は自動再送しない。紙出力有無を確認せずに再試行すると二重印刷になるため、画面上にも注意文を常時表示する。

## 現金会計とドロア

- 現金を含む初回売上レシートだけにドロアキックを付加する。
- 再発行、キャッシュレスのみの会計、返品・取消票、X点検票、Z精算票では自動で開かない。
- 設定画面からドロアだけを手動テストできる。

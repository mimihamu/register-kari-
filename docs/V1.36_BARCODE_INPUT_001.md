# v1.36 バーコード入力（#35）

## 正式仕様 v2.5 対応

- SAL-006: スキャナ入力を商品コードとして検索し、該当1件なら即登録する。
- SAL-006受入条件: 検索結果を100ms以内に処理する。
- SAL-007: 未登録時は権限に応じて「商品登録」「仮商品」「キャンセル」を選択できる。
- SAL-007推奨: 仮商品は名称「未登録商品」とし、読取コードを保持する。

## 実装

- `ScannerGatewayV136`
  - Android USB/Bluetooth HID のキーボードウェッジ入力を受ける。
  - `start()` / `stop()` でActivityライフサイクルに追従する。
  - Enter/テンキーEnterを読取終端として扱う。
  - HIDではシンボル種別を取得できないため `symbology=null`、読取コードとtimestampを保持する。
- `InputRouterV136`
  - raw `KeyEvent` と販売UIを分離し、`BarcodeScannedV136` を中央配送する。
- `BarcodeProductIndexV136`
  - 商品コード/バーコードを事前索引化し、スキャン時はO(1)の完全一致検索を行う。
  - 商品コードとバーコードが異なる商品へ衝突する曖昧ケースは登録せずfail-closedとする。
- 未登録バーコード
  - 責任者かつ設定権限ありの場合のみ「商品登録」を表示する。
  - 商品登録へ遷移した場合は読取バーコードを商品マスター画面へ引き継ぐ。
  - 「仮商品」では単価と税区分を明示入力し、名称を「未登録商品」、商品コード/バーコードに読取値を保持して現在取引へ登録する。
  - 「キャンセル」で取引を変更せず閉じる。

## 自動テスト

`V136BarcodeInputSafetyTest` で以下を確認する。

- 短いコードを含むHID入力とEnter終端
- 遅い途中入力のリセット
- 商品コード/バーコード完全一致と曖昧一致の抑止
- 10,000商品索引での100ms予算内検索
- 仮商品の名称・読取コード保持
- ScannerGateway → InputRouter → SalesScreen、および権限付き未登録導線のソース接続

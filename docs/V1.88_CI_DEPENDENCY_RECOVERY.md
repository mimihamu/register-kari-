# v1.88 CI依存配布先504からの復旧

GitHub Actionsの`setup-gradle@v4`でGradle 9.5.0配布先が504を返した場合、`ci/gradle-9.5-official-fallback.sh`がGradle公式`downloads.gradle.org`からZIPと公式SHA-256を取得し、検証したGradleを実行PATHへ追加する。

Kotlin 2.3.21のコンパイラJARはMaven CentralがGitHub Releasesへのリダイレクトで504となる場合があるため、事前に`ci/prepare-kotlin-compiler-2.3.21.sh`が別のMavenキャッシュから試験的に取得する。**JetBrainsが公開したSHA-256**（`d3e70fb011675e77ef00f1a68918d3cd91eed26058977d1e3ea2a37a293233af`）を検証し、一致する場合だけその単一モジュールをCI限定ローカルMavenリポジトリから優先解決する。不一致なら拒否する。

両ファイルとも取得に失敗した場合は、Gradleの通常のMaven解決へ戻る。開発者の通常ビルドは`CI_KOTLIN_COMPILER_REPO`を設定しなければ影響を受けない。移行・リリース・実機受入には含めず、CI復旧専用。版数はPOS 208、管理73、CD51のままである。

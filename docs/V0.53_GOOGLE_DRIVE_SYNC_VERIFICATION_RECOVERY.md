# v0.53 Google Drive売上同期検証・復旧

## 目的

Google Driveの接続設定だけでなく、現在選択されている方式で実際に売上JSONの差分同期を実行し、取込・重複・隔離・停止状態を一画面で確認する。

## 追加機能

- Drive API／互換フォルダの現在方式で差分同期
- 30分以上続く実行中状態の停止疑い判定
- 選択方式に合わせた自動同期設定の修復
- Drive API失敗カテゴリの保持
- 直近20件の同期検証履歴
- Googleアカウントをマスクした診断レポート共有
- 取込済み件数、隔離件数、最終同期結果の一括表示

## 安全条件

- 履歴消去では売上データを削除しない
- 設定修復ではSQLite、Drive上のJSON、同期指紋を削除しない
- アクセストークン、更新トークン、Authorizationヘッダーを保存しない
- 診断レポートへフォルダURI、content URI、JSON本文を含めない
- duplicateImportKeyと既存同期指紋による重複防止を維持する

## 実機確認

1. 運用方式を確定する。
2. 「現在の方式で差分同期を実行」を押す。
3. 新規・重複・隔離・エラー件数を確認する。
4. 同じJSONを再同期し、新規取込が増えないことを確認する。
5. アプリ再起動後も方式と履歴が維持されることを確認する。
6. 診断レポートにトークン、URI、JSON本文が含まれないことを確認する。

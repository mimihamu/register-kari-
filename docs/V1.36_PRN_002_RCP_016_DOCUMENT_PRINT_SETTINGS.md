# v1.36 Issue #137 #20 / 正式仕様 RCP-016 文書別設定

Issue #137 の旧 `PRN-002 通常/お客様控え/保存等の印刷モード` は、正式仕様 v2.5 の PRN-002（プリンター試験）とは番号・意味が一致しない。v1.36 では正式仕様 RCP-016「文書別設定」を実装基準とする。

## 対象

正式仕様に合わせ、次の5文書を対象とする。

- レシート
- 領収書
- 仮締め票
- 点検票
- 精算票

各文書に `自動印刷 / 部数 / ヘッダ / フッタ` を保持する。部数は初版制約の1〜3部とする。

レシートの自動印刷は #19 / RCP-002 で導入済みの `receiptAutoPrintEnabled` を唯一の正とし、競合する二重設定は作らない。RCP-016側ではレシートの部数・ヘッダ・フッタを保持し、自動印刷の表示はRCP-002設定を参照する。

## 初期値と互換性

既存動作を壊さないため、従来から自動生成されていたレシート・X点検・Z精算は初期値ONとする。従来手動発行だった領収書・仮締め票は初期値OFFとする。

領収書・仮締め票の手動印字は、自動印刷OFFでも禁止しない。返品・取消レシートはRCP-016対象外なので従来動作を維持する。

## 複数部

業務帳票は同一参照の印刷ジョブを設定部数分登録する。ヘッダ・フッタはジョブ登録時のpayloadへ反映する。

売上レシートは、コピー2部目以降を別ジョブにすると `print_count` や再発行判定、ドロア連動へ影響するため、1つの論理印刷ジョブ内で1〜3部を連続エンコードする。現金会計時のドロアキックは1部目だけに付加する。

## X点検 / Z精算

X点検とZ精算は同じ `SETTLEMENT_REPORT` 印刷基盤を使うが、文書設定は `INSPECTION` と `SETTLEMENT` に分離する。帳票確定自体と印刷ジョブ生成は分離し、自動印刷OFFでも点検・精算データは確定する。

## 実機未確認

以下は実機確認済みとは扱わず、最終統合受入へ繰り越す。

- 58mm / 80mm実プリンターでの複数部カット位置
- ヘッダ / フッタの実印字位置
- X点検 / Z精算の自動印刷ON/OFF
- 紙切れ・カバーオープンからの復旧
- ドロア連動と複数部印刷の組み合わせ

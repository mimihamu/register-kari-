# つぐレジ v0.25.0-dev.1 リリースノート

## 変更点

- レジ管理メニューの「点検・精算」を「X点検」と「Z精算」の別ボタンへ分離。
- X点検とZ精算を別画面・別ルートに変更。
- 各画面から処理種別の切替操作を撤廃。
- Z精算に営業終了確認ダイアログを追加。
- Z精算の最終確定を責任者PIN入力後のみ有効化。
- v0.24の入出金保存処理に残っていた整形不良を修正。

## 継承する仕様

- Z精算が正常確定した時点で営業セッションを終了する。
- 同じ営業日でも、終了後は新しい営業セッションを開始できる。
- Z精算と営業終了は同一SQLiteトランザクションで確定する。

## 実機確認

- X点検後も販売を継続できること。
- Z精算画面へ誤って入った場合に「戻る」で終了できること。
- PIN未入力ではZ精算を最終確定できないこと。
- Z精算確認画面の売上、実査額、過不足が正しいこと。

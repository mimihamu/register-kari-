# v0.45 リリースノート（開発版）

## バージョン

- つぐレジ：`0.45.0-dev.1`（versionCode 75）
- つぐレジ＋：`0.7.0-dev.1`（versionCode 7）
- つぐレジ CD：`0.14.0-dev.1`（versionCode 7、機能変更なし）

本成果物は開発署名のDebug APKであり、本番配布用ではない。

## 追加内容

### つぐレジ

- Google Drive APIによる売上ジャーナルJSONの直接アップロード
- `つぐレジ/stores/{storeId}/terminals/{terminalId}/journal/{businessDate}`の自動作成
- Driveフォルダ／ファイルを`appProperties`と親fileIdで識別
- `duplicateImportKey`とSHA-256による重複アップロード防止
- Drive fileId、modifiedTime、SHA-256、再試行状態のSQLite保存
- Outboxの`STAGED`／`SENT`を対象とした独立配送
- 通信失敗、レート制限、Drive一時障害の再試行
- 認可切れ、API無効、容量不足、権限不足、不正データの分類
- Googleアカウント連携画面からの手動アップロードと失敗再試行

### つぐレジ＋

- Drive APIによる売上ジャーナルJSON一覧取得
- fileId、modifiedTime、SHA-256による差分同期
- 変更ファイルのダウンロード
- 既存`SalesJournalImportRepository`への接続
- 同一JSON、同一イベントの二重計上防止
- 不正JSONの既存隔離機能への接続
- 手動差分同期
- 全件再取込
- 起動時差分同期
- 1時間ごとの定期同期
- 最終同期件数、新規、重複、隔離、読込エラーの表示
- SQLiteOpenHelper DB version 4への移行

### 維持した機能

- SAFによる複数JSON取込
- フォルダ登録と差分取込
- USB、端末フォルダ、Driveアプリ経由の互換用フォルダ方式
- 売上ジャーナルv1契約
- duplicateImportKey v1
- 既存イベント種別
- つぐレジの横画面固定
- つぐレジ＋の`sensorPortrait`
- つぐレジ CDの既存機能

## セキュリティとデータ方針

- 使用スコープは`drive.file`のまま変更しない。
- アクセストークン、更新トークン、Googleアカウントのパスワードは保存しない。
- Googleアカウント連携解除でローカル売上を削除しない。
- Drive上の削除とローカル売上削除を自動連動しない。
- Driveを唯一の原本にしない。
- 共有ドライブはv0.45対象外。

## Google Cloud設定

実機利用にはv0.44と同じGoogle Cloud設定が必要。

- Google Drive API有効化
- OAuth同意画面
- 必要に応じたテストユーザー
- Android OAuthクライアント
- 開発版applicationIdと開発署名SHA-1

開発版applicationId：

- `jp.co.tenposinfo.register.dev`
- `jp.co.tenposinfo.register.plus.dev`

開発署名SHA-1：

`5C:CC:D8:26:5E:BF:69:FF:36:EC:9D:37:6E:8C:AC:2A:DE:DB:89:44`

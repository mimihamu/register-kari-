# v1.73 両替は販売画面からのドロア開放だけ

- v1.72で入出金の選択肢から撤去した両替を、SecureOperationsCoordinatorとOperationsStoreの書込処理でも禁止する。入出金の新規登録は入金/出金のみ。
- `CashMovementType.EXCHANGE` は過去の取引・バックアップ・履歴表示との互換用に残す。
- 販売画面のドロア両替は現金移動や売上登録に関与しない。既存の `cash_drawer_events` に物理開放の履歴を残す。
- 連続タップの意図しない複数開放を防ぐため、受け付けた開放から1500ms未満の次のタップは無視。送信中のボタン無効化も維持。
- 販売画面の幅が狭い場合、両替ボタンをやや縮小し小計/会計ボタンの表示幅を拡張する。
- 実機では連打、物理ドロア接続、拒否・送信失敗、バックアップからの旧EXCHANGE履歴表示、800dp付近のタップ対象サイズを確認する。

# v1.35 領収書・分割複数枚印字 仕様監査

## Issue #137 対応

Issue #137 #33「領収書・分割複数枚印字（例: 4,000円×30枚）」を、詳細仕様書 v2.5 の RCP-018〜RCP-022 / 16.5 と突合した。

この変更では v1.35 で先行して、指定額×枚数の金額整合、補助領収書表示、店舗上限、印刷途中失敗からの未印刷分再開を固める。実プリンタ確認は他の実機項目と最後にまとめて実施するため、Issue #137 の完了件数にはまだ加算しない。

## v2.5 要件

- `receipt.maxBatchReceiptCopies`: 1〜999、初期100。
- 120,000円の元売上に対して4,000円×30枚を一括生成できる。
- 分割複数枚は補助領収書として、元売上番号・発行グループ・枝番・「適格簡易請求書ではありません」を表示する。
- 初回発行済み累計が元取引合計を1円でも超える場合は保存前に拒否する。
- 再発行は初回発行済み金額へ加算しない。
- 紙切れ・通信断では印刷済みと未印刷を識別し、未印刷分だけ再開する。完了済み票を再送しない。
- 発行条件、担当者、印刷結果、再発行履歴から元売上・発行グループを追跡できること。

## 実装

### 発行金額・店舗上限

`ReceiptVoucherPolicy`

- 日本円は従来どおりLong整数で扱い、`BigInteger` で `1枚金額 × 枚数` のオーバーフローを事前検証する。
- 発行予定合計が発行可能残額を超える場合はDB保存前に拒否する。
- 絶対上限を999枚へ合わせ、店舗設定は `ReceiptVoucherBatchSettingsV135` で初期100枚、1〜999枚に制限する。
- UIとDB確定時の双方で同じ店舗上限を使用する。
- v2.5既定どおり宛名空欄を許容する。但し書き・担当者は必須のまま。

### 補助領収書表示

複数枚発行時の各票に以下を表示する。

- `適格簡易請求書ではありません`
- 元売上No.
- 発行グループ `RG-<batchId>`
- 枝番 `n/N`
- 分割票へ適格簡易請求書の確定税額を表示せず、元売上の監査情報を参照する旨

再発行は同じ発行票ID・発行グループ・枝番を維持し、従来どおり `【再発行】` を追加する。再発行行は `receipt_voucher_reprints` に追記され、`receipt_voucher_issuances` を増やさないため発行可能残額を二重消費しない。

### 一括印刷の途中再開

`ReceiptVoucherBatchRecoveryV135.kt`

- 進捗の正本は既存 `document_print_jobs` とし、`receipt_voucher_reprints` に紐付く再発行ジョブを一括進捗から除外する。
- `COMPLETED` の元ジョブだけを印刷済みとして数える。
- 一部成功または失敗を含むグループは `PARTIAL` として表示する。
- 再開時は新しい領収書・新しい印刷ジョブを作らない。
- `FAILED` の未印刷元ジョブだけを `RETRY` に戻し、`PENDING/RETRY` はそのまま既存自動印刷処理へ渡す。
- `COMPLETED` は更新対象にしないため、例として1〜12枚目成功後に13枚目で停止した場合、再開対象は13〜30枚目のみとなる。
- 再開操作は `RECEIPT_BATCH_RESUME` として `operation_audit` に担当者・印刷済み枚数・対象枝番を追記する。
- `DISCARDED`、印刷ジョブ欠落、印刷中ジョブを含む場合は自動再開せず、安全側に停止する。

### UI

`ReceiptVoucherActivity`

- 売上合計、初回発行済み、発行可能残額、現在の店舗一括上限を表示する。
- 発行前に `1枚金額 × 枚数 = 発行予定合計` を確認する。
- 複数枚の場合は補助領収書であることを確定前に表示する。
- 発行グループごとに印刷済み/総枚数、未印刷枚数、次の未印刷枝番を表示する。
- `PARTIAL` かつ安全に再開可能な場合だけ「未印刷分を再開」を表示する。

## 自動テスト

`V135ReceiptSplitBatchSafetyTest`

- 初期上限100 / 絶対範囲1〜999。
- 4,000円×30枚 = 120,000円。
- 補助領収書の非適格表示、元売上、発行グループ、枝番。
- 1〜12完了、13失敗、14〜30待機からの再開対象が13〜30だけになること。
- 一括進捗から再発行ジョブを除外するSQL。
- 完了済みジョブを再開更新しないこと。
- UIの一括上限・宛名空欄・未印刷分再開導線。

既存 `V058ReceiptVoucherFoundationTest` も v2.5 の補助領収書表記に合わせて更新した。

## v1.36側へ残す関連項目

RCP-020 の「税率別対象額・税額を各分割票へ内部配賦し、30票の内部配賦合計を元取引スナップショットへ一致させる」監査値の永続化は、Issue #137 の税・インボイス側（TAX-005等）と一緒に扱う。v1.35では分割票を独立した適格簡易請求書として扱わず、確定税額を分割票へ印字しない安全側の表示までを固定する。

## 最後にまとめて行う実機確認

- 120,000円売上で4,000円×30枚を実プリンタへ連続印刷。
- 30枚すべての元売上No.、RG番号、1/30〜30/30、非適格表示。
- 58mm / 80mmで文字切れ・紙送り・カット位置。
- 途中で紙切れ/通信断を起こし、印刷済み票を確認後に未印刷分だけ再開。
- 再開後に既印刷票が重複しないこと。
- 再発行しても発行可能残額が変化しないこと。
- 宛名空欄、但し書き、100枚既定上限の画面操作性。

実機未確認のため、現時点では「コード・自動検証・APK検証済み / 実機確認待ち」として扱う。

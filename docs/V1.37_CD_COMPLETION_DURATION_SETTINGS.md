# v1.37 CD表示時間設定の分離
基準：正式仕様 v2.5 §30.7, §30.9。
- SCR-660に「お釣り表示秒数」（changeSeconds、1〜30秒、初期5秒）と「完了表示秒数」（completeSeconds、1〜30秒、初期3秒）を独立表示。
- 送信側は売上確定後のみCHANGEを開始し、changeSeconds後にCOMPLETE、completeSeconds後にSTANDBYを送信する。
- 既存のcompleteSeconds保存値は引き続き尊重し、欠損している新規設定の初期値のみ3秒へ変更。未移行の古い店舗設定値を破壊しない。
- 実機画面・秒数表示の実測は未確認。

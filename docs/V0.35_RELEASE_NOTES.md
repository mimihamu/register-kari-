# つぐレジ v0.35.0-dev.1 リリースノート

## 売上ジャーナル外部自動送信

- 端末内で生成したOutbox JSONをGoogle Drive、USB、端末フォルダへ自動配送
- Android Storage Access Frameworkによる送信先選択
- 永続読込・書込URI権限
- `STAGED`を端末内JSON完成、`SENT`を外部検証済みとして分離
- 営業日およびイベント種別ごとのフォルダ階層
- `.partial`書込後のサイズ・SHA-256照合
- rename非対応DocumentsProviderの再コピー確定
- 同名・同一SHA-256ファイルの重複配送防止
- 最大10回の段階的再試行と管理者による失敗再試行
- 保存先権限失効と配送失敗のAndroid通知
- 配送成功、重複、失敗、権限失効、手動再試行の監査ログ
- 従量課金でないネットワーク接続時だけ送信する設定

## 業務継続

- 外部送信失敗で売上を巻き戻さない
- 外部送信失敗で印刷ジョブを取り消さない
- 外部送信失敗でZ精算・返品・入出金を巻き戻さない
- SQLiteと`sales_journal`を正本として維持
- v0.34の外部バックアップ複製を維持
- v0.33の定期内部バックアップと失敗通知を維持
- v0.32の統合印刷キューを維持
- v0.31のプリンタ設定幅固定を維持

## バージョン

- つぐレジ: `0.35.0-dev.1` / versionCode `65`
- つぐレジ CD: `0.13.0-dev.6` / versionCode `6`

## 制限

- Google Drive REST APIおよびGoogle OAuthは使用しない
- Drive側のクラウド同期完了時刻はGoogle DriveアプリとAndroidに依存
- 双方向同期およびつぐレジ＋からのマスター反映は未実装
- 実端末、Google Drive、USB、容量不足、権限失効、Dozeでの確認が必要

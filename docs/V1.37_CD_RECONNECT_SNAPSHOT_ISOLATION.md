# v1.37 顧客表示: 再接続時の旧金額漏出防止

正式仕様v2.5 §30.5 CDP-NET-003 / §30.11 / CDP-AT-09に対応。

- WebSocketの101 handshake成功だけでは商品名・合計・旧お釣りを顧客表示しない。
- 新しいTransport接続時にHub内の以前のlatestSnapshotを破棄し、REGISTERが送信する最新完全snapshotを待つ。
- Activity再生成時には、接続できていない過去snapshotを別の画面へ再配布しない。
- 受信済みの最新完全snapshotが前回と同一sequenceでも、再接続待ち状態から表示へ復帰できる。
- 同一serverInstanceIdでsequenceが減った古いsnapshotは拒否する。
- 旧顧客表示からの通信形式や同一接続での重複sequence無視は維持する。
- 回線切断直後の表示猶予は既存設定の最大3秒とする。新画面での旧データ自動復元は行わない。
- 実機2台の再接続・再起動・回線切替受入試験は別途必要。

# v0.75.0-dev.1 リリースノート

## 変更点

- SCR-648「通常レシート再印字 運用台帳」にCSV出力を追加
- 出力対象はボタン押下時点の適用済み条件＋固定snapshot
- 画面の1ページ200件ではなくsnapshot内の条件一致全行を逐次出力
- Android Storage Access Frameworkでユーザーが保存先を指定
- UTF-8 BOM / CRLF / 全セルquoted CSV
- requested_at / sale_created_atをISO offset日時で出力
- CSV数式注入対策（`= + - @`）
- 引用符・改行の正規化/エスケープ
- 保存先選択後にVIEW_SALESを再確認し、失効時はfail-closed
- 出力処理はIO dispatcherで実施
- 成功時に出力件数、失敗時にエラーをSCR-648へ表示
- v0.74条件一致新着、v0.73 stable snapshot/keyset pagingを維持
- 読み取り専用。監査履歴・売上・税・支払・印刷jobの更新/削除は追加しない

# v0.79 Release Notes

## つぐレジ 0.79.0-dev.1

点検・精算履歴の「保存値と現在DBを照合」に追記専用監査を追加する。

### 追加

- 整合確認の `OK / INFO / ALERT` をすべて監査記録
- 既存 `operation_audit` を利用し、レポートNo.・営業日・営業セッション・snapshot種別・差異件数・差異内容・担当者・日時を保存
- `SETTLEMENT_RECONCILIATION_OK`
- `SETTLEMENT_RECONCILIATION_INFO`
- `SETTLEMENT_RECONCILIATION_ALERT`
- 監査追記成功後に「整合確認を監査履歴へ記録しました。」を表示
- 監査保存失敗時は成功結果を返さないfail-closed動作

### 維持

- v0.78のX点検差異=INFO、Z精算差異=ALERT
- snapshot version awareな照合
- runtime権限再確認
- 営業セッションの再取得・一致確認
- 売上・税・支払・精算snapshotの非破壊
- 通常レシート再印字監査など既存監査履歴の非破壊
- Google Drive診断情報の秘匿

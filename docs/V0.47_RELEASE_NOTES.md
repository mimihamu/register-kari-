# つぐレジ v0.47.0-dev.1 リリースノート

## 追加

- Google Drive診断・ログ画面
- applicationId、署名SHA-1／SHA-256、端末、Android、Google Play開発者サービス、ネットワークの一括表示
- Googleアカウント接続状態、最終接続確認、直接アップロード結果の表示
- `sync_outbox`と`drive_api_uploads`の状態別件数
- 直近20件の直接送信失敗表示
- 最大100件の診断イベント保存
- 診断ログのコピー／共有
- 診断画面からの送信テスト
- 診断イベント消去

## 安全性

- アクセストークンと更新トークンは従来どおり保存しない
- 診断ログへ売上JSON本文、レシート明細、保存先content URIを出力しない
- Googleアカウントのメールアドレスはマスクする
- 例外内のBearer値、Googleトークン形式、content URIを共有前に置換する
- 診断イベント消去で売上データやOutboxを削除しない

## 維持

- v0.46 Google Drive初期設定ガイド
- v0.45 Drive API直接アップロード／ダウンロード／差分同期
- `drive.file`限定スコープ
- SAFフォルダ方式の互換運用
- SQLiteローカル売上を原本とする設計
- 共有ドライブ非対応

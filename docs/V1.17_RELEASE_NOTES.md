# v1.17.0-dev.1 リリースノート

v1.17は同期データの再実行整合性を強化する版です。

- つぐレジ: 同じeventIdを再利用する場合に業務内容の一致を確認する仕組みを追加。
- つぐレジ＋: 同じduplicateImportKeyを再利用する場合に論理内容の一致を確認する仕組みを追加。
- 完全一致する通常の再送は従来どおり冪等に扱う。
- つぐレジ＋のManagementDatabaseをversion 5へ更新。

- つぐレジ＋: 16 / 0.16.0-dev.1
- つぐレジ CD: 変更なし

自動検証は累積unit test、Kotlin compile、3 APK生成、APK整合性確認、Artifact確認、SHA-256再計算まで行う。実端末での同期とDB移行確認は最終総合実機試験へ繰越す。

## v1.18.0-dev.1 同期衝突の隔離・監査

- 同一duplicateImportKey・異内容をimport transaction内で決定的衝突として分類。
- 正常な完全一致再送はduplicateとして従来どおり冪等処理。
- 衝突文書は `DUPLICATE_KEY_MISMATCH` のrejectionへ記録し、batch全体をrollbackしない。
- 衝突を `rejectedCount` と `COMPLETED_WITH_ERRORS` に反映。
- Drive同期はimport完了後のfingerprint記録へ進むため、未変更の決定的衝突を自動再試行し続けない。
- v1.17 DB guardは最終防御層として維持。

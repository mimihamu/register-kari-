# v0.72 再印字台帳 任意日付範囲検索

## 目的

v0.71の全期間・今日・7日・30日に加え、問い合わせや監査で特定日だけを調べられる任意の開始日／終了日検索をSCR-648へ追加します。

## 入力

- 開始日 `yyyy/MM/dd`
- 終了日 `yyyy/MM/dd`
- `yyyy-MM-dd` も受け付ける
- 開始日だけ、終了日だけの片側指定を許可
- 両方空欄は不可
- 終了日が開始日より前なら不可
- 存在しない日付は不可

入力検証に失敗した場合、現在適用中の検索条件と結果を維持し、エラーだけを表示します。

## SQL境界

開始日はその日の0:00を含む `requested_at >= ?` とします。

終了日は23:59:59.999を生成せず、翌日0:00を排他的上限とした `requested_at < ?` とします。これにより保存時刻のミリ秒精度に依存せず、指定終了日の全時刻を含めます。

開始／終了epoch値はSQLへ埋め込まずバインド引数として渡します。

## タイムゾーン

日付からepochへの変換は端末のローカルタイムゾーンを使用します。DSTが存在する地域でもLocalDateのatStartOfDayで日境界を求めます。

## データ保護

検索は読み取り専用です。監査履歴、売上、税、支払、印刷jobを更新・削除しません。印刷復旧は引き続き統合印刷キューだけで行います。

## 実機未確認

- ソフトキーボードでの日付入力操作性
- 端末タイムゾーン変更時の任意期間
- DST境界を含む期間
- 数万件規模の任意期間検索性能

# REGISTER（仮）

Android タブレット向けレジ、売上管理アプリ、Customer Display の開発リポジトリです。

## 基準資料

- `REGISTER（仮） Android レジ・売上管理・Customer Display 詳細仕様書 v2.5`
- `REGISTER（仮） 全画面構成・画面遷移イメージ集 v1.3`

## 開発方針

最初に REGISTER 本体の販売・伝票・会計・売上保存を実装し、実機確認可能な APK を継続的に生成します。その後、印刷、点検・精算、Google Drive 同期、売上管理アプリ、Customer Display を追加します。

## パッケージ名

`jp.co.tenposinfo.register`
